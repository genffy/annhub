## 维护约定

1. `docs/v2/` 是产品层真源，描述目标、边界、契约和路线图；规则见 [v2 文档约定](./v2/AGENTS.md)。
2. 根目录 `AGENTS.md` 是工程约定入口；目录专属规则由各级 `AGENTS.md` 管理，当前实现细节以源码和测试为准。CI、发布与仓库设置见根 `README.md`，工作流文件自带说明。
3. 不另建工程方案或待办文档：未确认的想法和待办进 [validation.md](./v2/validation.md)，交付状态进 [roadmap.md](./v2/roadmap.md)，局部的维护提示放进相应目录的 `AGENTS.md`。
4. 新文档必须服务剪藏、截图的采集与库内阅读、高亮、检索、导出的主链路；历史专项能力不再进入现行产品文档。
5. 每篇文档顶部保留更新日期（`更新时间：YYYY-MM-DD`）。
6. 图片资源放在对应模块的 `assets/` 下，并使用相对路径引用。
