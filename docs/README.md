## 维护约定

1. `docs/v2/` 是产品层真源，描述目标、边界、契约和路线图。
2. 根目录 `AGENTS.md` 是工程约定入口；目录专属规则由各级 `AGENTS.md` 管理，当前实现细节以源码和测试为准。
3. 新文档必须服务知识碎片主链路；历史专项能力不再进入现行产品文档。
4. 每篇工程文档顶部保留 `更新时间：YYYY-MM-DD`。
5. 图片资源放在对应模块的 `assets/` 下，并使用相对路径引用。
