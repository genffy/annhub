# AnnHub v2 UX/UI 设计稿

> 更新时间：2026-10-08。设计依据是 [docs/v2](../../v2/README.md)；文案与规则以 docs/v2 为准，本目录只做视觉与交互表达。

覆盖 docs/v2 里涉及的全部界面：页面里留下内容的两种方式（剪藏——选中一段或指一下整块——和截图），以及扩展自己的应用页（资料库、阅读视图、属性、设置）和工具栏弹窗。剪藏与截图是同一种“条目”，所以界面只有一套；**高亮不在网页里做**，它是在资料库里读剪藏时划出的标注；**所有扩展页面都是左侧导航 + 右侧内容**，窗口再窄也只折叠为图标栏，不换成顶部导航。每块画板标注了依据的文档章节和交付版本，并附编号的交互说明。

## 怎么看

直接用浏览器打开 [index.html](index.html)，不需要构建（用到 `oklch()` 与 `color-mix()`，需要 Chrome / Edge 111+、Safari 16.4+、Firefox 113+）。也可以起一个静态服务：

```bash
python3 -m http.server -d docs/design/v2 4177
```

- 改过脚本或样式后请强制刷新：静态服务会让浏览器缓存 `js/`、`css/` 下的文件。
- 页眉的“标注”开关控制画板上的编号钉，“亮色 / 暗色”切换主题（网页模拟区始终保持亮色）。
- 悬停画板右上角可放大到 100%；加 `?solo=关键字`（匹配画板标题）或 `?solo=序号` 只渲染对应画板，方便逐块检查。
- 标有“可交互”的两块是原型，放在“浏览器扩展”章节最后，共用同一份内存数据（刷新即重置，不写入任何存储）：
  - **页面里：选中文字或指一下整块，再剪藏 / 截图**：选区菜单只有“剪藏”和“截图”；点“剪藏”一步保存，约 3 秒的“已剪藏 · 撤销 · 编辑”，快速编辑可改标题、标签、备注。不选中任何文字，把指针停在“Three common strategies”那一节、其中的代码块或页面底部的帖子上约 0.4 秒，旁边出现胶囊「剪藏 | 截图 | 上一级 | 更多」，⌃ 选上一级；代码块和帖子的右上角各有页面自己的按钮，胶囊会让开。新剪藏会自动带上属性页里为“剪藏”勾选的预设，页面上不留任何标记。
  - **资料库：读剪藏、划高亮**：切换视图、折叠导航、搜索与按类型 / 标签 / 属性筛选；在抽屉或阅读视图里**选中一段原文**，选区旁出现五个颜色点，点一个创建高亮（`H` 以默认颜色创建，选区跨过已有高亮会合并）；点已有高亮改色、写备注、删除并可撤销；“高亮”视图按剪藏分组，点一行回到阅读视图的原位置；删除有高亮的剪藏会先提示高亮数；添加属性（补全已有的、选类型新建、保留名与同名被拒绝）、属性页（使用数、预设、删除未使用）、设置（区块入口开关、截图的下载格式 / 比例预设 / 水印开关）、导出对话框。上一块原型里保存的条目（Markdown）会出现在这里。键盘也能走通：Tab 与 Enter / 空格操作，导航里 ↑ ↓ 切换，`/` 聚焦搜索，抽屉打开时焦点进入并在其中循环，Esc 依次关闭对话框、高亮浮层与选区工具条、补全、抽屉和阅读视图。

## 目录

```text
index.html           画布外壳
css/                 tokens（令牌，含亮暗）· canvas（画布、规格表、标注钉）· ui（基础件）· ext（应用壳、页面内浮层、阅读视图、各页面与原型）
js/data.js           两种条目类型与库内高亮、六种属性类型、样例条目（剪藏的 content 是 Markdown，带高亮）与属性注册表（文案取自 docs/v2），以及两个原型共用的 STORE
js/ui.js, core.js    片段生成工具；画板 / 分组 / 章节、自适应缩放、主题与灯箱
js/md.js             极简 Markdown 渲染（只为画板与原型服务，含围栏代码块）：每段文字带源码偏移，选区据此换算成 content 里的范围；高亮的合并与上限
js/ext-parts.js      网页模拟（含 X 时间线与文档页）、选区菜单与区块胶囊的零件
js/app-parts.js      应用壳（左导航 + 右内容）、列表、高亮分组、阅读视图、属性面板、抽屉、属性页、设置、导出与弹窗零件
js/sec-*.js          各章节与分组：overview · system · extension（拼装）· ext-flow（选区菜单、选区剪藏）· ext-block（区块剪藏）· ext-shot（截图、截图输出与精确选区）· ext-app（应用页、设置与弹窗）· ext-read（阅读与库内高亮）· journey · open
js/proto-*.js        两个可交互原型：proto-capture（页面内）· proto-app（资料库与阅读视图）
js/icons.js          由 tools/gen-icons.mjs 生成，来源 lucide-react 与 assets/icons/logo.svg
```

新增图标：在 `tools/gen-icons.mjs` 的 `ICONS` 里加 lucide 名称，再运行 `node docs/design/v2/tools/gen-icons.mjs`。

## 约定

- 文案、提问和示例只从 docs/v2 复制，不在这里另写一套；要改先改 docs/v2。
- **壳的规则在 docs/v2，数值在这里**：docs/v2 只写“所有页面都是左导航 + 右内容；窄窗口折叠为图标栏，不出现顶部导航”；导航宽度、抽屉宽度、阅读视图右栏宽度、断点和控件高度只在“设计系统 · 应用壳规格”画板里，落地后在首次使用走查里验证。
- 画板上的“提案”标签表示规则还没进入 docs/v2；目前没有这样的画板。新增的规则先登记到 [validation.md](../../v2/validation.md)，确认后才迁入真源，再回到这里画。
- 不为未进入路线图的能力提前画入口：选区菜单里没有高亮，页面里没有任何标记，高亮只在资料库里读剪藏时划出；精确选区与可重复的取景框（R3）排在阶段 V 之后，但画了目标体验，并标注 R3。
- 界面支持中文与英文：画板按中文界面绘制，选区菜单与导航提供中英文对照；字段名、实体名和文档里的概念名不变。
- 原型里的规则与 docs/v2 一致：属性名称与类型全局绑定、保留名与同名（不区分大小写）被拒绝、使用中的属性不能删除、类型预设决定新条目自动带上哪些属性；高亮的范围是 Markdown 源文本里的偏移，重叠的新选区合并，有高亮的剪藏原文只读，删除剪藏会连同高亮一起删除并先提示高亮数。
