# AnnHub v2 UX/UI 设计稿

> 更新时间：2026-10-07。状态：草案。设计依据是 [docs/v2](../../v2/README.md)；文案与规则以 docs/v2 为准，本目录只做视觉与交互表达。

覆盖 docs/v2 里涉及的全部界面：Chrome 扩展（采集、加工、检索与导出）。每块画板标注了依据的文档章节和交付版本，并附编号的交互说明。

## 怎么看

直接用浏览器打开 [index.html](index.html)，不需要构建（用到 `oklch()` 与 `color-mix()`，需要 Chrome / Edge 111+、Safari 16.4+、Firefox 113+）。也可以起一个静态服务：

```bash
python3 -m http.server -d docs/design/v2 4177
```

- 页眉的“标注”开关控制画板上的编号钉，“亮色 / 暗色”切换主题（网页模拟区始终保持亮色）。
- 悬停画板右上角可放大到 100%；加 `?solo=关键字`（匹配画板标题）或 `?solo=序号` 只渲染对应画板，方便逐块检查。
- 标有“可交互”的一块是原型：采集流程（选中文字 → 选区菜单 → 采集窗口）。

## 目录

```text
index.html          画布外壳
css/                tokens（令牌）· canvas（画布与规格表）· ui（基础件）· ext
js/data.js          kind 与样例碎片（文案取自 docs/v2）
js/ui.js, core.js   片段生成工具、画板 / 分组 / 章节、自适应缩放、主题与灯箱
js/sec-*.js         各章节与分组；ext-parts*.js 是共用零件
js/proto-capture.js 可交互的采集原型
js/icons.js         由 tools/gen-icons.mjs 生成，来源 lucide-react 与 assets/icons/logo.svg
```

新增图标：在 `tools/gen-icons.mjs` 的 `ICONS` 里加 lucide 名称，再运行 `node docs/design/v2/tools/gen-icons.mjs`。

## 约定

- 文案、提问和示例只从 docs/v2 复制，不在这里另写一套；要改先改 docs/v2。
- 当前没有标为“提案 · 文档未定义”的画板：设计稿提出的补充方案都已并入 docs/v2。以后再出现这种画板时，按 [docs/v2/AGENTS.md](../../v2/AGENTS.md) 需先进入 validation.md，确认后才迁入真源。
- 不为未进入当前版本的能力提前画入口：设备端模型、PDF 采集等都不在本稿内。R5 截图增强是应产品负责人要求补画的例外，只表达目标体验：R5.3 在阶段 V 之后排期，R5.1、R5.2 后置、以 H-14 为门槛。
- 输出工坊与关系确认已由 [D-10](../../v2/validation.md) 移出产品范围，桌面客户端与间隔复习已由 [D-17](../../v2/validation.md) 移出产品范围，本稿没有相关页面。此前的提案与文档不一致已并入 docs/v2（[D-12 ~ D-14](../../v2/validation.md)）。
