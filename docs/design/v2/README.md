# AnnHub v2 UX/UI 设计稿

> 更新时间：2026-10-07。设计依据是 [docs/v2](../../v2/README.md)；文案与规则以 docs/v2 为准，本目录只做视觉与交互表达。

覆盖 docs/v2 里涉及的全部界面：页面里的三种采集（剪藏、高亮、截图），以及扩展自己的应用页（资料库、属性、设置）和工具栏弹窗。三种采集是同一种“条目”，所以界面只有一套；**所有扩展页面都是左侧导航 + 右侧内容**，窗口再窄也只折叠为图标栏，不换成顶部导航。每块画板标注了依据的文档章节和交付版本，并附编号的交互说明。

## 怎么看

直接用浏览器打开 [index.html](index.html)，不需要构建（用到 `oklch()` 与 `color-mix()`，需要 Chrome / Edge 111+、Safari 16.4+、Firefox 113+）。也可以起一个静态服务：

```bash
python3 -m http.server -d docs/design/v2 4177
```

- 改过脚本或样式后请强制刷新：静态服务会让浏览器缓存 `js/`、`css/` 下的文件。
- 页眉的“标注”开关控制画板上的编号钉，“亮色 / 暗色”切换主题（网页模拟区始终保持亮色）。
- 悬停画板右上角可放大到 100%；加 `?solo=关键字`（匹配画板标题）或 `?solo=序号` 只渲染对应画板，方便逐块检查。
- 标有“可交互”的两块是原型，放在“浏览器扩展”章节最后，共用同一份内存数据（刷新即重置，不写入任何存储）：
  - **选中文字 → 剪藏 / 高亮 / 截图**：选区菜单、约 3 秒的“已剪藏 · 撤销 · 编辑”、快速编辑、高亮气泡（换颜色、备注、删除）。新剪藏会自动带上属性页里为“剪藏”勾选的预设。
  - **资料库（左导航 + 右内容）**：切换六个视图、折叠导航、搜索与按类型 / 标签 / 属性筛选、详情抽屉里改标题与备注、添加属性（补全已有的、选类型新建、保留名与同名被拒绝）、属性页（使用数、预设、删除未使用）、导出对话框。上一块原型里保存的条目会出现在这里。键盘也能走通：Tab 与 Enter / 空格操作，导航里 ↑ ↓ 切换，`/` 聚焦搜索，抽屉打开时焦点进入并在其中循环，Esc 依次关闭对话框、补全与抽屉并把焦点还给触发它的那一行。

## 目录

```text
index.html           画布外壳
css/                 tokens（令牌，含亮暗）· canvas（画布、规格表、标注钉）· ui（基础件）· ext（应用壳、页面内浮层、各页面与原型）
js/data.js           三种类型、六种属性类型、样例条目与属性注册表（文案取自 docs/v2），以及两个原型共用的 STORE
js/ui.js, core.js    片段生成工具；画板 / 分组 / 章节、自适应缩放、主题与灯箱
js/ext-parts.js      网页模拟与选区菜单零件
js/app-parts.js      应用壳（左导航 + 右内容）、列表、属性面板、抽屉、属性页、设置、导出与弹窗零件
js/sec-*.js          各章节与分组：overview · system · extension（拼装）· ext-flow（选区菜单、剪藏、高亮）· ext-shot（截图与精确选区）· ext-app（应用页与弹窗）· journey · open
js/proto-*.js        两个可交互原型：proto-capture（页面内）· proto-app（资料库）
js/icons.js          由 tools/gen-icons.mjs 生成，来源 lucide-react 与 assets/icons/logo.svg
```

新增图标：在 `tools/gen-icons.mjs` 的 `ICONS` 里加 lucide 名称，再运行 `node docs/design/v2/tools/gen-icons.mjs`。

## 约定

- 文案、提问和示例只从 docs/v2 复制，不在这里另写一套；要改先改 docs/v2。
- **壳的规则在 docs/v2，数值在这里**：docs/v2 只写“所有页面都是左导航 + 右内容；窄窗口折叠为图标栏，不出现顶部导航”；导航宽度、抽屉宽度、断点和控件高度只在“设计系统 · 应用壳规格”画板里，落地后在首次使用走查里验证。
- 当前没有标为“提案 · 文档未定义”的画板：设计稿提出的补充方案都已并入 docs/v2。以后再出现这种画板时，按 [docs/v2/AGENTS.md](../../v2/AGENTS.md) 需先进入 validation.md，确认后才迁入真源。
- 不为未进入当前版本的能力提前画入口。[D-18](../../v2/validation.md) 已把采集窗口、九种 kind、三步加工、AI 与设备端模型、截图美化与品牌（原 R5.1、R5.2）移出范围，本稿没有这些画板；精确选区（R3）排在阶段 V 之后，但画了目标体验，并标注 R3。
- 桌面客户端与间隔复习（[D-17](../../v2/validation.md)）、输出工坊与关系确认（[D-10](../../v2/validation.md)）已移出产品范围，本稿没有相关页面。
- 界面支持中文与英文（[D-15](../../v2/validation.md)）：画板按中文界面绘制，选区菜单与导航提供中英文对照；字段名、实体名和文档里的概念名不变。
- 原型里的规则与 docs/v2 一致：属性名称与类型全局绑定、保留名与同名（不区分大小写）被拒绝、使用中的属性不能删除、类型预设决定新条目自动带上哪些属性。
