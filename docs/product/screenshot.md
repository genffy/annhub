# 截图采集

> 层级：core
> 状态：采集链路
> 更新：2026-10-30

截图是 [采集链路](capture.md) 的视觉入口，保存为 `screenshot` 条目。页面交互见 [扩展 PRD](extension.md)，资产字段、事务和 ZIP 导出以 [存储契约](storage.md) 为准，条目字段见 [条目契约](entry.md)。

## 1. 用户路径

```text
快捷键、选区菜单，或区块胶囊里的“截图”
  -> 拖拽区域（可先选比例预设）/ 单击元素（吸附、微调、边距、选区确认，或沿用上次取景框）/ 滚动长图
  -> 原位预览并标注，检查匿名与马赛克；可选美化
  -> 确认后保存为 screenshot 条目；也可以复制到剪贴板，或按设置的格式下载
  -> 在资料库的“截图”视图查看，补标题、标签、备注与属性
```

从页面批注（[annotate.md §1.3](annotate.md)）里点“截图”进入时，页面上的墨迹按画下时的位置成为编辑器里的标注，和这里的其他标注一样可撤销、进入入库、复制与下载的图片。

快捷键为 `Ctrl+Shift+S`，macOS 为 `Cmd+Shift+S`。拖拽选择视口区域，单击选择元素；`Esc` 取消会话，截取之前 `A` 切换 DOM 匿名（§3）。区块胶囊里的“截图”以该区块为目标元素，直接进入元素截图的原位编辑。

### 1.1 选区内编辑

交互以微信截图的原位编辑方式为参考：进入模式后页面变暗；拖拽时选区保持明亮、显示蓝色边框和像素尺寸。截取完成后，图片直接占据原选区，不跳到居中预览卡片。浮动工具栏贴近选区右下角；空间不足时移到上方并约束在视口内。图的像素尺寸标在左上角外侧，上方没有位置或被工具栏占着时移到下方，再不行放进左上角内侧，工具栏不盖住它。元素截图也使用同一编辑界面，超出视口的元素按比例缩小预览，但保存完整像素。窄视口下工具栏可横向滚动，不能遮住确认和取消操作。

| 工具                         | 行为                                                                                                                    |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 矩形、椭圆、箭头、直线、画笔 | 在图片上拖拽标注；支持红、黄、青、白、黑色；直线与画笔可选线宽（见下）                                                  |
| 荧光笔                       | 在图片上拖拽涂出半透明的宽笔迹，盖住的正文仍读得清；同样的五种颜色，可选线宽（见下）                                    |
| 马赛克                       | 拖拽指定像素区域，预览立即显示处理结果                                                                                  |
| 文字                         | 在图片上单击输入，回车提交，`Shift+Enter` 换行                                                                          |
| 序号                         | 在图片上单击依次放下 1、2、3… 的数字徽章；可以拖动、删除，计数可以重置（见下）；支持同样的五种颜色                      |
| 撤销                         | 逐步撤销人工标注：画上或写下一个标注，放下、拖动或删除一个序号，重置计数，各算一步；自动建议的马赛克区域可以单独移除    |
| 美化                         | 打开美化面板（§4.4），背景、留白、圆角、阴影与输出比例；只作用于复制与下载                                              |
| 复制                         | 把当前结果以 PNG 复制到剪贴板（`Ctrl/Cmd+C`；焦点在文字输入框里时，它仍复制框里的文字），继续保留编辑会话；不需要先下载 |
| 下载                         | 按设置里的格式下载当前结果，继续保留编辑会话                                                                            |
| 取消、确认                   | 分别丢弃本次截图、保存当前结果为 `screenshot` 条目                                                                      |

荧光笔、直线与线宽用来标出重点：涂出一行正文，画一条分隔或连接的线，加粗一圈强调。

- **荧光笔**：随指针涂出宽笔迹，颜色的不透明度是 40%：盖住的文字与底色之间的反差保留六成，浅色与深色页面上都读得清（见 [D-34](validation.md)）。一笔之内来回涂、交叉的地方颜色不加深，两笔重叠的地方加深。荧光笔只画在截图上，和资料库里读剪藏时划的高亮（[entry.md §4](entry.md)）无关。
- **直线**：从按下处画到松开处，两端是圆头。按住 `Shift` 拖动时，直线落在经过起点的水平、竖直或 45° 斜线中最近的一条上，终点是指针在这条线上的位置（见 [D-35](validation.md)）。
- **线宽**：画笔、直线或荧光笔开着时，工具栏下方显示“线宽”的细、中、粗三档，默认中档。画笔与直线是 2、3、6 CSS 像素，中档和矩形、椭圆、箭头的线一样粗；荧光笔是 12、20、32 CSS 像素，中档盖得住一行常见的正文。三档都和其他标注的线宽、字号一样随设备像素比放大。三种工具共用一个档位，换工具不变；和颜色一样，每次截图从默认开始。矩形、椭圆、箭头的线宽固定（档位与范围见 [D-32](validation.md)、[D-33](validation.md)）。
- **撤销**：涂一笔荧光笔、画一条直线各算一步，和画笔一样；换线宽、换颜色不算。

荧光笔与直线和其他标注一样画进入库、复制与下载的图片，美化与水印照常加在复制与下载的图片上（§4）。它们和线宽都没有单键切换的快捷键。

序号按顺序指出图上的一处处地方，写教程、提反馈时用来标出操作步骤。序号工具开着时：

- **放下**：在图片上按下，下一个序号出现在指针处，按住可以挪动，松开处就是它的位置。序号整个落在图内，贴着边缘放时停在边上。
- **样子**：实心圆里写着数字。圆是所选的颜色，数字和圆的一圈描边用与它对比强的颜色：红、青、黑色的序号用白色，黄、白色的用深色，放在浅色、深色或同色的背景上都读得清。直径 28 CSS 像素，和其他标注的线宽、字号一样随设备像素比放大，不随图片大小变化；三位数时字号缩小，数字仍在圆内。
- **拖动与删除**：按住已有的序号可以拖动它，拖动不改变它的数字。单击或拖动过的序号被选中，编辑界面用蓝色圆圈和“×”标出它；点“×”，或按 `Delete`、`Backspace`，删除选中的序号，同一组里排在它后面的序号依次减一，不留空号。在图片上别处按下或换工具时选中取消；选中不是单独的一层，`Esc` 照常取消截图。蓝色圆圈和“×”不进入图片。
- **计数**：工具栏下方显示下一个序号的数字和“重置计数”。重置后下一个序号从 1 开始，之后放下的另成一组，已经放下的不变；下一个已经是 1 时不能重置。
- **撤销**：放下、拖动、删除一个序号和重置计数各算一步，撤销逐步退回。

序号和其他标注一样画进入库、复制与下载的图片，美化与水印照常加在复制与下载的图片上（§4）。标注工具都没有单键切换的快捷键，序号也没有。

取景时，窗口顶部的提示条说明手势与按键，并显示本次截图的匿名与水印状态，进入编辑后消失。截取之前 `A` 切换匿名；设置里启用了水印时，编辑界面里 `W` 切换水印，预览直接显示水印的有无。两者只影响这一次截图。

`Esc` 先关闭最里面的一层——文字输入框或美化面板——再次按下才取消截图。保存、复制或下载失败时保留图片与全部标注，允许重试。截图链路不做分享、翻译、表情，也不做多选区拼接；滚动长图只拼长度有限的整页纵向滚动（§1.5）；真实发布动作（如发布到社交平台）同样不进入扩展域，截图产物以本地入库、复制与下载为终点。给截图加背景、留白、圆角与阴影的美化见 §4.4。

### 1.2 精确选区

选区精度：拖拽时对光标下的元素边缘实时吸附并高亮提示，起止点可吸附到元素矩形；单击元素的路径里，悬停时按 `↑` 选上一级、`↓` 回到下一级（跳过外框与当前元素完全相同的层级），不必为了选中一个容器去瞄它的边缘；确认前选区显示八向手柄，支持拖拽二次调边；方向键微调 1 像素，配合 `Shift` 每次 10 像素。拖拽中按住 `Shift` 临时锁定当前比例，松开即解除。

选区确认：拖拽松开后选区保持可调——选区旁出现“确认选区 ↵ / 取消”，按 `Enter` 或点击“确认选区”后才进入原位编辑，`Esc` 取消会话。待确认时遮罩接住指针：点在选区里（没点到确认、取消或手柄，也没有正在悬停别的元素）不会落到页面上，确认条也不会因此消失。单击元素的路径不变，直接进入原位编辑——悬停选中的元素单击后即换成该元素，即使点落在待确认的选区里。

### 1.3 比例预设

框选区域时可以先选一个比例预设，选区被锁定为该比例。区域截图的选区条上列出“自由”和设置里启用的预设，点一个即锁定，再点“自由”解除；尺寸标签同时显示像素与比例，并带锁形图标。锁定后拖拽始终输出目标比例，选区被夹紧在视口内；单击元素的路径不受影响。

可选的比例是 1:1、4:5、3:4、4:3、16:9、9:16；设置里勾选哪些出现在选区条上，默认 1:1、4:5、3:4、16:9（[extension.md §2.5](extension.md)）。每次截图从“自由”开始，不记忆上一次的选择。预设只约束选区的形状，不预设像素大小：截多大取决于页面，输出始终是选区的真实像素。

### 1.4 可重复的取景框

同一个界面在不同状态下反复截图——切换套餐周期、主题、语言、数据——要求每张图的取景完全一致：同样的像素尺寸，同样的边距。手动拖拽做不到：每次起止点都差几个像素，三张图的尺寸各不相同（验证见 [market.md §4.5](market.md)）。取景框因此可以由元素定义，并且能原样再用：

- **元素 + 边距**：选中一个元素后，选区条上出现“边距”：0、8、16、24、32 CSS 像素，也可以输入数值；取景框 = 元素外框向四周各外扩这个边距，边距里是元素周围真实的页面。选哪个元素用 `↑` `↓` 在层级间移动（§1.2），例如从卡片里的价格行选到包含切换条与全部卡片的容器。
- **沿用上次取景框**：同一标签页、同一网页（来源与路径相同）里，确认入库、复制或下载之后，当前取景框被记下。下次进入截图时，它直接作为待确认的选区出现，标注“上次取景框 · 1248 × 700”，`Enter` 确认并进入原位编辑；拖拽或单击别处则换成新的取景框。进入截图时指针已经在悬停别的元素，这次不恢复它，记忆原样留给下一次。取消不更新它。记忆只存在这个标签页的这个网页里，导航到别的页面、关闭标签页或重启浏览器就清除，不写入条目、设置或导出。
- **取景框记的是元素，不是屏幕位置**：页面滚动了、窗口变了、内容刷新了，只要元素还在，取景框就跟着它走；沿用时页面自动滚动到让取景框完整落进窗口。找不到上次的元素，或找到的元素大小与上次相差超过 10% 时，沿用上次的页面位置与尺寸，并在选区上标明“没找到上次的元素”，由用户确认。自由拖出来的取景框没有元素，记的是页面位置与尺寸。
- **输出一致**：同一个取景框、同一个设备像素比，输出的像素尺寸相同——宽高由元素的宽高与边距决定，与元素在屏幕上的位置无关，取整规则固定；边距环里的像素一致。截取前等待页面稳定（连续两帧布局不变，最长 500 毫秒），扩展的遮罩一出现，页面的悬停样式随之清掉。
- **放不下**：取景框必须完整落在窗口里；放不下时，选区上提示“取景框比窗口大”，并给出两条出路：减小边距，或缩小浏览器的页面缩放。元素本身比窗口大时走元素路径，不含边距。
- 取景框里如果压着页面固定定位的浮层（客服挂件、吸顶导航），它们会像在页面上一样入图；预览里能看到。

### 1.5 滚动长图

把比窗口长的文章页拼成一张图，再进原位编辑器标注、打码、复制、下载与入库。

- **入口**：区域截图的选区条（比例预设那一行）上的“滚动长图”。点下后从当前的滚动位置开始往下拼，宽度是窗口里页面的可见宽度，不含滚动条（见 [D-42](validation.md)）；不先选列，也不套比例预设。
- **拼的过程**：页面自动往下滚，一屏一屏地拍，相邻两屏有一段重叠，按实际滚到的位置对齐，拼接处没有重复或缺失的条带。窗口顶部显示进度“3 / 12”；拍的那一刻进度和扩展的其他界面一起隐藏。浏览器每秒只允许截取两次，一篇十屏的文章要五秒以上。`Esc` 随时取消，已拍的部分丢弃、不入库。拼完、取消或中途停下后，页面滚回开始的位置。
- **吸顶与固定的元素**：导航栏、客服挂件这类钉在窗口上的元素只出现在第一屏，之后几屏里隐藏，不在长图里重复。滚动之后才钉住的元素（往下滚时缩成吸顶条的页眉）在每一屏拍之前重新找一遍，同样隐藏。
- **到哪里停**：到页面底部；或拍满 30 屏；或长图的像素面积到达上限，约 4000 万像素，Retina 屏上约九屏（见 [D-49](validation.md)）；或长图的高度到达浏览器画布单边的上限 65535 像素（[market.md §4.7](market.md)）；或再拼下去图片会超过入库上限（单张 10 MB，见 Q-03）；或拼到中途页面不再往下动，例如弹出了锁住滚动的对话框——这时保留已经拼好的部分进编辑器，并提示后面没有拼。页面在拼的过程中一直变长（无限滚动的列表），到达上限停下并提示。
- **还在加载的图片**：每一屏拍之前，等这一屏里还在加载的图片，最多 1 秒；到时没加载出来的照原样拍。
- **范围**：只拼整页的纵向滚动。内容在页面里另一个滚动区域中、整页不滚动时，提示这类页面拼不了，可以改用区域或元素截图；页面用脚本接管了滚动、第一次自动滚动之后页面实际没有动时，同样停下并提示。横向超出窗口的内容不拼，提示一句。浏览器的页面缩放是多少都可以拼：和区域截图一样按设备像素比换算，拼接处按实际像素对齐；拼的过程中页面缩放变了或被双指放大，停下并提示重新开始；开始前已经用触控板或触屏双指放大过的页面（只放大画面、不改排版）不开始，提示先恢复原大小。
- **拼完之后**：长图进入原位编辑器（§1.1），标注、马赛克、美化、复制、下载与入库照常；比窗口高的长图在预览里按比例缩小，保存完整像素，和元素截图一样。匿名（§3）对每一屏都生效。
- **带着页面批注**：从页面批注（[annotate.md §1.3](annotate.md)）进入时，墨迹固定在屏幕上，按开始那一刻的屏幕位置画在长图最上面的一屏里，和区域截图一样成为编辑器里的标注。
- **断网时**：照常拼接、编辑与入库，都在本机完成；滚到才开始加载的图片可能加载不出来，照原样拍。

## 2. 截取与像素处理

区域路径使用 `captureVisibleTab({ format: 'png' })` 获取真实视口像素。选区是视口 CSS 坐标，裁剪时按 `devicePixelRatio` 转源像素，夹紧到源图边界；零面积选区报错，不保存空文件。调用浏览器截图 API 前隐藏扩展遮罩和预览 UI，等待两帧完成重绘，避免把扩展界面拍入图片。浏览器每秒只允许截取两次；紧接着前两张截的那一张等这一秒过去再拍，不报失败。

元素路径在离屏 surface 中克隆目标元素并栅格化，可覆盖超出视口的元素。克隆先执行匿名；跨域图片由扩展后台代取并内联，字体嵌入失败时跳过字体重试。视频帧与滚动位置不是样式、样式拷贝带不过来：克隆里的 `<video>` 换成截取时正播放画面的图片（受跨域保护、画布读不回的视频只截取视口内可见的部分），滚动的容器（多图轮播）按滚动后的窗口重建——窗口外的内容原地隐藏，窗口内的平移到滚动显示的位置。surface 在成功、失败和取消时都要移除。元素资源缺失可能影响结果，预览必须让用户检查最终图片。

截图会话跑在页面里，页面自己的脚本能派发任何事件，所以会话只听用户本人的输入和扩展自己的触发：脚本伪造的点击、拖拽、按键和自定义事件既不能启动会话，也不能选区、切换匿名、切换水印、复制或取消。区域截取只拍发起截图的那个标签页，并且只在它仍是所在窗口里显示着的标签页时；其他标签页或窗口里的页面不能借扩展拍到用户正在看的内容，截取期间用户切走了标签页就丢弃图片。后台代取跨域图片只接受公网的 http(s) 地址，拒绝本机、局域网、链路本地和带账号的地址，不带凭据，只接收不超过入库上限的图片；不符合的资源保留原地址，由页面自己尝试加载。截图界面里的像素对页面自己的脚本可见，这一残余风险见 [RK-14](validation.md)。

默认使用 PNG 保存文字与图表细节。区域和元素在同一个选区内编辑界面执行标注与像素马赛克；编辑期间保留会话内的原始截取画布，并按操作顺序重绘，使撤销可靠。区域截图的分辨率以屏幕 `devicePixelRatio` 为上限；元素截图已按 2 倍像素比栅格化。入库的是**裁剪、匿名、马赛克和标注之后的图片字节**，不保留未处理的屏幕原图，也不把编辑操作另存为附件。缩略图可从持久图片重建。滚动长图的拼接见 §1.5。

## 3. 匿名与预览

DOM 匿名默认开启。区域截图在真实页面的身份元素上临时覆盖占位，截取后恢复；元素截图只修改离屏克隆。X/Twitter 使用稳定 `data-testid` 识别身份元素，通用页面可通过 `data-ann-identity` 标记。自动检测只提出候选区域，用户在预览中可以增加或删除马赛克框。

身份元素分两种：头像，名字与账号（X 上是显示名与 @账号）。设置里分别勾选遮住哪些，默认两种都遮；没勾选的一种原样入图，关掉匿名时也不为它预填马赛克框。通用页面上 `data-ann-identity="avatar"` 标记头像，其余的 `data-ann-identity` 算名字与账号。

匿名的默认值与范围对每一种进入方式都生效：快捷键、选区菜单交来的取景框、区块胶囊与区块模式的截图都按设置截取。截取之前——包括待确认的取景框——`A` 切换本次是否匿名；两种都没勾选时没有可遮的东西，提示条不显示 `A`。

马赛克在最终像素上按块平均处理，块边界和设备像素比由同一纯函数计算。关掉自动匿名不等于关闭手工马赛克。截图处理默认全在本地，临时跨域资源只为当前元素栅格化，不写入记录或日志。

## 4. 保存与输出

一次截图有三种去处，互相独立：确认入库、复制、下载。资料库的“截图”视图可查看、重新下载和删除已入库的截图。

### 4.1 入库

确认入库时，在扩展 IndexedDB 的 `assets` 与 `entries` object store 中同事务保存处理后的 `Blob`、图片元数据和 `screenshot` 条目。保存失败不能显示成功，也不能仅因下载或复制成功就声称已入库；单独下载或复制失败不回滚已经成功的本地入库。入库统一使用 PNG 保持文字与图表细节，**入库的图片不带水印**：水印是对外分享时的署名，不是资料的一部分。从资料库重新下载得到的就是入库的图片。

`screenshot` 条目：`content` 为空串，`assetId` 指向刚保存的图片，`sourceUrl` 取所截内容自己的永久链接，解析不到时用采集页面的地址（[capture.md §5](capture.md)）；`title` 默认取页面标题，用户可以补标题、标签、备注与属性（字段见 [entry.md §3](entry.md)）。

### 4.2 复制与下载

复制与下载输出的都是**当前结果**：裁剪、匿名、马赛克与标注之后的图片；设置里启用了水印、且本次没有关掉时，再加上水印（§4.3）。

- **复制**：把图片以 PNG 写入剪贴板，可以直接粘贴到文档、聊天或设计工具。浏览器的剪贴板只可靠支持 PNG，所以复制与下载格式的设置无关。复制发生在用户在页面里的点击或按键之后，由页面里的脚本直接写入，不需要额外权限（[permissions.md §4](permissions.md)）。页面是 `http:` 时浏览器不开放剪贴板接口，复制按钮改为提示“此页面不允许复制，请下载”，下载照常可用。
- **下载**：格式取自设置——PNG（默认）、JPEG、WebP；JPEG 与 WebP 有质量（默认 0.9）。JPEG 不支持透明，透明处铺白色。文件名为 `AnnHub/screenshot-<本地时间>.<扩展名>`，扩展名随格式（与导出文件名的日期同为本地的口径，[storage.md §6](storage.md)）。格式与质量只作用于下载，不改变入库的字节。

### 4.3 品牌水印

署名用的水印，画在复制与下载的图片的一角，设置里启用后才出现（[extension.md §2.5](extension.md)）：

- **内容**：文字（至多 40 个字符，如账号名）、图片（PNG，不超过 512 KB，只保存在本机的偏好里，不进入条目，也不随导出）；可以只启用其中一种，也可以同时启用，图片在前、文字在后。
- **样式**：位置在四角里选（默认右下）、大小分小、中、大，透明度 20% 至 100%（默认 70%）。文字的墨色随它落在的背景在深浅之间切换（深色背景上用浅色字），任何背景上都读得清；图片按原样画出，不随背景换色；图片与文字共用同一个透明度。
- **排版**：图片与文字排成一行，不论在哪个角都自左向右读——图片在左、文字在右，两者之间隔半个字号——整行贴着所选的角，离相邻的两条边各留一段边距。大小同时定文字的字号和图片的高度：图片高度是字号的 1.5 倍，宽度按图片自己的比例；只有图片没有文字时，大小同样定图片的高度；很宽的图片收窄到不超过画布宽度的 40%。
- **预览**：编辑界面里显示水印，位置不可拖动；`W` 关掉或恢复本次的水印。
- **层次**：水印画在最上一层，不参与匿名与马赛克，也不是标注，不进撤销栈。

### 4.4 美化

给复制与下载的图片加上背景、留白、圆角和阴影，让截图能直接放进文章、聊天或幻灯片。美化是输出样式，不是资料的一部分：**入库的图片保持原样**（与水印同理），编辑界面里能预览合成后的样子。

- **入口**：工具栏上的“美化”按钮打开面板；面板贴在预览旁边，不盖住预览与工具栏，也不出窗口。面板里的改动立即预览，只影响本次截图，“复原”回到默认样式（输出画布比例回到“自由”）。设置里决定默认是否开启，以及面板的初始样式（[extension.md §2.5](extension.md)）。
- **控件**：每个控件只有一个名字。背景按名字区分，不用字母或数字编号；阴影是一个名为“阴影”的开关。改动任何一项都同时开启美化，让改动立刻看得见。键盘进入面板后落在它的第一个控件上，`Esc` 先关闭面板、焦点回到“美化”按钮。
- **参数**：

  | 参数         | 取值                                                                      |
  | ------------ | ------------------------------------------------------------------------- |
  | 背景         | 无、纯色 2 款（纯白、米色）、渐变 5 款（紫、蓝、绿、暖橙、深灰），共 8 款 |
  | 内边距       | 小 24、中 40、大 64（CSS 像素，随设备像素比放大）                         |
  | 圆角         | 0、12、24（CSS 像素）                                                     |
  | 阴影         | 开、关                                                                    |
  | 输出画布比例 | 自由，或比例预设里启用的比例（§1.3）                                      |

- **合成**：截图内容等比、完整地放在画布中央，不裁切；“自由”时画布 = 内容 + 内边距；选了比例时，在内边距之外把画布补足到目标比例，留白画在背景上。水印画在最终画布的一角（§4.3）。背景为“无”时画布透明，JPEG 下载铺白色。
- **预览**：预览在选区周围长大，超出视口时按比例缩小，工具栏随之移动，始终在窗口内、不盖住图；复制与下载仍是完整像素。参数是即时状态，重绘自会话里保留的原始截取画布，不进撤销栈。带着美化的预览上继续标注，标注落在指针指到的位置，入库的图片仍是不带美化的截取。
- **不做**：设备外框、模板、文案卡与自动平衡（[product.md §2.3](product.md)）。

### 4.5 导出

扩展的唯一用户导出是 Markdown + 已保存原图 ZIP（[storage.md §6](storage.md)）。`screenshot` 条目有自己的 Markdown，图片以相对链接指向同一份文件。只下载到系统目录、没有入库的文件不由扩展 ZIP 扫描或重新抓取。

## 5. 失败与清理

| 情况                                                                                               | 处理                                                                               |
| -------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 页面不允许截图、无活动标签页或图片解码失败                                                         | 预览显示可读错误，保留取消入口，不写入记录                                         |
| 选区超界或面积为零                                                                                 | 在裁剪阶段拒绝，并允许重新选择                                                     |
| 元素中的跨域资源或字体失败                                                                         | 尝试本地降级，在最终预览中让用户检查缺失内容                                       |
| IndexedDB 配额、图片写入或校验失败                                                                 | 保留当前预览供重试；不显示保存成功；配额不足时说明先导出内容、再删除不需要的条目   |
| 复制失败（页面是 `http:`、剪贴板被拒或无焦点）                                                     | 显示可读错误并保留图片与全部标注，给出“改为下载”；不影响已完成的编辑               |
| 水印图片损坏或读不出来                                                                             | 本次不加图片水印，文字水印照常；设置页提示重新上传                                 |
| 取景框比窗口大                                                                                     | 选区上提示，给出“减小边距”与“缩小页面缩放”；元素本身比窗口大时走元素路径，不含边距 |
| 找不到上次的元素                                                                                   | 沿用上次的页面位置与尺寸，选区上标明，由用户确认或重新选择                         |
| 编码为 JPEG 或 WebP 失败                                                                           | 改为 PNG 下载，并提示                                                              |
| 滚动长图：页面用脚本接管滚动，第一次自动滚动后没有动                                               | 停下，提示这类页面拼不了，可以改用区域或元素截图                                   |
| 滚动长图：内容在页面里另一个滚动区域中                                                             | 提示这类页面拼不了，可以改用区域或元素截图                                         |
| 滚动长图：拍满 30 屏、到达像素面积或画布高度的上限、页面一直变长、超过入库上限或拼到中途不再往下动 | 保留已经拼好的部分进编辑器，提示后面没有拼                                         |
| 滚动长图：拼的过程中页面缩放变了，或页面被双指放大                                                 | 停下或不开始，丢弃已拍的部分，提示恢复后重新开始                                   |
| 滚动长图：取消                                                                                     | 丢弃已拍的部分，不入库，页面滚回开始的位置                                         |
| 删除 `screenshot` 条目                                                                             | 同一事务删除条目及其图片                                                           |

上表里“可读错误”都是本地化的短句，依据后台返回的稳定错误码生成（写入类错误码见 [entry.md §6](entry.md)；截取、代取图片和下载失败各有自己的码）；界面不显示浏览器或后台的原始信息。

退出会话时清理遮罩、离屏 surface、临时样式和监听器；重复触发先结束旧会话。完整的清理规则见 [storage.md §7](storage.md)。

## 6. 验收与测试

- 单测覆盖 CSS 坐标与 dpr 换算、边界夹紧、零面积、马赛克边界块和 alpha、身份元素检测、DOM 匿名恢复与元素克隆清理。
- 单测覆盖比例锁定的选区几何（各比例、视口边缘夹紧）、水印布局（四角位置、边距、三档大小、透明度；图片与文字同排、只有图片、过宽的图片）与读不出来的图片被跳过而文字照常、JPEG 的透明处铺白与 WebP 的质量参数。
- 后台能力测试覆盖可视区域截取、跨域资源代取、保存失败与下载/入库结果区分；截取只对发起的可见标签页、代取拒绝私有网络与非图片响应，是必测边界。
- 页面脚本伪造的事件（自定义事件、点击、拖拽、按键）不能启动或推进截图会话，也不能触发复制或切换水印，由单测和 E2E 共同覆盖。
- E2E 覆盖区域拖拽、元素单击、遮罩不入图、预览马赛克、匿名开关、取消清理和 SPA 页面。
- 编辑器 E2E 覆盖选区原位预览与尺寸标签、工具栏贴边与视口约束、矩形和文字落图、马赛克预览、撤销、下载后继续编辑、确认入库与失败后保留画布。
- 荧光笔、直线与线宽的单测覆盖三档线宽的像素与随设备像素比放大、荧光笔 40% 的不透明度与一笔只描一次、直线按住 `Shift` 落在最近的水平、竖直或 45° 斜线上；E2E 在白底黑字的夹具上读像素：五种颜色的荧光笔盖住的纸与字都取 40% 的颜色、字保留六成反差，一笔来回涂不加深、两笔重叠加深；直线落在按下与松开之间，按住 `Shift` 水平、竖直或沿 45°，单击不画；三种工具的三档线宽在 1x 与 2x 下都量得出规定的像素，线宽按钮能用键盘选、换工具不变；每一笔都能撤销，在预览、三种格式的下载、剪贴板、带美化与水印的图片和入库图片上都在，下载或保存失败后都还在，重试成功。
- 序号的单测覆盖编号（放下递增，拖动不改，删除后同一组依次减一，重置后另成一组）、命中与贴边、大小随设备像素比、五种颜色的数字与填充的对比；E2E 放下三个、拖动一个、删除一个（`Delete` 与“×”）、重置计数，每一步都能撤销，并在预览、三种格式的下载、剪贴板、带美化与水印的图片和入库图片的像素上验收序号的位置与颜色；下载或保存失败后序号都在，重试成功。
- 输出 E2E 覆盖：https 页面上点击“复制”后剪贴板里是 PNG，`http:` 页面给出提示并仍可下载；三种下载格式的扩展名与内容类型正确；启用水印后复制与下载的图片带水印而入库的图片不带，`W` 同时关掉图片与文字且只关掉本次；水印图片在预览、剪贴板、下载与入库图片的像素上验收：图片在前、文字在后，随位置、大小、透明度与背景明暗变化，读不出来的图片被跳过而文字照常；设置页修改格式、水印与比例预设后下一次截图生效；比例锁定下拖拽始终输出目标比例。
- 资产测试覆盖 Blob 与条目同事务、重启后读取、删除条目时图片同事务删除，以及 ZIP 的图片相对链接。
- 美化的单测覆盖合成几何纯函数（各比例的画布尺寸与内容位置、内边距、圆角、阴影不改变内容尺寸）与面板的摆放、控件的名字和上报；E2E 在预览、剪贴板和入库图片的像素上验收：面板不盖住预览与工具栏、`Esc` 先关面板，每个控件只有一个名字，八款背景各画成它自己的颜色（渐变从第一色到末色），内边距、圆角、阴影与各比例下内容完整居中，水印随背景明暗换色，改动即开启、复原回到默认样式，带美化的预览上标注落在指针处，复制得到带美化的图而入库的图片保持原样。
- 精确选区的 E2E 覆盖选区吸附高亮、方向键微调、`Shift` 锁定比例、选区确认与元素层级选择（`↑` `↓` 跳过外框相同的层级）。
- 可重复的取景框用一个带切换条的夹具页验收：三种状态下，元素 + 24 CSS 像素边距的输出尺寸完全相同、边距环里的像素无差异；中间滚动页面或改变窗口大小后沿用上次取景框，框住的仍是同一块内容；元素找不到时给出提示并沿用位置与尺寸。记忆的范围同样验收：刷新、换查询或片段之后仍沿用，另一个标签页里没有，导航到别的页面（包括页面在原地改路径）或关闭标签页之后清除。
- 滚动长图的单测覆盖每一屏按实际滚动位置落点、重叠、各个停止条件（到底、30 屏、像素面积上限、画布高度上限、入库上限、一直变长、第一次滚动没有生效、拼到中途不再往下动、拼的过程中缩放变了、双指放大）、设备像素比不是整数（1.25、2.2）时拼接处不错一像素、宽度不含滚动条；E2E 在带吸顶导航与懒加载图片、五屏高的夹具页上拼长图：吸顶导航只出现一次，拼接处没有重复或缺失的条带，`Esc` 取消后不入库、页面滚回原位，拼好的图可以标注、复制、下载与入库；从页面批注进入时，墨迹落在长图最上面一屏的对应位置；到达像素面积上限的长图上画标注、打马赛克仍然跟手。
