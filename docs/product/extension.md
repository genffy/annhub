# 浏览器扩展 PRD

本文定义浏览器扩展的产品职责、信息架构、交互流程、状态和验收标准。DOM 与消息实现见根目录 `AGENTS.md`。

## 1. 产品职责

Extension 只负责四件事：

1. 在原始网页中指认内容：选中文字、指向一个区块（帖子、代码块、一节、整篇文章等），或框选画面。
2. 保留来源，保存为统一的条目：剪藏或截图。网页上不留任何标记。
3. 让用户在资料库里阅读剪藏并划出高亮、整理属性、检索，并随时导出。
4. 讲解网页时，在当前标签页上临时批注，再截进截图编辑器；或把当前标签页录成本地视频（[annotate.md](annotate.md)）。批注退出即清除，不留在网页上；录屏只下载到本机，不进资料库。

Extension 不提供通用笔记编辑器。

## 2. 信息架构

### 2.1 页面内入口

用户选中文本后显示选区菜单：

| 操作（中文 / English） | 图标       | 结果                         |
| ---------------------- | ---------- | ---------------------------- |
| 剪藏 / Clip            | `bookmark` | 一次点击保存选中的内容和语境 |
| 截图 / Screenshot      | `scan`     | 进入区域或元素截图           |

顺序固定为剪藏、截图。菜单必须使用图标加短文本，不依赖位置测试。**菜单里没有高亮**：高亮在资料库里读剪藏时完成（第 4.2 节）。选区菜单在选区形成后出现，不设最短长度：鼠标拖选或键盘选择（`Shift` 加方向键）停下后同样出现，选区全是空白时不出现；键盘上用 `Tab` 在两项动作间移动，`Enter` 触发。

菜单是一枚深色浮条，浮在页面内容之上，不随系统外观切换：每个动作是图标加名词，图标带各自类型的色相，两项之间有一条细分隔线；菜单带一个指向选区中点的小三角，键盘焦点是动作上的内描边。

```text
选中文本后，在选区旁出现：
┌────────────────────────────────────────┐
│ [bookmark] 剪藏 | [scan] 截图          │
└────────────────────────────────────────┘
```

悬停或键盘聚焦约 300ms 后，浮出一枚深色后果卡片：第一行是动作名，第二行一句后果，让两种保存方式的差别在入口就看得见（[US-CAP-01](user-stories.md)）。卡片在菜单的外侧——菜单在选区上方时它在菜单上方，菜单翻到选区下方时它跟到菜单下方——与菜单左缘对齐，没有箭头；视口边缘放不下时把卡片夹回视口内，不翻到选区那一侧去盖住选区。它是纯浮层：菜单始终只有一行按钮，不因提示变高、也不给按钮下面留空白；指针移开或失焦即消失。

| 动作 | 提示（中文）                           |
| ---- | -------------------------------------- |
| 剪藏 | 保存选中的内容，之后在资料库里读和高亮 |
| 截图 | 框选区域或单击元素 · 保存为图片        |

**区块剪藏入口**：没有选区时，指针在一个区块上停下约 400ms，区块出现描边，旁边出现胶囊：四个只带图标的按钮（剪藏、截图、下载、更多），名称在悬停提示与读屏名称里；点一次“剪藏”保存整块，不需要选中任何文字，“截图”则以这个区块为目标进入截图编辑，“下载”把这一块取成本地的 Markdown 文件夹（[download.md §2.1](download.md)）。悬停始终指向最内层的区块，胶囊上没有换层级的按钮。区块指帖子、代码块、表格、图、引用、一节或整篇文章，识别规则、胶囊的位置和键盘模式见 [capture.md §6.2](capture.md)。入口只是扩展自己的浮层，不改动网页，也不在页面上留下“已剪藏”的记号。默认开启，设置里可整体关闭，也可在胶囊的“更多”里按网站停用。

**页面批注入口**：工具栏弹窗里的“在页面上批注”，或用户自己绑定的快捷键（第 7.1 节），打开当前标签页上的批注层；画法、截图与退出见 [annotate.md §1](annotate.md)。选区菜单和区块胶囊里没有这个入口。

**同源 iframe 里只提供剪藏**：选区菜单只有“剪藏”，区块胶囊没有“截图”，区块模式没有 `S`；截图属于顶层页面（[capture.md §3](capture.md)）。

英文界面使用对应的英文译文，语言选择见第 2.7 节。

### 2.2 应用页：左导航 + 右内容

**所有扩展页面都是“左侧导航 + 右侧内容”**：资料库的各个视图、阅读视图、属性页、设置页和工具栏弹窗共用同一套壳，导航在所有页面里位置与顺序一致。不使用顶部导航；窗口变窄时导航折叠为左侧的图标栏，而不是换成顶栏。

```text
┌────────────────────────┬──────────────────────────────────────────────────────────┐
│ AnnHub             [«] │ 全部                   [搜索条目...                    ] │
│                        │ 类型 v  来源 v  标签 v  时间 v  属性 v      共 95 条     │
│ [library]  全部    95  ├──────────────────────────────────────────────────────────┤
│ [bookmark] 剪藏    71  │ ┌────────────────┐ ┌────────────────┐ ┌────────────────┐ │
│ [highlighter] 高亮 33  │ │Retries can     │ │Exponential     │ │（缩略图）      │ │
│ [scan]     截图    24  │ │amplify an ou...│ │backoff spre... │ │                │ │
│                        │ ├────────────────┤ ├────────────────┤ ├────────────────┤ │
│ ────────────────────── │ │Retry budgets   │ │Backoff, jitter │ │p99 延迟曲线    │ │
│ [tags]     属性     9  │ │#reliability    │ │#retry          │ │                │ │
│ [settings] 设置        │ │[剪藏] 3 天前   │ │[剪藏] · 3 高亮 │ │[截图] 周二     │ │
│                        │ └────────────────┘ └────────────────┘ └────────────────┘ │
│ [download] 导出内容    │                                                          │
│ 已用 126 MB            │                                                          │
└────────────────────────┴──────────────────────────────────────────────────────────┘
```

| 导航（中文 / English） | 路由            | 内容                     |
| ---------------------- | --------------- | ------------------------ |
| 全部 / All             | `#/all`         | 剪藏与截图的统一列表     |
| 剪藏 / Clips           | `#/clips`       | 只含剪藏                 |
| 高亮 / Highlights      | `#/highlights`  | 所有高亮，按所属剪藏分组 |
| 截图 / Screenshots     | `#/screenshots` | 只含截图，画廊           |
| 属性 / Properties      | `#/properties`  | 属性注册表               |
| 设置 / Settings        | `#/settings`    | 偏好、数据、本地指标     |

- 应用页只有一个 HTML，用 hash 路由；浏览器的扩展“选项”入口打开同一页面的 `#/settings`。
- 导航顶部是标识与折叠按钮；导航项分「资料库」「管理」两组，各带分组小标题（折叠成图标栏时隐藏）。类型视图的图标用各自的类型色。当前视图用底色、加粗和左侧竖条标出，不只靠颜色；计数右对齐、等宽数字。
- 导航上的数字：全部是条目数（剪藏加截图），剪藏、截图是各自的条目数，**高亮是高亮的条数**，属性是注册表里的属性数。
- 导航底部三块：存储用量（数值加进度条）、“导出内容”描边按钮（唯一的导出命令，[storage.md §6](storage.md)）和截图快捷键提示（键帽样式，跟随浏览器里的实际绑定）。点“导出内容”打开导出对话框：准备态说明 ZIP 包含与不包含的内容；点“导出 ZIP”开始导出，进行中显示进度，此时对话框不能关闭——导出一旦开始就会完成；结束后以横幅给出结果（完整、部分导出并写明缺失图片数、或失败原因），导航底部同时保留最近一次结果的提示。设置只通过导航进入，不在别处重复。
- 导航可折叠为图标栏：窗口宽度不足时默认折叠，导航顶部的按钮随时可以手动折叠与展开；手动折叠会被记住，窄窗口里的展开只对本次访问有效。折叠后只剩品牌标识、带文字提示的导航项图标和导出图标按钮，计数与分组小标题收起；当前视图仍有底色与竖条。具体宽度与断点见[设计稿](../design/README.md)。
- 每个页面从页头开始：标题、标题下的副标题计数，右侧是列表视图的搜索框；筛选条在页头之下。副标题说明这个视图装着什么：「全部」是“N 条 · N 剪藏 · N 截图”，“剪藏 / 截图”是“N 条”，“高亮”是“N 条 · 来自 N 条剪藏”；有筛选或搜索时是“筛选后 N 条”，数字取当前结果。
- 每个页面的标题与内容左缘一致，各页保留自己的最大宽度；引导卡与空状态限制行宽以保证可读，卡片网格与属性表占满内容区。
- 内容区随窗口自适应：四个列表视图（全部、剪藏、高亮、截图）都由卡片组成，铺满内容区；卡片有最小宽度，列数随窗口宽度增减，窄窗口里只剩一列。
- 当前视图、筛选条件、抽屉里打开的条目和阅读视图都写入 URL hash，刷新后恢复。

### 2.3 视图

- **筛选条**（四个列表视图共用）：每个维度一枚按钮（图标、名称、下箭头），点开弹层选择；已生效的条件在按钮旁显示为高亮芯片（图标、描述、移除叉），芯片主体重新打开该维度的弹层。弹层里类型与颜色是选项列表，来源与标签可搜索，时间是日期范围；属性弹层先选属性，运算符由属性类型决定。“全部”有类型维度，“高亮”多一个颜色维度，剪藏与截图没有类型。筛选条行尾是“共 N 条”，有生效条件时再有“清除筛选”。同一维度 OR、跨维度 AND，条件写入 URL；口径见 [search.md](search.md)。
- **全部 / 剪藏 / 截图**：条目排成卡片网格。卡片上部是预览，剪藏是正文的前几行（Markdown 去掉语法后的文字），截图是缩略图，所有卡片的预览一样高；高宽比达到 2 的截图从顶部裁切铺满预览框，而不是整张缩成一条细缝。下部是标题（最多两行）、标签与自定义属性小标签（同一行内换行），最后一行是类型徽标、来源主机（超长省略）与相对时间，有高亮的剪藏多一枚“N 高亮”小标签。同一行的卡片一样高，最后一行对齐。属性小标签显示条目已有的自定义属性值：按属性页的顺序最多两枚，复选框只在为真时出现，值过长省略。悬停时卡片边缘转品牌色，键盘焦点画在卡片上，抽屉里打开的那一张用品牌色描边。
- **截图**：与“全部”相同的卡片网格（画廊）；指针悬停或焦点进入卡片时出现“下载图片”与删除（选择模式里隐藏）。
- **选择**（全部、剪藏、截图三个视图的页头）：进入选择模式后，筛选条的位置换成选择条（同高，卡片不动，列表滚动时固定在顶部），卡片带上选中标记，点击切换选中、不打开抽屉；搜索与筛选在选择中不可用，切到别的视图会退出并清空选择。规则与键盘见 [download.md §3.2](download.md)。
- **高亮**：以高亮为单位，按所属剪藏分组，每组是一张卡片，卡片沿列自上而下排开，列宽与条目卡片相同。卡片头是剪藏标题（窄卡时独占一行）、来源主机、条数小标签“N 条”和“回到来源”链接（不折行）。每条高亮左侧是它自己的颜色条，然后是引文、备注行（备注图标加文字）和元信息行（相对时间，加上所属剪藏的标签与属性小标签）；整条可点，在阅读视图里定位到它。筛选条有颜色、来源、标签、时间和属性，其中来源、标签、属性按所属剪藏计算。
- **翻页**：条目卡片每页 50 张（[search.md §4](search.md)）。还有下一页时，列表底部是“显示更多（还有 N 条）”按钮，每次在列表末尾追加一页，焦点落在新增的第一张卡片；顶部的条目总数始终显示。
- 点击一条条目打开右侧的详情抽屉（第 4 节）。
- 不展示“收藏数”之类的成就指标。

### 2.4 属性页

属性注册表的管理界面，借鉴 Obsidian Web Clipper 的属性类型表（[market.md §4.2](market.md)）。页头是标题“属性”与副标题“N 个属性 · 内置 N · 自定义 N”，右侧是“删除未使用（N）”（N 为 0 时禁用，点击前先列出将被删除的名称）与“添加属性”。表格上方一条说明：名称与类型全局绑定；使用数为 0 才能删除；已被使用的属性不能改类型，也不提供重命名。

表格一列一个字段，表头写列名，使用数右对齐：

| 列          | 内容                                                                                                                      |
| ----------- | ------------------------------------------------------------------------------------------------------------------------- |
| 名称        | 类型图标 + 名称；`title`、`tags` 置顶并锁定，标“固定”                                                                     |
| 类型        | 类型名：文本、列表、数字、复选框、日期、日期时间                                                                          |
| 默认值      | 新条目附加该属性时使用的初值，可空（空显示为“—”）                                                                         |
| 使用数      | 带有该属性值的条目数                                                                                                      |
| 剪藏 / 截图 | 各放一个复选框：采集该类型时自动附加；`title`、`tags` 固定勾选且置灰                                                      |
| 操作        | 删除：使用数为 0 且非内置才可用；不可用时灰显且中性着色，旁边写明原因——可见处是短词（内置、使用中），整句供读屏朗读与悬停 |

- 新建属性：表格末尾展开的表单——名称（从注册表补全）、类型（六个类型的选择器）、可选默认值（按类型出现不同控件）、剪藏 / 截图预设，取消或保存。校验按 [entry.md §5.3](entry.md)，错误就地显示在名称输入下方，名称为空或有错时保存禁用。
- “删除未使用”一次清理使用数为 0 的自定义属性。
- 使用中的属性不可改类型，也不提供重命名（[entry.md §5.3](entry.md)）。

### 2.5 设置页

页头是标题“设置”与副标题“偏好只保存在本机”。内容是两列卡片（窄窗口变一列）：左列偏好、截图输出、下载、品牌水印、美化；右列录制、快捷键、数据、本地指标。每张卡片是同一套语法——标题、可选的一句说明、一行一项（名称 + 说明在左，控件在右），控件全部是原生表单控件加样式：开关是带 `role="switch"` 的复选框，可访问名称是它控制的功能名；分段控件（下载格式、水印大小、美化的内边距与圆角、录制光标的形状）、四角的水印位置和美化的八个背景色块都是单选组，方向键可选；滑块拖动中只改本地值，松开或失焦才保存。

- **偏好**：
  - 默认高亮颜色（阅读视图里新建高亮的初始颜色）。
  - 区块剪藏入口：开关（默认开）和已停用的网站（行右侧是数量，列表缩进在行下，可逐个移除）。
- **截图输出**：默认是否匿名，以及遮住哪些身份元素——头像、名字与账号，可分别勾选，默认都遮（[screenshot.md §3](screenshot.md)）；**下载格式**——PNG（默认）、JPEG、WebP，JPEG 与 WebP 有质量（默认 0.9，PNG 无损，滑块仍在但禁用）；**比例预设**——勾选哪些比例可选，选区条的“裁剪比例”与美化面板的“输出画布比例”共用这一份，可选 1:1、4:5、3:4、4:3、16:9、9:16，默认 1:1、4:5、3:4、16:9。截图输出的规则见 [screenshot.md §4](screenshot.md)。
- **下载**：Markdown 下载的默认形态——文件夹（默认）或 ZIP，以及“同时下载媒体”开关（默认开，取消后只写 Markdown、媒体保留原地址）；形态旁写明：浏览器设置了“下载前询问每个文件的保存位置”时，文件夹形态会逐个弹出保存对话框，此时建议改用 ZIP（[download.md §4.1](download.md)）。资料库的下载对话框可按次覆盖这两项。
- **品牌水印**：开关（默认关），子表单——文字（至多 40 个字符，带计数）、图片（PNG，不超过 512 KB，只保存在本机；有图时显示缩略图与“更换 / 移除”，无图时是“选择图片…”）、位置（四角，默认右下）、大小（小、中、大）、透明度（20%–100%，默认 70%）、预览（按当前设置绘制，画法与输出一致）。
- **美化**：默认是否开启（默认关）和初始样式——背景（8 款）、内边距（小、中、大）、圆角、阴影，带一块按当前设置画的预览；面板里的改动只影响本次截图。
- **录制**：麦克风授权的状态（没有授权、已允许、已拒绝）与“请求麦克风授权”；拒绝后的说明与“回到录制的标签页”同卡。在弹窗里勾选“带麦克风”或勾着它开始录制、扩展还没有麦克风授权时，在新标签页打开这里，由浏览器询问；允许后给出“回到录制的标签页”，拒绝后写明怎样在浏览器的扩展设置里改回允许（[annotate.md §2.1](annotate.md)）。光标高亮——开关（默认关）、形状（圆环、圆角方、菱形）、颜色（五种）（[annotate.md §3.2](annotate.md)）。
- **快捷键**：每条命令一行，右侧是拆开的键帽；只显示当前绑定，未绑定显示“未设置”，最后一行链接到浏览器的快捷键设置页。
- **数据**：存储用量（“已用 / 可用”，下带用量进度条）、异常残留资产的报告与清理（[storage.md §7](storage.md)）。
- **本地指标**：聚合数字（[metrics.md §10](metrics.md)），不展示正文；每项一行，编号是小标签，周表与事件计数仍是表格。

### 2.6 工具栏弹窗

点击浏览器工具栏图标打开同一套壳的紧凑版；它也是 `chrome://` 等页面内入口失效时的兜底。

```text
┌────────────────┬────────────────────────────────────────────────────┐
```

### 2.7 界面语言

界面语言随浏览器界面语言：中文系语言显示中文，其他语言显示英文，没有手动切换。选区菜单、应用页、弹窗、截图工具栏、阅读视图、错误提示和 Markdown ZIP 的章节标题都按这个语言显示；扩展清单里的名称、描述和快捷键说明也有两种语言。保存到条目里的用户内容不翻译。本文的中文文案是界面的中文版本，英文版与它一一对应。

## 3. 页面里的采集交互

采集规则见 [capture.md](capture.md)，这里只写用户看得到的部分。

- **选区剪藏**：点击“剪藏”立即保存，不打开窗口。保存后出现约 3 秒的提示“已剪藏 · 撤销 · 编辑”：提示是一枚深色胶囊，底部一条细条表示剩余时间，细条与计时同进退——指针停在提示上或焦点进入时，提示留住、细条停住，离开后重新计一轮；系统开启“减少动态效果”时细条按档跳变。撤销删除刚保存的条目，撤销后有一枚“已撤销”提示。编辑在选区旁打开小气泡，可改标题、标签、备注，“更多属性”在资料库里打开这条条目。保存失败时提示换成警示图标、原因与“重试”，选区保持。
- **快速编辑气泡**：头部写明“失焦即保存”，这也正是它的写入时机——失焦（点到气泡外）、`Esc` 与“完成”都写入，标题栏里按 `Enter` 同样写入；只提交改动过的字段，写入失败时气泡与已输入的内容都保留并说明原因。标签一栏是 chip 输入：`Enter` 或逗号把输入变成 chip，空输入时 `Backspace` 删除最后一个 chip，失焦时把剩下的文字也变成 chip；每个 chip 的“×”都有读屏名称，条数与长度的上限在就地提示。
- **区块剪藏**：点击胶囊里的“剪藏”保存整块，提示、撤销与编辑同上；胶囊什么时候出现、出现在哪里见第 2.1 节和 [capture.md §6.2](capture.md)。键盘用户用区块模式（第 7.1 节）。
- **截图**：`Ctrl+Shift+S` / `Cmd+Shift+S`、选区菜单或区块胶囊进入；拖拽区域（可先选一个比例预设）、单击元素，或把比窗口长的文章页拼成滚动长图，在选区内直接标注、匿名、加马赛克，再确认入库，或复制到剪贴板、按设置的格式下载（可先在美化面板里加背景与留白）；入库后出现在“截图”视图。完整契约见 [截图采集](screenshot.md)。
- **页面里不高亮**：想划重点，到资料库里读这条剪藏（第 4.2 节）。

## 4. 条目详情、阅读与属性编辑

### 4.1 详情抽屉与属性编辑

点击列表里的条目，在右侧抽屉打开详情；`Esc` 或点击抽屉外面关闭。窄窗口里抽屉占满内容区。

```text
┌──────────────────────────────────────────────────┐
│ [bookmark] 剪藏    [阅读] [回到来源] [🗑] [✕]     │
│ Retries and backpressure                          │
│ engineering.example.com/retries · 3 天前          │
├──────────────────────────────────────────────────┤
│ [quote] 原文                    🔒 原文只读 · 2 条 │
│ ## Exponential backoff with jitter                │
│ ==a random factor== between 0 and 1 so that …     │
│ ┌ 语境 ──────────────────────────────────────┐   │
│ │ In a saturated service, retries amplify …  │   │
│ └────────────────────────────────────────────┘   │
│ [message] 备注                                    │
│ [tags] 属性                                       │
│ [text]   title    Retries and backpressure       │
│ [list]   tags     reliability ×  retry ×  +      │
│ [list]   author   Jane Doe ×  +                  │
│ + 添加属性                                        │
│ 系统字段 · 只读                                    │
│ 🔒 source   engineering.example.com/retries      │
│ 🔒 created  2026-10-05  ·  🔒 updated  10-14     │
│ 🔒 type     剪藏                                  │
└──────────────────────────────────────────────────┘
```

- 头部是类型徽标与五个动作：**阅读**（仅剪藏）、**下载**（剪藏与截图都有，把这个条目取成 Markdown 文件夹，进度与结果显示在底部浮着的状态条里，[download.md §3.1](download.md)）、**回到来源**（新标签页打开原页面）、**删除**与**关闭**（仅图标，各带读屏名称）。截图卡片与抽屉图片节里的“下载图片”下载图片本身。标题块在头部下方：标题（至多两行）与一行来源地址、相对时间。
- 正文按节组织，节与节之间以发丝线分开，每节标题带图标：**原文**（或截图的**图片**）、**备注**、**属性**。有高亮时，原文节标题旁是“原文只读 · N 条高亮”的小标签，完整原因在悬停提示与读屏里；语境是原文下方的一个浅底框，可就地编辑。截图的图片节带下载按钮，图片点击放大。
- 原文显示为渲染后的 Markdown，带着高亮。**可编辑**：`title`（属性面板的第一行）、备注、全部属性；`clip` 的原文与语境可就地编辑，但**有高亮时原文只读**，并说明原因（[entry.md §4](entry.md)）。`type`、`id` 与 `sourceUrl` 不可改，`sourceUrl` 在系统字段里只读显示（[entry.md §5.5](entry.md)）。
- **属性面板**与 Obsidian 的 Properties 同构：每行左侧是类型图标与名称，右侧是值编辑器——静止时是正文文字，悬停出现细线，聚焦出现输入框外观与焦点环；列表值是带 × 的 chip 加一个“+”。值编辑器按类型：文本是单行输入，列表是标签输入，数字、日期、日期时间用对应控件，复选框是勾选。清空等于未设置。
- **添加属性**：行内展开的补全——输入名称时列出注册表的匹配项（类型图标、名称、类型名与“内置”）；注册表里没有的名称以“创建属性 …”进入创建分支：先在六个类型里选一个（创建后不可更改），创建后写入注册表并加到当前条目。保留名被拒绝并说明原因（[entry.md §5.3](entry.md)）。
- 属性面板下方是**系统字段 · 只读**：source、created、updated、type 四行，带锁形图标。
- 删除条目前确认：一张卡片叠在抽屉之上，写明条目将删除；有高亮的剪藏标题为“删除这条剪藏？”，正文写明将一并删除的高亮数（数字加粗），按钮是“删除剪藏与高亮”。`Esc`、取消与点击遮罩都只取消确认，焦点回到“删除”。删除 `screenshot` 条目同时删除它的图片。
- 改动在失焦或点击保存时写入；写入失败保留已输入的内容并显示错误与重试。

### 4.2 阅读与高亮

高亮发生在 AnnHub 里：把剪藏读一遍、划出重点、写下想法，是把内容变成自己的那一步。

- **打开**：抽屉里的“阅读”，或高亮视图里的一条高亮。内容区换成这条剪藏的阅读视图，导航不变；“返回”或 `Esc` 回到之前的列表与位置。路由 `#/read/<id>` 写入 URL，刷新后恢复。
- **版式**：主区顶部一行是“返回”、“下载”（把这个条目取成 Markdown 文件夹，进度与结果显示在底部浮着的状态条里，[download.md §3.1](download.md)）与“回到来源”；正文列居中，最宽适合阅读，从标题开始：大号标题、类型徽标、来源地址、相对时间与标签，其下一条分隔线，再往下是渲染后的 Markdown（标题、段落、列表、引用、代码和链接）。右侧窄栏有两个下划线式标签：“高亮”（带数量小标签）列出这条剪藏的高亮（按位置排序，每条是色条、引文和备注，点一条滚动到它）、“属性”是抽屉里同一个属性面板（含系统字段）；窄窗口里右栏收到正文下方。
- **新建高亮**：在正文里选中文字（鼠标或键盘），选区旁出现小工具条：五个颜色点和“备注”。点颜色点立即创建；点“备注”以默认颜色创建并打开备注输入；键盘上选中后按 `H` 以默认颜色创建。新选区与已有高亮重叠时合并（[entry.md §4](entry.md)）。
- **已有高亮**：正文里带底色和下划线，有备注的带一个小标记；点一下出现浮层，可改颜色、写备注（失焦即保存）或删除。删除后出现约 3 秒的“已删除 · 撤销”。
- **图片**：正文里的图片显示替代文字的占位和“打开原图”，不联网加载（[capture.md §3.1](capture.md)）。
- **同一个正文组件**也用在抽屉的“原文”里，所以抽屉里同样可以高亮；“阅读”只是换成更舒服的版式。
- **页面里看不到高亮**：这些高亮不写进网页，“回到来源”只打开原页面。
- **失败**：写入失败保留所选范围和已输入的备注，显示错误与重试。

## 5. 空状态

空状态都是图标方块、标题、说明和（有出路时的）操作，限制行宽居中呈现。

- **首次使用**：整个资料库还是空的、也没有筛选时，不显示筛选条。列表的位置是引导卡：三张卡各带类型色的图标方块、名称和一句话，说明剪藏、截图、高亮各是什么（高亮是“在资料库里读剪藏时划重点”）；底部主按钮“打开示例页面”（带图标）、一句说明文字和右侧的“不再显示”无边框按钮。可关闭。示例页只存在于演示，不混入用户的库。
- **某个视图为空**：显示对应的入口提示，例如“截图”为空时写明 `Cmd+Shift+S`，“高亮”为空时说明在阅读视图里选中文字即可；“全部”为空时写明两条来路——选中网页文字剪藏、用截图快捷键截一张（快捷键跟随浏览器里的实际绑定）。
- **无搜索结果**：保留当前筛选器，并提供实心的“清除筛选”，不显示导入或营销信息。

激活口径见 [metrics.md §2](metrics.md)。

## 6. 错误与恢复

- 保存失败（写入或配额）：不显示成功；截图保留预览与全部标注，编辑中的标题、备注、属性和高亮备注保留输入，都可重试；配额不足时提示导出，保存前先做配额校验（[storage.md §3](storage.md)）。
- 复制截图失败（页面是 `http:`、剪贴板被拒或窗口没有焦点）：保留图片与全部标注，说明原因并给出“改为下载”（[screenshot.md §5](screenshot.md)）。
- 页面脚本不可信：选区菜单、区块入口与截图会话只响应用户本人的输入和扩展自己的触发（[screenshot.md §2](screenshot.md)）。
- 图片缺失：条目仍可阅读，并提示“图片缺失”。
- 导出：生成失败时显示原因和未导出项，不把不完整的 ZIP 标记为成功。

## 7. 快捷键与可访问性

### 7.1 快捷键

| 快捷键                         | 功能                                                                                      |
| ------------------------------ | ----------------------------------------------------------------------------------------- |
| `Ctrl+Shift+S` / `Cmd+Shift+S` | 截图模式                                                                                  |
| `Ctrl+Shift+E` / `Cmd+Shift+E` | 区块模式：用键盘选一个区块并剪藏或截图                                                    |
| 默认不绑定                     | 页面批注：打开或退出当前标签页上的批注层                                                  |
| 默认不绑定                     | 录屏：开始或停止录制当前标签页                                                            |
| 默认不绑定                     | 下载本页正文：取当前标签页的主体文章为 Markdown 文件夹（[download.md §2.3](download.md)） |
| `H`                            | 阅读视图里，选中文字后以默认颜色高亮                                                      |
| `Esc`                          | 关闭菜单、取消截图、关闭抽屉、气泡与阅读视图                                              |

`Esc` 一次只关最里面的一层：高亮工具条，其次是高亮浮层，最后才是阅读视图或抽屉；输入法组词期间的 `Esc` 只取消组词。

区块模式里的按键（`Tab`、`↑` `↓`、`Enter`、`S`、`D`、`Esc`）见 [capture.md §6.2](capture.md)，截图编辑里的按键见 [screenshot.md §1.1](screenshot.md)，录制中页面批注的单键见 [annotate.md §3.1](annotate.md)。截图与区块模式的快捷键只作用于当前标签页的顶层页面，一次只开一个会话（[capture.md §3](capture.md)），批注层开着时它们怎样响应见 [annotate.md §1.1](annotate.md)；页面批注、录屏与下载本页正文的快捷键默认不绑定。所有快捷键都在浏览器的快捷键设置页绑定或修改。

### 7.2 可访问性

- 选区菜单、截图工具栏、阅读视图和应用页的主流程都能只用键盘完成（选区菜单在键盘选择停下后出现，用 `Tab` 与 `Enter` 操作，见第 2.1 节）。
- 壳的导航是导航地标，当前视图用 `aria-current` 标出；折叠为图标栏后仍有可读名称。导航项都在 Tab 顺序里，`↑` `↓` 另外在导航项之间移动焦点。列表视图里 `/` 聚焦搜索框。
- 筛选条用键盘可走通：触发按钮与芯片都在 Tab 顺序里；弹层打开后焦点进入（有搜索框先落搜索框，否则落在第一个选项），`↑` `↓` 在选项间移动，`Enter` / 空格选择，`Esc` 只关最里面一层并把焦点还给打开它的元素，`Tab` 离开弹层即关闭，点弹层外关闭。芯片的移除叉有读屏名称。
- 抽屉打开时焦点进入并被限制在其中，关闭后回到触发位置。阅读视图打开时焦点进入它自己的“返回”，被它盖住的列表不可聚焦，导航照常可用。
- 点“显示更多”之后，焦点落在新增的第一张卡片（第 2.3 节）；等待下一页时、按钮随最后一页消失时，焦点都不丢失。改筛选或别处的写入刷新列表时，焦点不跳进列表。
- 颜色不是状态的唯一表达：类型有图标和文字，属性类型有图标和文字；正文里的高亮带下划线，读屏读作“高亮，颜色名”。
- 设置页的开关是带 `role="switch"` 的复选框，读屏名称是它控制的功能名；分段控件、四角位置与背景色块是单选组，方向键可选。
- 屏幕阅读器能读出条目类型、标题和来源：条目卡片的名称是标题、标签、类型、来源与时间，剪藏的正文预览是它的描述，读在名称之后。

## 8. 验收标准

1. 在普通文章、信息流和 SPA 页面均可创建带来源和永久链接的选区剪藏与区块剪藏（选区剪藏另带语境）；页面上不出现任何标记。X 的帖子、Medium 的文章、技术文档的代码块与一节、个人博客的文章各至少在 3 个页面上识别到并保存出可读的 Markdown；在 [market.md §4.3](market.md) 抽样的 33 个可评估页面里，至少 30 个页面的文章级区块能包住 75% 以上的正文段落。
2. 剪藏一次点击保存，不打开窗口，约 3 秒内可撤销；选区到菜单出现小于 150ms，从点击到写入成功的 95 分位小于 300ms。
3. 区域与元素截图都能完成匿名、标注和入库，入库的图片出现在“截图”视图；可以复制到剪贴板（https 页面上粘贴得到 PNG），也可以按设置的格式下载；启用水印与美化后，复制与下载的图片带水印、带背景与留白，入库的图片保持原样。
4. 在资料库里打开剪藏，选中原文可创建、改色、写备注和删除高亮；刷新后高亮仍在；高亮视图按剪藏分组列出；有高亮的剪藏原文只读；删除剪藏前提示高亮数。
5. 两种条目共用同一个属性面板：可添加内置或自定义属性，同名属性类型一致，保留名与超限值被拒绝。
6. 属性页的使用数正确，使用中的属性不可删除，“删除未使用”可用。
7. 资料库可按类型、来源、标签、时间和属性筛选并搜索，条件写入 URL 并在刷新后恢复。
8. 所有扩展页面（应用页各视图、阅读视图、设置、弹窗）都是左导航 + 右内容；窗口变窄时导航折叠为图标栏，不出现顶部导航。
9. 断网时仍能采集、阅读、高亮、查询、编辑和导出；ZIP 里的 frontmatter 带着属性，剪藏里的高亮写成 `==…==`，截图的图片链接均有效。
10. 保存失败不丢失已输入的内容、高亮备注与截图预览。
11. 浏览器界面为英文时，扩展的每个界面都显示英文，不出现中文；为中文时不出现英文的 “Entry”（数据实体名除外）。
12. [examples.md §3](examples.md) 的场景 A 到 C 通过。
13. 区块胶囊不盖住页面自己的按钮、链接和菜单，左右缘留在区块轮廓内，不伸出轮廓盖住旁边的边栏：X 时间线的帖子（右上角有“更多”）、带“复制”按钮的代码块上，胶囊出现在不遮挡它们的位置；区块比窗口高时，胶囊始终在窗口里可见。
14. 页面的 `http:` 与 `https:` 两种情形下，截图的复制按钮分别给出“已复制”与“改为下载”的提示。
15. 同一网页里重拍同一取景框：元素 + 固定边距的输出尺寸完全相同、边距环里的像素无差异，滚动或改窗口大小之后沿用上次取景框仍框住同一块内容，页面不为它滚动，取景框不完整落在窗口里时不出现；选区待确认时画面上只有这一个选区和一条说明怎样处置它的提示（[screenshot.md §1.2、§1.4](screenshot.md)）。
16. 在当前标签页上打开页面批注，画出的笔画、形状、文字与序号截进截图编辑器后位置不变，进入入库、复制与下载的图片；退出、刷新或导航后页面上不留痕迹（[annotate.md §1.5](annotate.md)）。
17. 从工具栏弹窗录制当前标签页，停止后得到能在常见播放器里拖动进度条的 WebM；带麦克风时有旁白、麦克风的声音不回放，拒绝麦克风时仍有画面与标签页的声音；资料库里不出现新条目（[annotate.md §2.5](annotate.md)）。
18. 录制中打开页面批注：页面上只有墨迹、没有工具栏，单键切换工具、颜色与线宽；打开光标高亮后，光标周围的形状与左键的涟漪进入视频，页面照常可以点击（[annotate.md §3.4](annotate.md)）。
19. 在带吸顶导航的长文章页上拼滚动长图：吸顶导航只出现一次，拼接处没有重复或缺失的条带，拼好的图可以标注、复制、下载与入库；`Esc` 取消后不入库（[screenshot.md §1.5](screenshot.md)）。
20. 页面批注的墨迹随整页滚动跟着内容走，滚走再滚回来仍对得上；带着墨迹拼滚动长图时，笔画落在长图里对应的位置（[annotate.md §1.2、§1.3](annotate.md)）。
