# 网页批注与录制

> 层级：product
> 状态：页面批注的真源
> 更新：2026-10-30

讲解网页时用：直接在当前标签页上画箭头、圈出重点、写字，画完截进截图编辑器。它服务的是核心用户里要讲清楚一个界面的时刻（[product.md §2.1](product.md)）：产品经理、设计师提反馈、做走查，工程师复现问题、说明故障。交互参照 Presentify 的屏幕批注，范围只到当前标签页。

## 1. 页面批注

### 1.1 进入与退出

- **进入**：工具栏弹窗里的“在页面上批注”，或快捷键（[extension.md §7.1](extension.md)）。快捷键默认不绑定，用户在浏览器的快捷键设置页自己绑（见 [D-37](validation.md)）。只作用于当前标签页的顶层页面，一次只开一个；`chrome://` 等受限页面上没有这个入口。
- **界面**：页面上盖一层透明的批注层，窗口边上一条工具栏：画笔、荧光笔、直线、箭头、矩形、椭圆、文字、序号，五种颜色，线宽，撤销、清空、截图、退出。工具栏上写明“墨迹固定在屏幕上”。
- **指针与画**：进入时没有选中工具，是“指针”：页面照常可以点击、选中和滚动。选中一种工具后，在页面上按下拖动就是画，这一下不触发页面自己的动作。要点页面时，点工具栏上的“指针”切回，页面照常可点；再点一种工具接着画。不用按住修饰键临时穿透：浏览器里按住 `Alt` 点链接是下载，按住 `Ctrl` 或 `Cmd` 是在新标签页打开。
- **退出**：工具栏的“退出”或 `Esc`。`Esc` 先关最里面的一层——正在输入的文字框——再次按下才退出。退出时批注层和墨迹全部清除；刷新或打开别的网页同样清除。墨迹不保存，不写进条目、设置或导出。
- **和其他入口**：批注层开着时，选区菜单和区块胶囊不出现——选中文字、停在区块上都不弹出，它们会挡住要讲解的内容——退出批注后恢复。截图快捷键和工具栏上的“截图”一样，带着墨迹进入截图会话（§1.3）；区块模式的快捷键不响应，页面上提示先退出批注。截图会话进行中时不打开批注，截图界面上提示先完成或取消这次截图，已经画好的选区与标注不受影响；区块模式进行中时，打开批注会先退出区块模式。
- 马赛克不在批注层里：批注层上没有可以处理的像素。要打码，截进编辑器之后再打（[screenshot.md §1.1](screenshot.md)）。

### 1.2 画法

- 各工具的画法、五种颜色、三档线宽、荧光笔的透明度、直线按住 `Shift` 的吸附、序号的编号与拖动删除，都和截图编辑器相同（[screenshot.md §1.1](screenshot.md)）。每次进入从默认开始：红色、中档线宽、序号从 1 开始。
- **墨迹固定在屏幕上**：页面滚动时墨迹留在画下时的屏幕位置，不跟着内容走（见 [D-40](validation.md)）。窗口大小或页面缩放变化后，墨迹仍在画下时的屏幕位置，线宽按新的设备像素比显示。
- **撤销与清空**：画一笔、写一段字、放下、拖动或删除一个序号、重置计数、清空，各算一步，撤销逐步退回。清空之后序号从 1 重新开始；撤销清空时，墨迹与序号的计数一起回来。
- **自动擦除**：默认关；工具栏上可选 3 秒或 8 秒，开启后每一笔画完、到时自己消失（见 [D-39](validation.md)）。自动擦除只作用于页面上的墨迹，不进撤销，也不影响已经截进编辑器或入库的图片。
- **叠放与全屏**：批注层和工具栏始终在页面自己的浮层（吸顶导航、弹窗、客服挂件）之上；网页打开浏览器原生的模态对话框时也一样，对话框开着时照常可以画（[market.md §4.7](market.md)）。网页进入全屏时——把一个容器放大（例如 YouTube 的播放器），或用浏览器自带视频控件的全屏按钮放大视频本身——批注层和工具栏留在全屏画面之上，照常可以画。

### 1.3 截进截图编辑器

- 工具栏的“截图”进入截图会话（[screenshot.md §1](screenshot.md)）：拖拽区域或单击元素都可以。取景时墨迹仍然可见，不挡指针。
- 截取的那一刻，墨迹和扩展的其他界面一起隐藏；截到的图片进入编辑器后，墨迹按画下时的屏幕位置画回图上，成为编辑器里的普通标注：可以撤销（全部墨迹算一步，见 [D-38](validation.md)），可以接着画，和其他标注一样进入入库、复制与下载的图片（[screenshot.md §4](screenshot.md)）。完全落在取景框外的笔画不进图，跨过边界的在边界处截断。
- 截图会话结束——确认、取消或出错——之后回到批注层，墨迹还在，可以接着画、再截。

### 1.4 边界

- 只覆盖当前标签页顶层页面的视口；画不到浏览器自己的界面、别的标签页或别的应用上。页面里的 iframe 上方也能画：批注层盖在顶层页面上，截下来的是 iframe 的画面加上墨迹。
- 不改网页的内容与结构：批注层是扩展自己的浮层，用户打开时才出现，退出就清除（[product.md §6](product.md) 原则 2）。
- 不需要新的权限（[permissions.md §2](permissions.md)）。
- 断网时照常可用：批注、截图与入库都在本机完成。
- 页面自己的脚本伪造的事件不能打开批注、落笔，也不能触发截图；和截图会话一样只认用户本人的输入（[screenshot.md §2](screenshot.md)）。

### 1.5 验收与测试

- 单测覆盖墨迹从屏幕位置到截取图片像素的换算：取景框原点、设备像素比、落在框外与跨过边界的笔画。
- 单测与 E2E 覆盖：伪造的指针与按键事件不能打开批注或落笔；退出、刷新与导航后页面上没有批注层残留；切回“指针”后点击落到页面上，再选工具又是画；清空之后序号从 1 开始，撤销清空后计数回来；网页把一个容器或视频元素本身放大到全屏时都可以画，页面自己的最高层浮层盖不住批注层，网页打开原生模态对话框时批注层在对话框之上、照常可以画，对话框关上后批注层还在；批注层开着时选中文字不出现选区菜单、停在区块上不出现胶囊，截图快捷键带着墨迹进入截图会话，区块模式的快捷键只给出提示，截图会话进行中打开批注不丢失已画的选区与标注。
- E2E 在夹具页上画一条红色直线和一个序号，进入截图拖出区域：预览、三种格式的下载、剪贴板和入库图片的像素里，直线与序号都在对应位置；截取的那一刻页面上没有批注层；撤销一次拿掉全部墨迹；会话结束后墨迹仍在页面上。
- 自动擦除到时只清掉页面上的墨迹，已经入库的图片不变。
- 真机走查见 [roadmap.md §5](roadmap.md)。
