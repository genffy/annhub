# 网页批注与录制

> 层级：product
> 状态：页面批注与标签页录制的真源
> 更新：2026-10-30

讲解网页时用：直接在当前标签页上画箭头、圈出重点、写字，画完截进截图编辑器；或者把当前标签页录成本地视频，带上麦克风旁白。它服务的是核心用户里要讲清楚一个界面的时刻（[product.md §2.1](product.md)）：产品经理、设计师提反馈、做走查，工程师复现问题、说明故障。交互参照 Presentify 的屏幕批注，范围只到当前标签页。

## 1. 页面批注

### 1.1 进入与退出

- **进入**：工具栏弹窗里的“在页面上批注”，或快捷键（[extension.md §7.1](extension.md)）。快捷键默认不绑定，用户在浏览器的快捷键设置页自己绑（见 [D-37](validation.md)）。只作用于当前标签页的顶层页面，一次只开一个；`chrome://` 等受限页面上没有这个入口。
- **界面**：页面上盖一层透明的批注层，窗口边上一条工具栏：画笔、荧光笔、直线、箭头、矩形、椭圆、文字、序号，五种颜色，线宽，撤销、清空、截图、退出。
- **指针与画**：进入时没有选中工具，是“指针”：页面照常可以点击、选中和滚动。选中一种工具后，在页面上按下拖动就是画，这一下不触发页面自己的动作。要点页面时，点工具栏上的“指针”切回，页面照常可点；再点一种工具接着画。不用按住修饰键临时穿透：浏览器里按住 `Alt` 点链接是下载，按住 `Ctrl` 或 `Cmd` 是在新标签页打开。
- **退出**：工具栏的“退出”或 `Esc`。`Esc` 先关最里面的一层——正在输入的文字框——再次按下才退出。退出时批注层和墨迹全部清除；刷新或打开别的网页同样清除。墨迹不保存，不写进条目、设置或导出。
- **和其他入口**：批注层开着时，选区菜单和区块胶囊不出现——选中文字、停在区块上都不弹出，它们会挡住要讲解的内容——退出批注后恢复。截图快捷键和工具栏上的“截图”一样，带着墨迹进入截图会话（§1.3）；区块模式的快捷键不响应，页面上提示先退出批注。截图会话进行中时不打开批注，截图界面上提示先完成或取消这次截图，已经画好的选区与标注不受影响；区块模式进行中时，打开批注会先退出区块模式。
- 马赛克不在批注层里：批注层上没有可以处理的像素。要打码，截进编辑器之后再打（[screenshot.md §1.1](screenshot.md)）。

### 1.2 画法

- 各工具的画法、五种颜色、三档线宽、荧光笔的透明度、直线按住 `Shift` 的吸附、序号的编号与拖动删除，都和截图编辑器相同（[screenshot.md §1.1](screenshot.md)）。每次进入从默认开始：红色、中档线宽、序号从 1 开始。
- **墨迹跟着页面内容走**：整页纵向或横向滚动时，墨迹跟着画在下面的内容一起移动，滚走再滚回来仍对得上。从吸顶导航、固定的挂件这类钉在窗口上的元素上开始画的笔画固定在屏幕上，不随滚动移动。墨迹只跟整页的滚动：页面里另一个滚动区域（例如邮件列表、文档的编辑区、横向滚动的代码块）自己滚动时，画在它上面的墨迹不跟着走；整页滚动时照常跟着整页走。窗口大小或页面缩放变化、页面重新排版时，墨迹留在画下时的页面位置，不跟着排版移动；线宽按新的设备像素比显示。
- **撤销与清空**：画一笔、写一段字、放下、拖动或删除一个序号、重置计数、清空，各算一步，撤销逐步退回。清空之后序号从 1 重新开始；撤销清空时，墨迹与序号的计数一起回来。
- **自动擦除**：默认关；工具栏上可选 3 秒或 8 秒，开启后每一笔画完、到时自己消失（见 [D-39](validation.md)）。自动擦除只作用于页面上的墨迹，不进撤销，也不影响已经截进编辑器或入库的图片。
- **叠放与全屏**：批注层和工具栏始终在页面自己的浮层（吸顶导航、弹窗、客服挂件）之上；网页打开浏览器原生的模态对话框时也一样，对话框开着时照常可以画（[market.md §4.7](market.md)）。网页进入全屏时——把一个容器放大（例如 YouTube 的播放器），或用浏览器自带视频控件的全屏按钮放大视频本身——批注层和工具栏留在全屏画面之上，照常可以画。

### 1.3 截进截图编辑器

- 工具栏的“截图”进入截图会话（[screenshot.md §1](screenshot.md)）：拖拽区域或单击元素都可以。取景时墨迹仍然可见，不挡指针。
- 截取的那一刻，墨迹和扩展的其他界面一起隐藏；截到的图片进入编辑器后，墨迹按截取那一刻在屏幕上的位置画回图上，成为编辑器里的普通标注：可以撤销（全部墨迹算一步，见 [D-38](validation.md)），可以接着画，和其他标注一样进入入库、复制与下载的图片（[screenshot.md §4](screenshot.md)）。完全落在取景框外的笔画不进图，跨过边界的在边界处截断。
- 在截图会话里选“滚动长图”（[screenshot.md §1.5](screenshot.md)）时，墨迹按它在页面上的位置画进长图，滚出窗口的笔画同样进图。固定在屏幕上的笔画不进长图：它们在每一屏的同一个位置，画进哪一屏都对不上；编辑器里提示一句。
- 截图会话结束——确认、取消或出错——之后回到批注层，墨迹还在，可以接着画、再截。

### 1.4 边界

- 只覆盖当前标签页顶层页面的视口；画不到浏览器自己的界面、别的标签页或别的应用上。页面里的 iframe 上方也能画：批注层盖在顶层页面上，截下来的是 iframe 的画面加上墨迹。
- 不改网页的内容与结构：批注层是扩展自己的浮层，用户打开时才出现，退出就清除（[product.md §6](product.md) 原则 2）。
- 不需要新的权限（[permissions.md §2](permissions.md)）。
- 断网时照常可用：批注、截图与入库都在本机完成。
- 页面自己的脚本伪造的事件不能打开批注、落笔，也不能触发截图；和截图会话一样只认用户本人的输入（[screenshot.md §2](screenshot.md)）。

### 1.5 验收与测试

- 单测覆盖墨迹从屏幕位置到截取图片像素的换算：取景框原点、设备像素比、落在框外与跨过边界的笔画。
- 单测与 E2E 覆盖：伪造的指针与按键事件不能打开批注或落笔；退出、刷新与导航后页面上没有批注层残留；切回“指针”后点击落到页面上，再选工具又是画；清空之后序号从 1 开始，撤销清空后计数回来；网页把一个容器或视频元素本身放大到全屏时都可以画，页面自己的最高层浮层盖不住批注层，网页打开原生模态对话框时批注层在对话框之上、照常可以画，对话框关上后批注层还在；批注层开着时选中文字不出现选区菜单、停在区块上不出现胶囊，截图快捷键带着墨迹进入截图会话，区块模式的快捷键只给出提示，截图会话进行中打开批注不丢失已画的选区与标注。
- E2E 在夹具页上画一条红色直线和一个序号，进入截图拖出区域：预览、三种格式的下载、剪贴板和入库图片的像素里，直线与序号都在对应位置；截取的那一刻页面上没有批注层；撤销一次拿掉全部墨迹；会话结束后墨迹仍在页面上。
- 单测覆盖页面位置与屏幕位置的换算（含横向滚动）：滚走再滚回来，位置不变。E2E 在夹具页上画一笔，滚动一屏再滚回，墨迹仍压在同一段文字上；滚动之后再截图，墨迹落在截取那一刻显示的位置；画在页面内另一个滚动区域上的一笔，那个区域自己滚动时不跟着走，整页滚动时跟着整页走；从页面批注进入滚动长图，笔画落在长图里对应的位置，固定在屏幕上的笔画不进长图并有提示。
- 自动擦除到时只清掉页面上的墨迹，已经入库的图片不变。
- 真机走查见 [roadmap.md §5](roadmap.md)。

## 2. 录制标签页

把当前标签页录成一段本地视频，用来讲解操作。录制时画在页面上的批注也进视频（§3）。

### 2.1 开始与停止

- **开始**：工具栏弹窗里的“录制此标签页”，或用户自己绑定的快捷键（见 [D-37](validation.md)）。录制只能从浏览器的界面上开始——弹窗或快捷键；页面里没有开始录制的按钮，网页也不能替用户开始。
- **麦克风**：弹窗里有“带麦克风”，默认不勾，勾选与否下次录制沿用。浏览器只在看得见的扩展页面上询问麦克风授权（[market.md §4.7](market.md)），所以勾选“带麦克风”或勾着它开始录制时，如果扩展还没有麦克风授权（第一次用，或上次在询问里只允许了这一次），先在新标签页打开设置页的“录制”一节，由浏览器在那里询问，这一次不开始录制（见 [D-43](validation.md)）。允许以后，设置页写明已允许，并给出“回到录制的标签页”，用户回去从弹窗开始录制。拒绝以后浏览器不再询问：“带麦克风”取消勾选，设置页写明怎样在浏览器的扩展设置里改回允许。关掉询问、没有作选择时按没有授权处理，“带麦克风”同样取消勾选。没有麦克风或麦克风被占用时，只录画面与标签页的声音，弹窗写明原因。
- **录制中**：扩展图标上显示红色的“REC”角标，浏览器也会在标签页上标出它正在被录制。弹窗显示正在录的标签页标题、已录时长和“停止录制”。页面里不放录制按钮或指示灯：它们会被录进视频。
- **停止**：弹窗里的“停止录制”、再按一次快捷键、关闭被录的标签页，或到达上限——15 分钟或约 500 MB，先到为准（见 [D-46](validation.md)）。停止后自动下载为 `AnnHub/recording-<本地时间>.webm`，和截图的下载在同一个目录；扩展不弹出另存为对话框，浏览器设置了“下载前询问每个文件的保存位置”时由浏览器询问（[market.md §4.7](market.md)）。到达上限时，弹窗里写明到了哪一个上限，例如“已到 15 分钟，已保存”。
- 一次只录一个标签页：录制中弹窗只显示正在录的那一个和“停止录制”，要录别的标签页，先停止当前的录制。

### 2.2 录什么

- **画面**：开始录制时那个标签页的可见区域，不含浏览器的地址栏、工具栏和其他窗口。鼠标指针在画面上移动或点击时出现在视频里，停下约 2 秒后从画面上隐去：这是浏览器录制标签页的方式（[market.md §4.7](market.md)）。要让观众一直看得到指针在哪里，打开光标高亮（§3.2）。
- **声音**：这个标签页发出的声音；开了麦克风时加上麦克风旁白。录制期间标签页的声音照常从扬声器出来；麦克风的声音不回放。用扬声器外放时，扬声器里的页面声音会被麦克风收进视频；勾选“带麦克风”时，弹窗提示戴耳机。
- **导航与切换**：同一标签页里打开别的网页，继续录在同一段视频里。切到别的标签页时，继续录开始时的那一个（见 [D-45](validation.md)）；它在后台时画面可能变卡，弹窗写明正在录哪一个。
- **格式**：WebM，画面 VP9（不支持时用 VP8），声音 Opus。常见播放器能打开并拖动进度条。
- 页面批注的墨迹与光标高亮在画面里（§3），批注工具栏不在。

### 2.3 不进资料库

- 录屏只下载到本机：不是条目，不出现在资料库，也不进“导出内容”的 ZIP（见 [D-41](validation.md)；条目类型见 [entry.md §2](entry.md)）。
- 不上传，不需要账号；不做剪辑、字幕与转码（[product.md §2.3](product.md)）。
- 画面、声音与网址不进日志和指标；指标只记时长分桶、有没有麦克风和停止原因（[metrics.md §9](metrics.md)）。
- 断网时照常录制与下载。

### 2.4 失败

| 情况                                | 处理                                                                                                                  |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 受限页面（`chrome://`、扩展商店等） | 弹窗里“录制此标签页”不可用，写明原因                                                                                  |
| 麦克风被拒绝、不存在或被占用        | 只录画面与标签页声音，弹窗写明原因；被拒绝时，设置页写明怎样在浏览器的扩展设置里改回允许                              |
| 被录的标签页关闭                    | 停止，下载已经录下的部分                                                                                              |
| 到达上限                            | 自动停止并下载；弹窗里写明到了哪一个上限、已经保存                                                                    |
| 下载失败                            | 扩展图标的角标换成“!”；弹窗里写明原因，给出“重新下载”与“放弃”。视频保留到重新下载成功或放弃，在这之前不能开始新的录制 |
| 录制中浏览器或扩展被关闭            | 已录的部分丢失；开始录制前，弹窗写明视频在停止之后才会保存成文件                                                      |

上表里的提示都是本地化的短句，依据稳定的错误码生成，不显示浏览器的原始信息。

### 2.5 验收与测试

- 单测用替身覆盖：麦克风被拒时仍有画面与标签页的声音，“带麦克风”取消勾选；“带麦克风”的勾选下次录制沿用，关掉麦克风询问、没有作选择时取消勾选；勾着“带麦克风”开始录制而扩展没有麦克风授权时，打开设置页询问、不开始录制；麦克风不接到扬声器，标签页的声音接到扬声器；只有扩展自己的界面能开始和停止录制，网页发来的请求被拒绝；下载的文件是 `.webm`，在 `AnnHub/` 目录下；下载完成之前不丢弃视频；下载失败时角标换成“!”，重新下载或放弃之前不能开始新的录制；资料库里没有新条目。
- 浏览器自动化模拟不了用户在浏览器界面上开始录制，录制本身走真机验收（[roadmap.md §5](roadmap.md)）。

## 3. 录制时的批注与光标高亮

录制中照样可以打开页面批注（§1）：画在页面上的笔画会进视频。再加上光标高亮与点击涟漪，观众不用猜讲解的人点了哪里。

### 3.1 控件不进画面

- 录制中打开页面批注时，页面上不显示批注工具栏，只有墨迹：工具栏会被录进视频（见 [D-48](validation.md)）。工具用单键切换：

  | 按键    | 作用                   |
  | ------- | ---------------------- |
  | `P`     | 画笔                   |
  | `H`     | 荧光笔                 |
  | `L`     | 直线                   |
  | `A`     | 箭头                   |
  | `R`     | 矩形                   |
  | `O`     | 椭圆                   |
  | `T`     | 文字                   |
  | `N`     | 序号                   |
  | `V`     | 回到指针，页面照常可点 |
  | `1`–`5` | 红、黄、青、白、黑     |
  | `[` `]` | 线宽细一档、粗一档     |
  | `Z`     | 撤销                   |
  | `E`     | 清空                   |
  | `Esc`   | 退出批注               |

- 这些按键只在批注层打开、焦点不在输入框或可编辑区域时生效；其余时候属于页面。工具栏弹窗里列出这张表。批注层打开时这些键先交给批注层；少数网站在扩展之前就截获按键，同一个键可能同时触发网站自己的快捷键（例如 X 的 `L` 是点赞），真机验收逐个核对。
- 工具栏上另外三样没有单键：自动擦除沿用工具栏收起前的选择；“重置计数”不可用，清空之后序号从 1 重新开始（§1.2）；“截图”换成截图快捷键，和工具栏上的一样带着墨迹进入截图会话（§1.1、§1.3），截图的界面在被录的页面上，也会录进视频。
- 工具栏收起时，当前的工具与颜色由鼠标指针的样子表示：画图工具时指针是所选颜色的十字，“指针”时是平常的箭头。
- 截图编辑器里的标注工具没有单键（[screenshot.md §1.1](screenshot.md)）；这张表只属于录制中的批注层。
- 不录制时打开的批注层照常显示工具栏（§1.1）；开始录制时工具栏收起，停止后回来。

### 3.2 光标高亮与点击涟漪

- 设置页的“录制”一节里：光标高亮开关（默认关）、形状（圆环、圆角方、菱形）、颜色（与标注相同的五种）。打开后，录制中光标周围显示所选的形状，跟着光标移动；按下左键时，以按下处为中心扩散一圈涟漪。
- 鼠标停下约 2 秒后浏览器从画面上隐去指针（§2.2），光标高亮留在指针最后的位置，观众仍看得到它在哪里。指针离开页面——移到浏览器的工具栏或别的窗口——时光标高亮隐去，回来时重新出现。截图时它和扩展的其他界面一起隐藏，不进截图。
- 光标高亮只在录制中、只在被录的标签页上出现；不挡点击，不改页面，页面照常可以操作。
- 指针移到页面里另一个来源的 iframe 上时，光标高亮停在 iframe 的边上；打开别的网页之后的最初片刻没有光标高亮。这两处是浏览器给扩展的限制，录制照常进行。

### 3.3 停止录制以后

光标高亮随录制停止而消失。批注层回到 §1 的样子：工具栏重新出现，墨迹还在，用户自己退出。

### 3.4 验收与测试

- 单测与 E2E 覆盖：录制中批注层不显示工具栏，单键切换工具、颜色与线宽，焦点在输入框里时按键属于页面；光标高亮不挡点击，鼠标停下时留在原处，指针离开页面时隐去，截图时不进截图；选中画图工具时这一次点击不落到页面上，按 `V` 切回指针后落到页面上；鼠标指针的样子随工具与颜色变化；停止录制后光标高亮消失、工具栏回来。
- 墨迹、光标高亮与涟漪确实进入视频，走真机验收（[roadmap.md §5](roadmap.md)）。
