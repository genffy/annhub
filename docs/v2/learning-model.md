# 学习模型与方法论

> 层级：vision
> 状态：产品方法论
> 更新：2026-10-04

目标用户和产品边界见 [产品定位](product.md)，页面体验分别见 [扩展](extension.md) 与 [Desktop](desktop.md)。

## 1. 核心问题

AnnHub 解决的是“保存了，但没有成为可调用知识”的问题。

| 失效点   | 常见表现                               |
| -------- | -------------------------------------- |
| 散落     | 信息分布在书签、高亮、截图和聊天记录中 |
| 脱离语境 | 只剩一句话，不知道当时为何重要         |
| 缺少加工 | 原样搬运，没有形成自己的理解           |
| 没有提取 | 只重复阅读，从未主动回忆               |
| 没有应用 | 认得内容，但写作、决策或解释时用不出来 |

框架用三层分别处理这些问题；其中“没有应用”通过采集时写下的应用承诺和复习时的回看来缓解，不验证真实使用。

## 2. 三层模型

```text
L1 Capture     内容 + 语境 + 来源 + 定位
L2 Process     理解 + 核验 + 应用
L3 Review      到期队列 + 提取练习 + 评分日志
```

L1 到 L3 构成闭环。

## 3. 逐层契约

### L1 采集

**目标**：碎片离开原始页面后仍能被理解和追溯。

最小输出必须包含：

- 被指认或手工写下的内容
- 能重新解释该内容的上下文
- 来源地址和标题
- 采集时间
- 尽力而为的定位符

没有上下文的选区只能作为高亮或剪藏，不能直接进入学习核心。

用户不愿意完成加工时，产品应把内容保存为 Highlight 或 Clip，而不是创建未完成 Fragment。

### L2 主动加工

**目标**：把搬运转化为自己的认知产物。

通用过程：

1. **理解**：先写下当前判断、解释或疑问。
2. **核验**：回看原文、可信资料或个人推测后，明确确认、保留不确定性或修正；说明与备注可选。
3. **应用**：说明它能解释什么、改变什么或如何使用。

应用不可为空。不同碎片类型可以使用不同校验器，但不能把“保存原文”当作应用。

标准模式只要求核验与应用；深度模式在前面增加理解步骤。模式定义见 [扩展 PRD](extension.md)。

### L3 间隔复习

**目标**：在合适时间制造主动提取，而不是再次浏览。

复习输入是到期碎片，输出是不可变的 `ReviewLog` 和可重算的调度状态。文本题型包括概念解释、理由回忆和步骤重建；基础视觉题型先回忆关键结构，揭示后再看图。图像遮挡属于视觉增强，不是基础 `visual` 的默认题型。

## 4. 三条方法论

每条原则的研究依据与适用边界见第 6 节。

### 4.1 语境完整

语境不是辅助元数据，而是碎片的一部分。采集流程宁可多一步确认，也不能保存无法独立理解的内容。

### 4.2 主动生成

用户必须留下自己的解释、问题或应用。系统可以辅助，但不能替用户完成所有加工。

### 4.3 提取优于重读

复习页先要求回忆，再展示原文或提示。直接展示答案会制造熟悉感，却无法验证能否调用。

## 5. 内容类型适配

每种 kind 如何落实 L1–L3（采集提问、复习题面、示例）集中在 [kinds.md](kinds.md)，本文不再重复。适配遵循两条原则：

1. **L2 的提问必须因类型而异**：概念问边界，论点问前提与证据，方法问步骤与失败条件，决策问约束与备选，问题问假设与下一步，视觉问关键细节，灵感问缘起与推测。
2. **L3 的题面取“最难被字面记忆替代”的那个问题**：提示由粗到细，使用任何提示都要记录。

新类型必须说明三层如何落实（清单见 [kinds.md §5](kinds.md)）。如果某层长期不适用，应先判断该内容是否真的属于 AnnHub。

## 6. 证据基础

方法论不是凭感觉。下表把原则对应到可核对的研究，并写明**证据的边界**：这些研究多在学生与教材文本上完成，能否迁移到职场知识工作是 AnnHub 的假设，由 [H-02](validation.md) 检验。

Dunlosky 等人（2013）综述了 10 种常用学习技术，评级依据是益处能否推广到不同的学习条件、学习者、材料和考核任务，而不是单次实验的效果大小。

| 原则                       | 证据                                                                                                                                                    | 边界                                                     | 设计推论                                                                 |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------ |
| 4.3 提取优于重读           | Dunlosky 等（2013，_Psychological Science in the Public Interest_ 14(1)）：练习测试评为高效用，重读评为低效用                                           | 以学生与教材文本为主                                     | 先回忆再揭示；评分按钮在揭示后出现；重复浏览不计入复习                   |
| 间隔复习                   | 同上：分散练习评为高效用                                                                                                                                | 同上                                                     | 间隔调度；每日建议量设上限，不强制一次做完                               |
| 两条分流（高亮不等于学习） | 同上：高亮或划线、摘要评为低效用                                                                                                                        | 结论针对“指望靠高亮记住”；作为页面标记与查阅，高亮仍有用 | Highlight 与 Clip 不进入复习，只有 Fragment 是学习对象                   |
| 4.2 主动生成               | 同上：精细询问、自我解释评为中等效用，稳健性不及练习测试；生成效应另有元分析（Bertsch 等，2007，_Memory & Cognition_）                                  | 中等效用依赖已有知识                                     | 理解、核验、应用三步，应用必填；标准模式只要求核验与应用，把摩擦降到最低 |
| 4.2 AI 在用户生成之后      | Bastani 等（2025，_PNAS_）：高中数学的大规模实验显示，AI 辅导提高练习表现，但撤走 AI 后表现反而更差；让 AI 给教师设计的提示、而不是直接给答案，可以缓解 | 高中数学，使用 GPT-4；对象不是知识工作者                 | 先写后看；提示梯度先于答案；模型不代写应用                               |
| 复习负担的权衡             | Anki 手册：期望记忆率默认 90%，高于 90% 工作量迅速上升，高于 97% 可能难以承受                                                                           | 来自算法实践，不是对照实验                               | 每日建议上限 20、单次会话约 10 分钟，以“不压垮用户”为首要约束            |

原文（核对于 2026-10-03）：[Dunlosky 等](https://www.psychologicalscience.org/publications/journals/pspi/learning-techniques.html)、[Bastani 等](https://www.pnas.org/doi/10.1073/pnas.2422633122)、[Anki 手册](https://docs.ankiweb.net/deck-options.html)。

### 与常见方法的关系

| 方法                               | 它的核心                           | AnnHub 的借鉴与差异                                                     |
| ---------------------------------- | ---------------------------------- | ----------------------------------------------------------------------- |
| 渐进阅读（SuperMemo）              | 边读边提取片段，逐步加工并安排复习 | 借鉴“提取”与逐步加工；不把所有阅读活动都变成排程                        |
| 卡片盒与常青笔记                   | 用自己的话写原子化笔记，并相互链接 | Fragment 近似原子笔记，但强制写应用，并要求提取复习；不做碎片之间的链接 |
| 第二大脑（捕获、整理、提炼、表达） | 用流程组织个人资料                 | 对应 L1、L2；补上“提取复习”这一环（L3）                                 |
| 助记媒介（Quantum Country）        | 把提取提示嵌入阅读材料本身         | 思路相近：在采集现场当场加工；差异是材料由用户自选，而不是作者预制      |

## 7. 产品形态映射

| 层     | 主要承载端    |
| ------ | ------------- |
| L1、L2 | 浏览器扩展    |
| L3     | macOS Desktop |

分端不是数据分裂。两端共享领域契约，通过 Desktop 本地服务逐项交付；扩展面向其他工具的 Markdown ZIP 不作为跨端数据库同步协议。

## 8. 成功指标

优先指标：

- 被复习后成功提取的碎片数

不作为核心指标：采集总量、打开次数、停留时长和连续签到。

精确口径见 [体验与指标](metrics.md)。
