# 截图采集

> 层级：core
> 状态：采集链路；复制在 R1，比例预设、下载格式、品牌水印与美化在 R2；精确选区与可重复的取景框（R3）在阶段 V 之后排期（范围状态见 [roadmap.md](roadmap.md)）
> 更新：2026-10-10

截图是 [采集链路](capture.md) 的视觉入口，保存为 `screenshot` 条目。页面交互见 [扩展 PRD](extension.md)，资产字段、事务和 ZIP 导出以 [存储契约](storage.md) 为准，条目字段见 [条目契约](entry.md)。

## 1. 用户路径

```text
快捷键、选区菜单，或区块胶囊里的“截图”
  -> 拖拽区域（可先选比例预设）/ 单击元素（R3：吸附、微调、边距、选区确认，或沿用上次取景框）
  -> 原位预览并标注，检查匿名与马赛克；可选美化
  -> 确认后保存为 screenshot 条目；也可以复制到剪贴板，或按设置的格式下载
  -> 在资料库的“截图”视图查看，补标题、标签、备注与属性
```

快捷键为 `Ctrl+Shift+S`，macOS 为 `Cmd+Shift+S`。拖拽选择视口区域，单击选择元素；`Esc` 取消会话，`A` 切换 DOM 匿名。区块胶囊里的“截图”以该区块为目标元素，直接进入元素截图的原位编辑。

### 1.1 选区内编辑

交互以微信截图的原位编辑方式为参考：进入模式后页面变暗；拖拽时选区保持明亮、显示蓝色边框和像素尺寸。截取完成后，图片直接占据原选区，不跳到居中预览卡片。浮动工具栏贴近选区右下角；空间不足时移到上方并约束在视口内。图的像素尺寸标在左上角外侧，上方没有位置或被工具栏占着时移到下方，再不行放进左上角内侧，工具栏不盖住它。元素截图也使用同一编辑界面，超出视口的元素按比例缩小预览，但保存完整像素。窄视口下工具栏可横向滚动，不能遮住确认和取消操作。

| 工具                   | 行为                                                                                                                    |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 矩形、椭圆、箭头、画笔 | 在图片上拖拽标注；支持红、黄、青、白、黑色                                                                              |
| 马赛克                 | 拖拽指定像素区域，预览立即显示处理结果                                                                                  |
| 文字                   | 在图片上单击输入，回车提交，`Shift+Enter` 换行                                                                          |
| 撤销                   | 撤销最近一次人工标注；自动建议的马赛克区域可以单独移除                                                                  |
| 美化（R2）             | 打开美化面板（§4.4），背景、留白、圆角、阴影与输出比例；只作用于复制与下载                                              |
| 复制                   | 把当前结果以 PNG 复制到剪贴板（`Ctrl/Cmd+C`；焦点在文字输入框里时，它仍复制框里的文字），继续保留编辑会话；不需要先下载 |
| 下载                   | 按设置里的格式下载当前结果，继续保留编辑会话                                                                            |
| 取消、确认             | 分别丢弃本次截图、保存当前结果为 `screenshot` 条目                                                                      |

编辑界面底部的状态条显示本次截图的匿名与水印状态：`A` 切换匿名；设置里启用了水印时，`W` 切换水印。两者只影响这一次截图。

`Esc` 先关闭最里面的一层——文字输入框或美化面板——再次按下才取消截图。保存、复制或下载失败时保留图片与全部标注，允许重试。截图链路不做分享、翻译、表情；真实发布动作（如发布到社交平台）同样不进入扩展域，截图产物以本地入库、复制与下载为终点。给截图加背景、留白、圆角与阴影的美化见 §4.4。

### 1.2 精确选区（R3，阶段 V 之后排期）

选区精度：拖拽时对光标下的元素边缘实时吸附并高亮提示，起止点可吸附到元素矩形；单击元素的路径里，悬停时按 `↑` 选上一级、`↓` 回到下一级（跳过外框与当前元素完全相同的层级），不必为了选中一个容器去瞄它的边缘；确认前选区显示八向手柄，支持拖拽二次调边；方向键微调 1 像素，配合 `Shift` 每次 10 像素。拖拽中按住 `Shift` 临时锁定当前比例，松开即解除。

选区确认：拖拽松开后选区保持可调——选区旁出现“确认选区 ↵ / 取消”，按 `Enter` 或点击“确认选区”后才进入原位编辑，`Esc` 取消会话。单击元素的路径不变，直接进入原位编辑。R3 之前松手即截取。

### 1.3 比例预设（R2）

框选区域时可以先选一个比例预设，选区被锁定为该比例。区域截图的选区条上列出“自由”和设置里启用的预设，点一个即锁定，再点“自由”解除；尺寸标签同时显示像素与比例，并带锁形图标。锁定后拖拽始终输出目标比例，选区被夹紧在视口内；单击元素的路径不受影响。

可选的比例是 1:1、4:5、3:4、4:3、16:9、9:16；设置里勾选哪些出现在选区条上，默认 1:1、4:5、3:4、16:9（[extension.md §2.5](extension.md)）。每次截图从“自由”开始，不记忆上一次的选择。预设只约束选区的形状，不预设像素大小：截多大取决于页面，输出始终是选区的真实像素。

### 1.4 可重复的取景框（R3，阶段 V 之后排期）

同一个界面在不同状态下反复截图——切换套餐周期、主题、语言、数据——要求每张图的取景完全一致：同样的像素尺寸，同样的边距。手动拖拽做不到：每次起止点都差几个像素，三张图的尺寸各不相同（验证见 [market.md §4.5](market.md)）。取景框因此可以由元素定义，并且能原样再用：

- **元素 + 边距**：选中一个元素后，选区条上出现“边距”：0、8、16、24、32 CSS 像素，也可以输入数值；取景框 = 元素外框向四周各外扩这个边距，边距里是元素周围真实的页面。选哪个元素用 `↑` `↓` 在层级间移动（§1.2），例如从卡片里的价格行选到包含切换条与全部卡片的容器。
- **沿用上次取景框**：同一标签页、同一网页（来源与路径相同）里，确认入库、复制或下载之后，当前取景框被记下。下次进入截图时，它直接作为待确认的选区出现，标注“上次取景框 · 1248 × 700”，`Enter` 确认并进入原位编辑；拖拽或单击别处则换成新的取景框。取消不更新它。记忆只存在这个标签页的这个网页里，导航到别的页面、关闭标签页或重启浏览器就清除，不写入条目、设置或导出。
- **取景框记的是元素，不是屏幕位置**：页面滚动了、窗口变了、内容刷新了，只要元素还在，取景框就跟着它走；沿用时页面自动滚动到让取景框完整落进窗口。找不到上次的元素，或找到的元素大小与上次相差超过 10% 时，沿用上次的页面位置与尺寸，并在选区上标明“没找到上次的元素”，由用户确认。自由拖出来的取景框没有元素，记的是页面位置与尺寸。
- **输出一致**：同一个取景框、同一个设备像素比，输出的像素尺寸相同——宽高由元素的宽高与边距决定，与元素在屏幕上的位置无关，取整规则固定；边距环里的像素一致。截取前等待页面稳定（连续两帧布局不变，最长 500 毫秒），扩展的遮罩一出现，页面的悬停样式随之清掉。
- **放不下**：取景框必须完整落在窗口里；放不下时，选区上提示“取景框比窗口大”，并给出两条出路：减小边距，或缩小浏览器的页面缩放。元素本身比窗口大时走元素路径，不含边距。
- 取景框里如果压着页面固定定位的浮层（客服挂件、吸顶导航），它们会像在页面上一样入图；预览里能看到。

## 2. 截取与像素处理

区域路径使用 `captureVisibleTab({ format: 'png' })` 获取真实视口像素。选区是视口 CSS 坐标，裁剪时按 `devicePixelRatio` 转源像素，夹紧到源图边界；零面积选区报错，不保存空文件。调用浏览器截图 API 前隐藏扩展遮罩和预览 UI，等待两帧完成重绘，避免把扩展界面拍入图片。

元素路径在离屏 surface 中克隆目标元素并栅格化，可覆盖超出视口的元素。克隆先执行匿名；跨域图片由扩展后台代取并内联，字体嵌入失败时跳过字体重试。surface 在成功、失败和取消时都要移除。元素资源缺失可能影响结果，预览必须让用户检查最终图片。

截图会话跑在页面里，页面自己的脚本能派发任何事件，所以会话只听用户本人的输入和扩展自己的触发：脚本伪造的点击、拖拽、按键和自定义事件既不能启动会话，也不能选区、切换匿名、切换水印、复制或取消。区域截取只拍发起截图的那个标签页，并且只在它仍是所在窗口里显示着的标签页时；其他标签页或窗口里的页面不能借扩展拍到用户正在看的内容，截取期间用户切走了标签页就丢弃图片。后台代取跨域图片只接受公网的 http(s) 地址，拒绝本机、局域网、链路本地和带账号的地址，不带凭据，只接收不超过入库上限的图片；不符合的资源保留原地址，由页面自己尝试加载。截图界面里的像素对页面自己的脚本可见，这一残余风险见 [RK-14](validation.md)。

默认使用 PNG 保存文字与图表细节。区域和元素在同一个选区内编辑界面执行标注与像素马赛克；编辑期间保留会话内的原始截取画布，并按操作顺序重绘，使撤销可靠。区域截图的分辨率以屏幕 `devicePixelRatio` 为上限；元素截图已按 2 倍像素比栅格化。入库的是**裁剪、匿名、马赛克和标注之后的图片字节**，不保留未处理的屏幕原图，也不把编辑操作另存为附件。缩略图可从持久图片重建。滚动拼接整页不属于当前截图范围。

## 3. 匿名与预览

DOM 匿名默认开启。区域截图在真实页面的身份元素上临时覆盖占位，截取后恢复；元素截图只修改离屏克隆。X/Twitter 使用稳定 `data-testid` 识别身份元素，通用页面可通过 `data-ann-identity` 标记。自动检测只提出候选区域，用户在预览中可以增加或删除马赛克框。

马赛克在最终像素上按块平均处理，块边界和设备像素比由同一纯函数计算。关掉自动匿名不等于关闭手工马赛克。截图处理默认全在本地，临时跨域资源只为当前元素栅格化，不写入记录或日志。

## 4. 保存与输出

一次截图有三种去处，互相独立：确认入库、复制、下载。资料库的“截图”视图可查看、重新下载和删除已入库的截图。

### 4.1 入库

确认入库时，在扩展 IndexedDB 的 `assets` 与 `entries` object store 中同事务保存处理后的 `Blob`、图片元数据和 `screenshot` 条目。保存失败不能显示成功，也不能仅因下载或复制成功就声称已入库；单独下载或复制失败不回滚已经成功的本地入库。入库统一使用 PNG 保持文字与图表细节，**入库的图片不带水印**：水印是对外分享时的署名，不是资料的一部分。从资料库重新下载得到的就是入库的图片。

`screenshot` 条目：`content` 为空串，`assetId` 指向刚保存的图片，`sourceUrl` 是采集页面；`title` 默认取页面标题，用户可以补标题、标签、备注与属性（字段见 [entry.md §3](entry.md)）。

### 4.2 复制与下载

复制与下载输出的都是**当前结果**：裁剪、匿名、马赛克与标注之后的图片；设置里启用了水印、且本次没有关掉时，再加上水印（§4.3）。

- **复制**：把图片以 PNG 写入剪贴板，可以直接粘贴到文档、聊天或设计工具。浏览器的剪贴板只可靠支持 PNG，所以复制与下载格式的设置无关。复制发生在用户在页面里的点击或按键之后，由页面里的脚本直接写入，不需要额外权限（[permissions.md §4](permissions.md)）。页面是 `http:` 时浏览器不开放剪贴板接口，复制按钮改为提示“此页面不允许复制，请下载”，下载照常可用。
- **下载**：格式取自设置——PNG（默认）、JPEG、WebP；JPEG 与 WebP 有质量（默认 0.9）。JPEG 不支持透明，透明处铺白色。文件名为 `AnnHub/screenshot-<时间>.<扩展名>`，扩展名随格式。格式与质量只作用于下载，不改变入库的字节。

### 4.3 品牌水印

署名用的水印，画在复制与下载的图片的一角，设置里启用后才出现（[extension.md §2.5](extension.md)）：

- **内容**：文字（至多 40 个字符，如账号名）、图片（PNG，不超过 512 KB，只保存在本机的偏好里，不进入条目，也不随导出）；可以只启用其中一种，也可以同时启用，图片在前、文字在后。
- **样式**：位置在四角里选（默认右下）、大小分小、中、大，透明度 20% 至 100%（默认 70%）。文字的墨色随它落在的背景在深浅之间切换（深色背景上用浅色字），任何背景上都读得清；图片按原样画出，不随背景换色；图片与文字共用同一个透明度。
- **排版**：图片与文字排成一行，不论在哪个角都自左向右读——图片在左、文字在右，两者之间隔半个字号——整行贴着所选的角，离相邻的两条边各留一段边距。大小同时定文字的字号和图片的高度：图片高度是字号的 1.5 倍，宽度按图片自己的比例；只有图片没有文字时，大小同样定图片的高度；很宽的图片收窄到不超过画布宽度的 40%。
- **预览**：编辑界面里显示水印，位置不可拖动；`W` 或状态条上的开关关掉本次的水印。
- **层次**：水印画在最上一层，不参与匿名与马赛克，也不是标注，不进撤销栈。

### 4.4 美化（R2）

给复制与下载的图片加上背景、留白、圆角和阴影，让截图能直接放进文章、聊天或幻灯片。美化是输出样式，不是资料的一部分：**入库的图片保持原样**（与水印同理），编辑界面里能预览合成后的样子。

- **入口**：工具栏上的“美化”按钮打开面板；面板贴在预览旁边，不盖住预览与工具栏，也不出窗口。面板里的改动立即预览，只影响本次截图，“复原”回到默认样式（输出画布比例回到“自由”）。设置里决定默认是否开启，以及面板的初始样式（[extension.md §2.5](extension.md)）。
- **控件**：每个控件只有一个名字。背景按名字区分，不用字母或数字编号；阴影是一个名为“阴影”的开关。改动任何一项都同时开启美化，让改动立刻看得见。键盘进入面板后落在它的第一个控件上，`Esc` 先关闭面板、焦点回到“美化”按钮。
- **参数**：

  | 参数         | 取值                                                                      |
  | ------------ | ------------------------------------------------------------------------- |
  | 背景         | 无、纯色 2 款（纯白、米色）、渐变 5 款（紫、蓝、绿、暖橙、深灰），共 8 款 |
  | 内边距       | 小 24、中 40、大 64（CSS 像素，随设备像素比放大）                         |
  | 圆角         | 0、12、24（CSS 像素）                                                     |
  | 阴影         | 开、关                                                                    |
  | 输出画布比例 | 自由，或比例预设里启用的比例（§1.3）                                      |

- **合成**：截图内容等比、完整地放在画布中央，不裁切；“自由”时画布 = 内容 + 内边距；选了比例时，在内边距之外把画布补足到目标比例，留白画在背景上。水印画在最终画布的一角（§4.3）。背景为“无”时画布透明，JPEG 下载铺白色。
- **预览**：预览在选区周围长大，超出视口时按比例缩小，工具栏随之移动，始终在窗口内、不盖住图；复制与下载仍是完整像素。参数是即时状态，重绘自会话里保留的原始截取画布，不进撤销栈。带着美化的预览上继续标注，标注落在指针指到的位置，入库的图片仍是不带美化的截取。
- **不做**：设备外框、模板、文案卡与自动平衡（[product.md §2.3](product.md)）。

### 4.5 导出

扩展的唯一用户导出是 Markdown + 已保存原图 ZIP（[storage.md §6](storage.md)）。`screenshot` 条目有自己的 Markdown，图片以相对链接指向同一份文件。只下载到系统目录、没有入库的文件不由扩展 ZIP 扫描或重新抓取。

## 5. 失败与清理

| 情况                                           | 处理                                                                               |
| ---------------------------------------------- | ---------------------------------------------------------------------------------- |
| 页面不允许截图、无活动标签页或图片解码失败     | 预览显示可读错误，保留取消入口，不写入记录                                         |
| 选区超界或面积为零                             | 在裁剪阶段拒绝，并允许重新选择                                                     |
| 元素中的跨域资源或字体失败                     | 尝试本地降级，在最终预览中让用户检查缺失内容                                       |
| IndexedDB 配额、图片写入或校验失败             | 保留当前预览供重试；不显示保存成功；配额不足时说明先导出内容、再删除不需要的条目   |
| 复制失败（页面是 `http:`、剪贴板被拒或无焦点） | 显示可读错误并保留图片与全部标注，给出“改为下载”；不影响已完成的编辑               |
| 水印图片损坏或读不出来                         | 本次不加图片水印，文字水印照常；设置页提示重新上传                                 |
| 取景框比窗口大（R3）                           | 选区上提示，给出“减小边距”与“缩小页面缩放”；元素本身比窗口大时走元素路径，不含边距 |
| 找不到上次的元素（R3）                         | 沿用上次的页面位置与尺寸，选区上标明，由用户确认或重新选择                         |
| 编码为 JPEG 或 WebP 失败                       | 改为 PNG 下载，并提示                                                              |
| 删除 `screenshot` 条目                         | 同一事务删除条目及其图片                                                           |

上表里“可读错误”都是本地化的短句，依据后台返回的稳定错误码生成（写入类错误码见 [entry.md §6](entry.md)；截取、代取图片和下载失败各有自己的码）；界面不显示浏览器或后台的原始信息。

退出会话时清理遮罩、离屏 surface、临时样式和监听器；重复触发先结束旧会话。完整的清理规则见 [storage.md §7](storage.md)。

## 6. 验收与测试

- 单测覆盖 CSS 坐标与 dpr 换算、边界夹紧、零面积、马赛克边界块和 alpha、身份元素检测、DOM 匿名恢复与元素克隆清理。
- 单测覆盖比例锁定的选区几何（各比例、视口边缘夹紧）、水印布局（四角位置、边距、三档大小、透明度；图片与文字同排、只有图片、过宽的图片）与读不出来的图片被跳过而文字照常、JPEG 的透明处铺白与 WebP 的质量参数。
- 后台能力测试覆盖可视区域截取、跨域资源代取、保存失败与下载/入库结果区分；截取只对发起的可见标签页、代取拒绝私有网络与非图片响应，是必测边界。
- 页面脚本伪造的事件（自定义事件、点击、拖拽、按键）不能启动或推进截图会话，也不能触发复制或切换水印，由单测和 E2E 共同覆盖。
- E2E 覆盖区域拖拽、元素单击、遮罩不入图、预览马赛克、匿名开关、取消清理和 SPA 页面。
- 编辑器 E2E 覆盖选区原位预览与尺寸标签、工具栏贴边与视口约束、矩形和文字落图、马赛克预览、撤销、下载后继续编辑、确认入库与失败后保留画布。
- 输出 E2E 覆盖：https 页面上点击“复制”后剪贴板里是 PNG，`http:` 页面给出提示并仍可下载；三种下载格式的扩展名与内容类型正确；启用水印后复制与下载的图片带水印而入库的图片不带，`W` 同时关掉图片与文字且只关掉本次；水印图片在预览、剪贴板、下载与入库图片的像素上验收：图片在前、文字在后，随位置、大小、透明度与背景明暗变化，读不出来的图片被跳过而文字照常；设置页修改格式、水印与比例预设后下一次截图生效；比例锁定下拖拽始终输出目标比例。
- 资产测试覆盖 Blob 与条目同事务、重启后读取、删除条目时图片同事务删除，以及 ZIP 的图片相对链接。
- 美化的单测覆盖合成几何纯函数（各比例的画布尺寸与内容位置、内边距、圆角、阴影不改变内容尺寸）与面板的摆放、控件的名字和上报；E2E 在预览、剪贴板和入库图片的像素上验收：面板不盖住预览与工具栏、`Esc` 先关面板，每个控件只有一个名字，八款背景各画成它自己的颜色（渐变从第一色到末色），内边距、圆角、阴影与各比例下内容完整居中，水印随背景明暗换色，改动即开启、复原回到默认样式，带美化的预览上标注落在指针处，复制得到带美化的图而入库的图片保持原样。
- R3 的 E2E 覆盖选区吸附高亮、方向键微调、`Shift` 锁定比例、选区确认与元素层级选择（`↑` `↓` 跳过外框相同的层级）。
- R3 的取景框用一个带切换条的夹具页验收：三种状态下，元素 + 24 CSS 像素边距的输出尺寸完全相同、边距环里的像素无差异；中间滚动页面或改变窗口大小后沿用上次取景框，框住的仍是同一块内容；元素找不到时给出提示并沿用位置与尺寸。
- 高风险截图链路变更先运行截图单测，再构建预加载扩展运行相关 Playwright E2E。
