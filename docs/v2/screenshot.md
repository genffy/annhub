# 截图采集与视觉 Fragment

> 层级：core
> 状态：R1 采集链路；R5.3 精确选区在阶段 V 之后排期；R5.1 美化与品牌、R5.2 导出增强后置，以 H-14 为门槛（范围状态见 [roadmap.md](roadmap.md)）
> 更新：2026-10-04

截图是 [采集链路](capture.md)的视觉入口，不建立独立学习系统。页面交互见 [扩展 PRD](extension.md)，资产字段、事务、本机交付和 ZIP 导出以[存储契约](storage.md)为准；`visual` 的字段与定位符以 [Fragment 契约](fragments.md)为准。

## 1. 用户路径

```text
快捷键或截图入口
  -> 拖拽区域 / 单击元素（R5.3：吸附、微调、比例锁定与选区确认）
  -> 原位预览并标注，检查匿名与马赛克
  -> 可选：美化合成与品牌水印（R5.1，后置）
  -> 确认后保存到截图集，或下载 PNG / JPEG / WebP、复制到剪贴板
  -> 用户主动填写描述、语境、核验确认与应用
  -> 转为 visual Fragment，在 Desktop 复习
```

快捷键为 `Ctrl+Shift+S`，macOS 为 `Cmd+Shift+S`。拖拽选择视口区域，单击选择元素；`Esc` 取消会话，`A` 切换 DOM 匿名。截图默认只是 ScreenshotRecord，不自动进入复习。只有用户主动完成 [L2 加工](processing.md)后才成为 `visual` Fragment；截图集与 Fragment 引用同一个 `assetId`，不复制图片。

### 1.1 选区内编辑

交互以微信截图的原位编辑方式为参考：进入模式后页面变暗；拖拽时选区保持明亮、显示蓝色边框和像素尺寸。截取完成后，图片直接占据原选区，不跳到居中预览卡片。浮动工具栏贴近选区右下角；空间不足时移到上方并约束在视口内。元素截图也使用同一编辑界面，超出视口的元素按比例缩小预览，但保存完整像素。窄视口下工具栏可横向滚动，不能遮住确认和取消操作。

选区精度（R5.3）：拖拽时对光标下的元素边缘实时吸附并高亮提示，起止点可吸附到元素矩形；确认前选区显示八向手柄，支持拖拽二次调边；方向键微调 1 像素，配合 `Shift` 每次 10 像素。拖拽中按住 `Shift` 临时锁定比例，也可锁定到 1:1、3:4、4:5、16:9 预设比例。

选区确认（R5.3）：拖拽松开后选区不再立即截取，而是保持可调——选区旁出现“确认选区 ↵ / 取消”，按 `Enter` 或点击“确认选区”后才进入原位编辑，`Esc` 取消会话。单击元素的路径不变，直接进入原位编辑。R5.3 之前松手即截取。

| 工具                   | 行为                                                                                        |
| ---------------------- | ------------------------------------------------------------------------------------------- |
| 矩形、椭圆、箭头、画笔 | 在图片上拖拽标注；支持红、黄、青、白、黑色                                                  |
| 马赛克                 | 拖拽指定像素区域，预览立即显示处理结果                                                      |
| 文字                   | 在图片上单击输入，回车提交，`Shift+Enter` 换行                                              |
| 撤销                   | 撤销最近一次人工标注；自动建议的马赛克区域可以单独移除                                      |
| 下载                   | 下载当前已处理的 PNG，继续保留编辑会话；R5.2（后置）起 PNG / JPEG / WebP 可选               |
| 复制图片（R5.2，后置） | 以 PNG 复制当前处理结果到剪贴板，继续保留编辑会话                                           |
| 美化（R5.1，后置）     | 打开衬底面板：背景、内边距、圆角、边框阴影与输出比例；R5.2 的平台尺寸预设也在面板的“输出”区 |
| 品牌（R5.1，后置）     | 打开水印面板：文字水印、LOGO 图章、位置与透明度，可套用或保存品牌预设                       |
| 取消、确认             | 分别丢弃本次截图、保存当前结果到截图集                                                      |

`Esc` 在文字输入期间先关闭输入框，再次按下才取消截图。保存或下载失败时保留图片与全部标注，允许重试。分享、翻译和表情工具不是当前 AnnHub 截图链路的一部分；真实发布动作（如发布到社交平台）同样不进入扩展域，截图产物以本地下载与截图集入库为终点。

### 1.2 美化与品牌合成（R5.1，后置）

进入条件：[H-14](validation.md) 通过（[D-02](validation.md) 已采纳）；在此之前本节是规格储备，不进入开发。

美化与品牌是编辑器的像素处理增强，不是社交分享功能：真实发布动作不在 AnnHub 域内，产物只落到本地下载与截图集入库。合成在原位完成：启用衬底后，画布在原选区外扩展出背景、内边距与水印；画布超出视口时按比例缩小预览，保存完整像素，与元素截图的预览规则一致。

| 能力                 | 行为                                                                                                                           |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 衬底背景             | 无 / 纯色 / 渐变，提供预设色板与自定义色                                                                                       |
| 内容排版             | 内边距、圆角、细边框与柔和阴影                                                                                                 |
| 输出比例             | 原始 / 1:1 / 3:4 / 4:5 / 16:9；非原始比例时内容等比完整置入，留白画在衬底上，不裁切内容                                        |
| 平台尺寸预设（R5.2） | 在面板“输出”区、比例选择的下面，作为“尺寸预设”下拉选择；只约束输出尺寸，见第 4 节                                              |
| 文字水印             | 自定义文案（如账号名或一句话），字号与透明度可调                                                                               |
| LOGO 图章            | 在设置页上传 PNG（不超过 512KB），仅存扩展本地，不进入学习记录、不跨端同步；上传、更换与移除都在设置页的“截图品牌”一节         |
| 水印位置             | 四角与边中九宫格，可调边距与不透明度                                                                                           |
| 品牌预设             | 把衬底、比例、圆角与水印样式整体存为命名预设，一键套用，可保存多个；编辑器里只套用与保存，重命名与删除在设置页的“截图品牌”一节 |

美化参数是工具条面板的即时状态，立即生效并可复原，不进入标注撤销栈。水印绘制在最终合成层，不参与匿名与马赛克。平台尺寸预设只约束输出尺寸，见第 4 节；编辑器内不出现任何平台上传或账号操作。

## 2. 截取与像素处理

区域路径使用 `captureVisibleTab({ format: 'png' })` 获取真实视口像素。选区是视口 CSS 坐标，裁剪时按 `devicePixelRatio` 转源像素，夹紧到源图边界；零面积选区报错，不保存空文件。调用浏览器截图 API 前隐藏扩展遮罩和预览 UI，等待两帧完成重绘，避免把扩展界面拍入图片。

元素路径在离屏 surface 中克隆目标元素并栅格化，可覆盖超出视口的元素。克隆先执行匿名；跨域图片由扩展后台代取并内联，字体嵌入失败时跳过字体重试。surface 在成功、失败和取消时都要移除。元素资源缺失可能影响结果，预览必须让用户检查最终图片。

默认使用 PNG 保存文字与图表细节。区域和元素在同一个选区内编辑界面执行标注与像素马赛克；编辑期间保留会话内的原始截取画布，并按操作顺序重绘，使撤销可靠。美化合成（R5.1）沿用非破坏式重绘：编辑器维护一份合成配置（衬底、内边距、圆角、边框阴影、输出比例、水印样式），每次变更从原始截取画布按三段重绘——底图（含遮罩与标注）、装饰合成、品牌水印，不修改已截取的源像素；比例画布与留白几何由纯函数计算，便于脱离 DOM 测试。区域截图的分辨率以屏幕 `devicePixelRatio` 为上限，合成放大只做插值不增加细节；元素截图已按 2 倍像素比栅格化。最终持久化的是**裁剪、匿名、马赛克、标注以及美化与水印合成之后的图片字节**，不保留未处理的屏幕原图，也不把编辑操作另存为附件。缩略图可从持久图片重建。滚动拼接整页不属于当前截图范围。

## 3. 匿名与预览

DOM 匿名默认开启。区域截图在真实页面的身份元素上临时覆盖占位，截取后恢复；元素截图只修改离屏克隆。X/Twitter 使用稳定 `data-testid` 识别身份元素，通用页面可通过 `data-ann-identity` 标记。自动检测只提出候选区域，用户在预览中可以增加或删除马赛克框。

马赛克在最终像素上按块平均处理，块边界和设备像素比由同一纯函数计算。关掉自动匿名不等于关闭手工马赛克。截图处理默认全在本地，临时跨域资源只为当前元素栅格化，不写入学习记录或日志。

## 4. 保存、引用与交付

“确认入库”与“下载”是两个独立动作；截图集页面可查看、重新下载和删除截图。确认入库时，在扩展 IndexedDB 的 `assets` 与 `screenshots` object store 中同事务保存处理后的 `Blob` 和截图元数据。保存失败不能显示成功，也不能仅因下载成功就声称已入库；单独下载失败不回滚已经成功的本地入库。R5.2 扩展下载格式为 PNG（默认）、JPEG（默认质量 0.9）与 WebP，并可把当前处理结果以 PNG 复制到剪贴板（需要 `clipboardWrite` 权限）；文件名沿用 `AnnHub/screenshot-<时间>` 前缀并按格式选择扩展名。截图集入库统一使用 PNG 保持文字与图表细节，格式与质量选择只作用于下载与复制，不改变入库字节。平台尺寸预设（小红书 3:4 约 1080×1440、1:1 1080×1080；X 建议 16:9 1600×900、单图不超过 5MB）在美化面板“输出”区的“尺寸预设”下拉里选择，位于输出比例之下，只约束输出尺寸。

转为 `visual` 时，`content` 是用户对关键细节的描述，`excerpt` 由该描述加页面语境构成，`sourceUrl` 保留原页面，`locator` 使用图片 `assetId` 与可选的归一化矩形。用户明确确认核验步骤并填写准备如何使用或继续观察后保存。Desktop 先接收文字 Fragment，再按同一 ID 接收图片 BLOB；传输失败时保留文字和待发送图片状态，不能制造第二份图片或丢失表单。

扩展的唯一用户导出是 Markdown + 已保存原图 ZIP。截图集条目有自己的 Markdown 说明；关联 `visual` 的 Markdown 以相对链接指向同一份图片。只下载到系统目录、未进入截图集的文件不由扩展 ZIP 扫描或重新抓取。

## 5. 失败与清理

| 情况                                       | 处理                                                             |
| ------------------------------------------ | ---------------------------------------------------------------- |
| 页面不允许截图、无活动标签页或图片解码失败 | 预览显示可读错误，保留取消入口，不写入记录                       |
| 选区超界或面积为零                         | 在裁剪阶段拒绝，并允许重新选择                                   |
| 元素中的跨域资源或字体失败                 | 尝试本地降级，在最终预览中让用户检查缺失内容                     |
| IndexedDB 配额、图片写入或校验失败         | 保留当前预览供重试；不显示保存成功                               |
| Desktop 未启动或图片交付失败               | 扩展本地资产与待发送任务保留，文字 Fragment 可独立阅读           |
| 保存后删除截图集条目                       | 只删截图引用；仍被 Fragment 引用的图片继续保留                   |
| LOGO 素材加载失败或损坏                    | 以无 LOGO 状态继续编辑，水印面板提示重新上传，不阻塞截图会话     |
| 剪贴板写入失败（权限被拒或无焦点）         | 显示可读错误并保留画布，可改用下载；不影响已完成编辑             |
| 品牌预设损坏或超限                         | 跳过损坏条目并回退默认参数；保存失败时保留当前参数，不显示已保存 |

退出会话时清理遮罩、离屏 surface、临时样式和监听器；重复触发先结束旧会话。完整引用计数与孤儿资产清理见 [storage.md](storage.md)。

## 6. 验收与测试

- 单测覆盖 CSS 坐标与 dpr 换算、边界夹紧、零面积、马赛克边界块和 alpha、身份元素检测、DOM 匿名恢复与元素克隆清理。
- 后台能力测试覆盖可视区域截取、跨域资源代取、保存失败与下载/入库结果区分。
- E2E 覆盖区域拖拽、元素单击、遮罩不入图、预览马赛克、匿名开关、取消清理和 SPA 页面。
- 编辑器 E2E 覆盖选区原位预览与尺寸标签、工具栏贴边与视口约束、矩形和文字落图、马赛克预览、撤销、下载后继续编辑、确认入库与失败后保留画布。
- 资产测试覆盖 Blob 与截图元数据同事务、重启后读取、截图转 `visual` 共用 ID、Desktop 图片缺失后重试、删除引用不误删共享图片，以及无 Desktop 时 ZIP 的图片相对链接。
- 编辑器单测覆盖合成几何与水印布局纯函数（比例画布与留白、圆角矩形、水印位置与边距）、品牌预设序列化与损坏回退、LOGO 大小校验。
- 编辑器 E2E 覆盖美化面板即时重绘且不影响标注撤销、比例画布留白、水印与 LOGO 落位、JPEG/WebP 下载、PNG 复制到剪贴板，以及选区吸附高亮、方向键微调、比例锁定与选区确认，设置页“截图品牌”一节的 LOGO 上传、更换、移除和预设重命名、删除。
- 高风险截图链路变更先运行截图单测，再构建预加载扩展运行相关 Playwright E2E。
