# 截图采集

> 层级：core
> 状态：采集链路；精确选区（R3）在阶段 V 之后排期（范围状态见 [roadmap.md](roadmap.md)）
> 更新：2026-10-07

截图是 [采集链路](capture.md) 的视觉入口，保存为 `screenshot` 条目。页面交互见 [扩展 PRD](extension.md)，资产字段、事务和 ZIP 导出以 [存储契约](storage.md) 为准，条目字段见 [条目契约](entry.md)。

## 1. 用户路径

```text
快捷键或截图入口
  -> 拖拽区域 / 单击元素（R3：吸附、微调、比例锁定与选区确认）
  -> 原位预览并标注，检查匿名与马赛克
  -> 确认后保存为 screenshot 条目，或下载 PNG
  -> 在资料库的“截图”视图查看，补标题、标签、备注与属性
```

快捷键为 `Ctrl+Shift+S`，macOS 为 `Cmd+Shift+S`。拖拽选择视口区域，单击选择元素；`Esc` 取消会话，`A` 切换 DOM 匿名。

### 1.1 选区内编辑

交互以微信截图的原位编辑方式为参考：进入模式后页面变暗；拖拽时选区保持明亮、显示蓝色边框和像素尺寸。截取完成后，图片直接占据原选区，不跳到居中预览卡片。浮动工具栏贴近选区右下角；空间不足时移到上方并约束在视口内。元素截图也使用同一编辑界面，超出视口的元素按比例缩小预览，但保存完整像素。窄视口下工具栏可横向滚动，不能遮住确认和取消操作。

| 工具                   | 行为                                                   |
| ---------------------- | ------------------------------------------------------ |
| 矩形、椭圆、箭头、画笔 | 在图片上拖拽标注；支持红、黄、青、白、黑色             |
| 马赛克                 | 拖拽指定像素区域，预览立即显示处理结果                 |
| 文字                   | 在图片上单击输入，回车提交，`Shift+Enter` 换行         |
| 撤销                   | 撤销最近一次人工标注；自动建议的马赛克区域可以单独移除 |
| 下载                   | 下载当前已处理的 PNG，继续保留编辑会话                 |
| 取消、确认             | 分别丢弃本次截图、保存当前结果为 `screenshot` 条目     |

`Esc` 在文字输入期间先关闭输入框，再次按下才取消截图。保存或下载失败时保留图片与全部标注，允许重试。分享、翻译、表情、美化合成与品牌水印不是截图链路的一部分（[D-18](validation.md)）；真实发布动作（如发布到社交平台）同样不进入扩展域，截图产物以本地下载与入库为终点。

### 1.2 精确选区（R3，阶段 V 之后排期）

选区精度：拖拽时对光标下的元素边缘实时吸附并高亮提示，起止点可吸附到元素矩形；确认前选区显示八向手柄，支持拖拽二次调边；方向键微调 1 像素，配合 `Shift` 每次 10 像素。拖拽中按住 `Shift` 临时锁定比例，也可锁定到 1:1、3:4、4:5、16:9 预设比例。

选区确认：拖拽松开后选区不再立即截取，而是保持可调——选区旁出现“确认选区 ↵ / 取消”，按 `Enter` 或点击“确认选区”后才进入原位编辑，`Esc` 取消会话。单击元素的路径不变，直接进入原位编辑。R3 之前松手即截取。

## 2. 截取与像素处理

区域路径使用 `captureVisibleTab({ format: 'png' })` 获取真实视口像素。选区是视口 CSS 坐标，裁剪时按 `devicePixelRatio` 转源像素，夹紧到源图边界；零面积选区报错，不保存空文件。调用浏览器截图 API 前隐藏扩展遮罩和预览 UI，等待两帧完成重绘，避免把扩展界面拍入图片。

元素路径在离屏 surface 中克隆目标元素并栅格化，可覆盖超出视口的元素。克隆先执行匿名；跨域图片由扩展后台代取并内联，字体嵌入失败时跳过字体重试。surface 在成功、失败和取消时都要移除。元素资源缺失可能影响结果，预览必须让用户检查最终图片。

截图会话跑在页面里，页面自己的脚本能派发任何事件，所以会话只听用户本人的输入和扩展自己的触发：脚本伪造的点击、拖拽、按键和自定义事件既不能启动会话，也不能选区、切换匿名或取消。区域截取只拍发起截图的那个标签页，并且只在它仍是所在窗口里显示着的标签页时；其他标签页或窗口里的页面不能借扩展拍到用户正在看的内容，截取期间用户切走了标签页就丢弃图片。后台代取跨域图片只接受公网的 http(s) 地址，拒绝本机、局域网、链路本地和带账号的地址，不带凭据，只接收不超过入库上限的图片；不符合的资源保留原地址，由页面自己尝试加载。

默认使用 PNG 保存文字与图表细节。区域和元素在同一个选区内编辑界面执行标注与像素马赛克；编辑期间保留会话内的原始截取画布，并按操作顺序重绘，使撤销可靠。区域截图的分辨率以屏幕 `devicePixelRatio` 为上限；元素截图已按 2 倍像素比栅格化。最终持久化的是**裁剪、匿名、马赛克和标注之后的图片字节**，不保留未处理的屏幕原图，也不把编辑操作另存为附件。缩略图可从持久图片重建。滚动拼接整页不属于当前截图范围。

## 3. 匿名与预览

DOM 匿名默认开启。区域截图在真实页面的身份元素上临时覆盖占位，截取后恢复；元素截图只修改离屏克隆。X/Twitter 使用稳定 `data-testid` 识别身份元素，通用页面可通过 `data-ann-identity` 标记。自动检测只提出候选区域，用户在预览中可以增加或删除马赛克框。

马赛克在最终像素上按块平均处理，块边界和设备像素比由同一纯函数计算。关掉自动匿名不等于关闭手工马赛克。截图处理默认全在本地，临时跨域资源只为当前元素栅格化，不写入记录或日志。

## 4. 保存与引用

“确认入库”与“下载”是两个独立动作；资料库的“截图”视图可查看、重新下载和删除。确认入库时，在扩展 IndexedDB 的 `assets` 与 `entries` object store 中同事务保存处理后的 `Blob`、图片元数据和 `screenshot` 条目。保存失败不能显示成功，也不能仅因下载成功就声称已入库；单独下载失败不回滚已经成功的本地入库。入库统一使用 PNG 保持文字与图表细节；下载文件名使用 `AnnHub/screenshot-<时间>.png`。

`screenshot` 条目：`content` 为空串，`assetId` 指向刚保存的图片，`sourceUrl` 是采集页面；`title` 默认取页面标题，用户可以补标题、标签、备注与属性（字段见 [entry.md §3](entry.md)）。

扩展的唯一用户导出是 Markdown + 已保存原图 ZIP（[storage.md §6](storage.md)）。`screenshot` 条目有自己的 Markdown，图片以相对链接指向同一份文件。只下载到系统目录、没有入库的文件不由扩展 ZIP 扫描或重新抓取。

## 5. 失败与清理

| 情况                                       | 处理                                         |
| ------------------------------------------ | -------------------------------------------- |
| 页面不允许截图、无活动标签页或图片解码失败 | 预览显示可读错误，保留取消入口，不写入记录   |
| 选区超界或面积为零                         | 在裁剪阶段拒绝，并允许重新选择               |
| 元素中的跨域资源或字体失败                 | 尝试本地降级，在最终预览中让用户检查缺失内容 |
| IndexedDB 配额、图片写入或校验失败         | 保留当前预览供重试；不显示保存成功           |
| 删除 `screenshot` 条目                     | 同一事务删除条目及其图片                     |

退出会话时清理遮罩、离屏 surface、临时样式和监听器；重复触发先结束旧会话。完整的清理规则见 [storage.md §7](storage.md)。

## 6. 验收与测试

- 单测覆盖 CSS 坐标与 dpr 换算、边界夹紧、零面积、马赛克边界块和 alpha、身份元素检测、DOM 匿名恢复与元素克隆清理。
- 后台能力测试覆盖可视区域截取、跨域资源代取、保存失败与下载/入库结果区分；截取只对发起的可见标签页、代取拒绝私有网络与非图片响应，是必测边界。
- 页面脚本伪造的事件（自定义事件、点击、拖拽、按键）不能启动或推进截图会话，由单测和 E2E 共同覆盖。
- E2E 覆盖区域拖拽、元素单击、遮罩不入图、预览马赛克、匿名开关、取消清理和 SPA 页面。
- 编辑器 E2E 覆盖选区原位预览与尺寸标签、工具栏贴边与视口约束、矩形和文字落图、马赛克预览、撤销、下载后继续编辑、确认入库与失败后保留画布。
- 资产测试覆盖 Blob 与条目同事务、重启后读取、删除条目时图片同事务删除，以及 ZIP 的图片相对链接。
- R3 的 E2E 覆盖选区吸附高亮、方向键微调、比例锁定与选区确认。
- 高风险截图链路变更先运行截图单测，再构建预加载扩展运行相关 Playwright E2E。
