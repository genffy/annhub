# 界面视觉基线

> 层级：product
> 状态：目标体验真源
> 更新：2026-10-08

本文只定义扩展的视觉基线：品牌色、外观、类型编码与版式原则。页面结构与交互见 [扩展 PRD](extension.md)；令牌取值、组件与画板在[设计稿](../design/v2/README.md)里维护，不在本文重复。

## 1. 品牌色

- 品牌紫（logo 的 `#673AB8`）是唯一的强调色，用于主按钮、选中态和焦点环；它进入产品内的主操作，而不只出现在 logo 里。
- 中性色（表面、文字、描边）沿用现有令牌，不另立一套。
- 成功、警告、危险、信息等语义色只表达状态，并且总是配图标和文字，不单靠颜色（[extension.md §7.2](extension.md)）。

## 2. 外观

- 亮色与暗色两套令牌成对定义；应用页、弹窗和页面内浮层都提供两种外观，默认跟随系统。
- 页面内的菜单、提示和截图工具栏叠在网页之上，使用自己的表面色，不改变用户正在阅读的网页。

## 3. 条目类型与高亮的编码

- 两种条目类型各有固定的图标和一个辅助色相：剪藏 `bookmark`、截图 `scan`。高亮是剪藏里的标注，不是类型；它的入口、导航项和高亮视图用 `highlighter` 图标，颜色来自五色调色板（黄、绿、蓝、粉、紫）。
- 类型出现的任何地方（导航、列表行、徽标、详情抽屉）都同时有图标和文字；色相只做辅助，不单独承担含义，也不大面积铺底。
- 正文里的高亮不只靠底色：同时带下划线，有备注的带一个小标记；颜色有文字名称，供读屏朗读。颜色只是用户的选择，不承担含义。
- 属性的六种类型同样用图标加文字区分：文本、列表、数字、复选框、日期、日期时间。

## 4. 版式原则

- **一套壳**：左侧导航固定在左，右侧内容滚动；应用页、设置页和弹窗共用，不出现顶部导航版式（[extension.md §2.2](extension.md)）。
- **内容优先**：导航、筛选和属性面板用中性色，让条目内容（原文与图片）最显眼；强调色只给当前位置与主操作。
- **密度**：应用页的基础字号略大于页面内浮层；列表行足够高，长标题和多个标签换行时不挤成一团；控件与卡片使用统一圆角，细边框加轻阴影。
- **属性行**：左侧是类型图标与名称，右侧是值编辑器，名称列对齐；与 Obsidian 的 Properties 同构，用户一眼认得出。
- **状态**：保存中、成功、失败、缺失都有文字，不只靠颜色或图标。
