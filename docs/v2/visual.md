# 界面视觉基线

> 层级：product
> 状态：目标体验真源
> 更新：2026-10-07

本文只定义扩展的视觉基线：品牌色与外观。页面结构与交互见 [扩展 PRD](extension.md)；令牌取值、组件与画板在[设计稿](../design/v2/README.md)里维护，不在本文重复。

## 1. 品牌色

- 品牌紫（logo 的 `#673AB8`）是唯一的强调色，用于主按钮、选中态和焦点环；它进入产品内的主操作，而不只出现在 logo 里。
- 中性色（表面、文字、描边）沿用现有令牌，不另立一套。
- 成功、警告、危险、信息等语义色只表达状态，并且总是配图标和文字，不单靠颜色（[extension.md §9.1](extension.md)）。

## 2. 外观

- 亮色与暗色两套令牌成对定义；扩展页和采集窗口都提供两种外观，默认跟随系统。
- 采集窗口叠在网页之上，使用自己的表面色，不改变用户正在阅读的网页。
