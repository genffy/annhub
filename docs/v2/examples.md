# 场景与走查

> 层级：scenario
> 状态：当前产品方向
> 更新：2026-10-07

本文用具体的人、具体的时间点和具体的界面行为，把[产品定位](product.md)和各规则文档串成可演示、可验收的场景。它同时是演示脚本、端到端测试脚本和对外案例的素材来源，因此数字与行为必须与真源一致。

页面体验见 [扩展 PRD](extension.md)。

## 1. 场景边界

首版处理的来源：

- 技术文档、RFC、博客和事故复盘。
- 行业文章、研究报告和产品说明。
- 竞品页面、设计案例和图表说明。
- 公开会议纪要、决策记录和项目复盘。

核心输入是网页文本选区和网页截图。典型用户见 [product.md §2.1](product.md)。

## 3. 验收场景

每个场景都是一条可直接执行的脚本。通过标准写成可观察的结果。

| 场景       | Given                    | When                                                                         | Then                                                                                                                                                       |
| ---------- | ------------------------ | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A 断网采集 | 断网                     | 剪藏一段文字、高亮一段文字、截一张图，搜索它们，点“导出内容”                 | 三条都保存成功并可搜索；ZIP 含三份 Markdown 和一份图片，Markdown 的图片链接有效                                                                            |
| B 属性     | 资料库里有三种类型的条目 | 给其中一条添加文本属性 `project`，按它筛选，再导出                           | 注册表出现类型为文本的 `project`；其他条目上同名属性只能是文本；筛选命中该条；导出的 frontmatter 含 `project`；使用数为 1 时不可删除该属性，清空值后可删除 |
| C 同一套壳 | 打开资料库               | 依次进入全部、剪藏、高亮、截图、属性、设置，再点工具栏图标，并把窗口缩到最窄 | 每个页面都是左导航 + 右内容，导航顺序一致；窗口最窄时导航折叠为左侧图标栏，没有顶部导航                                                                    |
