# 场景与走查

> 层级：scenario
> 状态：当前产品方向
> 更新：2026-10-08

本文用具体的人、具体的时间点和具体的界面行为，把[产品定位](product.md)和各规则文档串成可演示、可验收的场景。它同时是演示脚本、端到端测试脚本和对外案例的素材来源，因此数字与行为必须与真源一致。

页面体验见 [扩展 PRD](extension.md)。

## 1. 场景边界

首版处理的来源：

- 技术文档、RFC、博客和事故复盘。
- 行业文章、研究报告和产品说明。
- 竞品页面、设计案例和图表说明。
- 公开会议纪要、决策记录和项目复盘。

核心输入是网页文本选区、整块内容（一条推文、一篇文章）和网页截图。典型用户见 [product.md §2.1](product.md)。

## 3. 验收场景

每个场景都是一条可直接执行的脚本。通过标准写成可观察的结果。

| 场景                 | Given                                                | When                                                                                                                                                                                         | Then                                                                                                                                                       |
| -------------------- | ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A 断网采集           | 断网                                                 | 剪藏一段选中的文字、剪藏一个区块、截一张图并点“复制”；打开区块那条，高亮一句话；搜索它们，点“导出内容”                                                                                       | 三条都保存成功并可搜索；剪贴板里是 PNG；高亮刷新后仍在；ZIP 含两份剪藏 Markdown（其中一份带 `==…==`）、一份截图 Markdown 和一份图片，截图的图片链接有效    |
| B 属性               | 资料库里有两种类型的条目                             | 给其中一条添加文本属性 `project`，按它筛选，再导出                                                                                                                                           | 注册表出现类型为文本的 `project`；其他条目上同名属性只能是文本；筛选命中该条；导出的 frontmatter 含 `project`；使用数为 1 时不可删除该属性，清空值后可删除 |
| C 同一套壳           | 打开资料库                                           | 依次进入全部、剪藏、高亮、截图、属性、设置，再打开一条剪藏的阅读视图，点工具栏图标，并把窗口缩到最窄                                                                                         | 每个页面都是左导航 + 右内容，导航顺序一致；窗口最窄时导航折叠为左侧图标栏，没有顶部导航                                                                    |
| D 重拍同一区域（R3） | 一个带切换条的页面，有三种状态（如套餐的月、季、年） | 第一种状态下进入截图，悬停在卡片上按 `↑` 选到包含切换条与全部卡片的容器，边距选 24，`Enter` 确认并入库；切到第二种状态，再按截图快捷键，上次取景框已经在，`Enter` 确认并入库；第三种状态同样 | 三张截图的像素尺寸完全相同；与第一张相比，只有切换条与价格文字不同，最外圈的边距环里没有差异；中间滚动一下页面再截，框住的仍是同一块内容                   |
