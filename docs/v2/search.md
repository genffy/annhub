# 检索与筛选契约

> 层级：core
> 状态：目标契约
> 更新：2026-10-10

本文定义扩展对条目的基础搜索、筛选和排序。匹配规则只在共享领域层实现一次，各页面不各自复制。

## 1. 搜索范围

默认搜索条目的 `content`（按 Markdown 渲染后的纯文本，不含语法记号）、`context`、`note`、`sourceUrl`、`sourceHost`，剪藏里每条高亮的 `quote` 与 `note`，以及 `properties` 里文本与列表类型的值（含 `title`、`tags`）。不搜索图片字节、整页正文，也不搜索数字、复选框与日期属性的值。

“全部”视图搜索两种类型；“剪藏”“截图”视图只在对应 `type` 内搜索；“高亮”视图以高亮为单位搜索，见第 5 节。结果数分别标识（[extension.md §2.3](extension.md)）。

## 2. 匹配

查询和候选字段都使用共享的归一化（[entry.md §6](entry.md)）。输入按 Unicode 空白拆成非空词；每个词必须在上述任一字段中以归一化子串形式命中，词可以落在不同字段。中文与其他无空格语言直接按子串匹配；基础搜索不依赖分词、词干化或在线模型。空查询只执行筛选。

## 3. 筛选

基础维度：`type`（仅“全部”视图）、`sourceHost`、`tags`、创建时间，以及任意属性；“高亮”视图另有颜色。同维度多选取 OR，跨维度取 AND，搜索条件再与筛选结果取 AND。

- 时间范围采用 `[start, end)` 的 UTC epoch 毫秒；用户选择日历日期时，页面先按其本地时区换算边界。
- **属性筛选**：先从属性注册表选一个属性，运算符由它的类型决定，多个属性条件之间取 AND。

| 属性类型   | 运算符                 |
| ---------- | ---------------------- |
| `text`     | 包含、等于             |
| `list`     | 含有某一项             |
| `number`   | 等于、大于、小于、区间 |
| `checkbox` | 是、否                 |
| `date`     | 区间                   |
| `datetime` | 区间                   |

- 筛选条件写入 URL，刷新后可恢复。

## 4. 排序与分页

有搜索词时，每个词取其命中字段的最高权重并求和：`content=5`、`title=4`、`note=4`、高亮的 `quote=4` 与 `note=3`、`tags=3`、其他文本与列表属性 `=2`、`context=2`、`sourceHost`/`sourceUrl=1`。分数降序后按 `createdAt` 降序、`id` 升序。无搜索词时按 `createdAt` 降序、`id` 升序。每页默认 50 条，翻页使用稳定排序键，不因同一时间戳而重复或漏项。

## 5. “高亮”视图

以单条高亮为单位：

- 搜索：每个词必须命中这条高亮的 `quote`、`note`，或所属剪藏的 `title`、`tags`、`sourceHost`；归一化与匹配规则同第 2 节。
- 筛选：颜色按高亮自己的 `color`；时间按高亮的 `createdAt`；来源、标签与属性按所属剪藏计算，同维度 OR、跨维度 AND。
- 排序与分组：按所属剪藏分组；组内按高亮在正文中的位置排序；组按组内最新高亮的 `createdAt` 降序，同时间戳按剪藏 `id` 升序。无搜索词与有搜索词时的分组顺序一致，搜索只决定哪些高亮留下。

## 6. 性能

扩展可以维护 IndexedDB 搜索索引，但候选结果必须经过上述共享规则复核。索引是派生数据：与条目在同一事务里更新，缺失或对不上条目时由条目重建，不改变结果语义（存放见 [storage.md §3](storage.md)）。没有搜索词的查询——列表、类型与来源筛选、高亮视图——不读取检索文本。1 万条条目的常用查询以首屏 50 条、冷启动后第二次查询为基准，目标 200ms 内返回；搜索不得阻塞页面交互。
