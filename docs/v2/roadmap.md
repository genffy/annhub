# 产品路线图

> 层级：vision
> 状态：当前计划；交付状态的唯一入口
> 更新：2026-10-08

本文是阶段顺序、发布范围、交付状态和发布门禁的唯一真源。页面体验见 [扩展](extension.md)，字段见 [条目契约](entry.md) 和 [存储](storage.md)。尚未验证的假设与待确认的路线调整见 [validation.md](validation.md)。产品先后收窄为浏览器扩展（[D-17](validation.md)）和三种采集（[D-18](validation.md)），并把高亮挪进资料库（[D-19](validation.md)）：Desktop、复习、跨端同步、碎片加工与页面高亮标记不在路线图内。**当前代码仍是收窄之前的实现**（碎片、采集窗口、页面高亮标记、四个互相独立的实体），R1、R2 把它迁移到本目录的目标契约。

## 1. 排期原则

1. 先统一数据模型，再改采集与页面：R1 完成条目与两种页面采集（剪藏、截图），R2 再做应用页、阅读与高亮、属性界面。
2. 每个版本都必须在断网时可降级运行。
3. 当前没有需要兼容的用户存量数据；直接实现最新契约。导出、测试和文档是功能的一部分，不在版本末尾补做。
4. 不为未进入当前版本的能力提前增加 UI 入口。
5. 交付完成不等于验证完成：用户是否真的使用，由 [validation.md](validation.md) 的阶段 V 回答。

## 2. 版本总览

| 版本                  | 用户结果                                                                     | 状态   | 备注                                     |
| --------------------- | ---------------------------------------------------------------------------- | ------ | ---------------------------------------- |
| R0 产品方向收敛       | 从早期专项场景收敛为浏览器扩展里的三种采集                                   | 完成   | 文档契约已更新；代码尚未迁移             |
| R1 统一条目与页面采集 | 剪藏（选区与区块）、截图保存为同一种带属性的条目，可检索并导出               | 未开始 | 当前代码是旧实现，R1 把它收敛到 entry.md |
| R2 应用页、阅读与属性 | 所有扩展页面左导航右内容；在资料库读剪藏并高亮；条目属性与属性页；弹窗紧凑壳 | 进行中 | 设计稿已按新契约重画；代码未开始         |
| V 内测验证            | 用真实使用回答 A 级假设，再决定后续范围                                      | 未开始 | 进入条件与准备项见 V 节                  |
| R3 精确选区           | 截图选区吸附、手柄、比例锁定与确认                                           | 未开始 | 阶段 V 之后排期                          |

**状态词**：`未开始` → `进行中` → `范围完成`（清单全部勾选且验收条件满足，尚未经真实用户验证）→ `已验证`（对应假设在 validation.md 中通过）。`未触发` 表示条件性范围的进入条件还没有满足。

## R0：产品方向收敛

- [x] 删除手机端、桌面客户端与复习的产品形态和专属实现（D-17）。
- [x] 删除专项学习产品文档；文档层移出碎片与三步加工，统一条目与属性契约（D-18）。
- [x] 高亮挪进资料库：页面里只做剪藏与截图，不留标记；剪藏增加区块入口并存 Markdown（D-19）。
- [x] 建立产品定位、Extension PRD 和指标真源。

## R1：统一条目与页面采集

**产品承诺**：用户可以用剪藏（选区或整块）和截图保存网页内容，两者是同一种条目，带来源与属性；断网也能保存、检索，并把本地内容与已保存图片导出为一份可独立阅读的 ZIP。

- [ ] 按 [entry.md](entry.md) 建立条目（含剪藏里的高亮）与属性注册表的类型、运行时校验器与稳定错误码。
- [ ] 用一个 IndexedDB 保存条目、图片与属性注册表；现有的高亮、剪藏、截图三份存储并为统一的 `entries`；截图元数据与原图 `Blob` 同事务保存，删除 `screenshot` 条目时图片同事务删除，删除 `clip` 时高亮一并删除。
- [ ] 按 [search.md](search.md) 实现基础搜索、筛选（含属性）与稳定排序，1 万条条目的首屏查询 200ms 内返回。
- [ ] 选区菜单两项：剪藏、截图。剪藏一次点击保存，约 3 秒内可撤销，提示里可编辑标题、标签、备注。
- [ ] 区块剪藏：悬停入口、Markdown 转换（链接、标题层级、列表）、区块自己的永久链接与页面 meta；触发方式、识别范围与默认值按 [D-20](validation.md) 确认后的结论。
- [ ] 按[截图契约](screenshot.md)完成选区内编辑的边界验收，以及区域/元素截图的入库。
- [ ] 采集时按类型预设附加属性，页面 meta 取得到就写入。
- [ ] 提供唯一的“导出内容”命令：每条条目一份带 frontmatter 的 Markdown（剪藏里的高亮写成 `==…==`），加已保存的原图，打成一个 ZIP；大量截图时有配额提示、ZIP 逐 Blob 读取和图片缺失报告。
- [ ] 记录 [metrics.md §9](metrics.md) 的事件，只记录事件，不记录正文。
- [ ] 删除不再属于当前产品的旧消息、设置、测试入口与文案（碎片、采集窗口、媒体片段、LLM、页面高亮标记与回访恢复、连续高亮模式）。

**验收**：在普通文章、信息流和 SPA 页面中创建选区剪藏与区块剪藏，页面上不出现任何标记；区域与元素截图都能完成匿名、预览、入库；同名属性类型一致；断网后仍能保存、查看和导出，截图的 ZIP 图片链接有效。

## R2：应用页、阅读与属性

**产品承诺**：所有扩展页面都是左导航 + 右内容；用户能在资料库里读剪藏并划出高亮；能在详情里给条目加属性，并在属性页管理它们。

- [ ] 一个应用页，左导航 + 右内容：全部、剪藏、高亮、截图、属性、设置；路由与筛选写入 URL。
- [ ] 条目详情抽屉与属性面板：添加、编辑、清除属性，值按类型校验。
- [ ] 阅读视图与库内高亮：在原文里选中文字创建、改色、写备注、删除；“高亮”视图按剪藏分组；有高亮的剪藏原文只读；渲染不解析原始 HTML，图片不联网加载（[D-21](validation.md)）。
- [ ] 属性页：注册表、使用数、类型预设勾选、删除与“删除未使用”。
- [ ] 工具栏弹窗改为紧凑左右壳；窄窗口折叠为图标栏；键盘与读屏可用；亮暗外观。
- [ ] 首次使用引导卡与各视图的空状态。
- [x] [设计稿](../design/v2/README.md)按新契约重做（D-18、D-19）。

**验收**：所有扩展页面都是左导航 + 右内容，没有顶部导航；在资料库里创建的高亮刷新后仍在，导出时写成 `==…==`；属性使用数正确，使用中的属性不可删除；ZIP 的 frontmatter 带着属性。

## V：内测验证

**产品承诺**：用真实使用回答最危险的假设，再决定后续范围。R1、R2 范围完成后，[用户故事](user-stories.md)里没有任何一条得到真实用户验证；继续增加功能只会扩大未验证的面积。V 不为 R3 及之后的范围开发新能力，准备项只涉及分发、指南和指标可读性。

**进入条件**：R1、R2 范围完成，且第 5 节的未决验收项已补齐。

**准备（P0）**

- [ ] 扩展内测构建（需要商店开发者账号）：用商店的私有可见性发布，仅指定测试者可安装；商店对各种可见性的审核流程相同，需预留审核时间（[D-08](validation.md) 已采纳）。
- [ ] 安装指南与首次使用说明；知情同意说明（只看聚合指标，不收集正文）；商店要求的隐私披露与权限说明。
- [ ] 设置页的本地指标面板覆盖 M-03、M-11、M-19、M-20、M-21（[metrics.md §5、§10](metrics.md)）。
- [ ] 首次使用走查第 1 轮（E-03），按结果修正文案。

**运行（P0）**：自用先行（E-01）、设计伙伴内测（E-02）、每周指标回顾、价值问卷与退出访谈（E-05）。

| 时间         | 事项                                                  |
| ------------ | ----------------------------------------------------- |
| T+0 周       | 自用开始（E-01）；首次使用走查第 1 轮已在准备项中完成 |
| T+2 周       | 设计伙伴开始使用                                      |
| T+3 ~ T+5 周 | 每周 20 分钟回访；每周指标回顾                        |
| T+6 周       | 价值问卷与退出访谈                                    |
| T+7 周       | 决策评审：汇总结论，决定 R3 及后续范围                |

T+0 从准备项全部完成之日起算。参与者、入选条件、数据口径与假设判据见 [validation.md §2、§3](validation.md)。

**退出标准**：A 级假设（H-04、H-16）均有结论（通过、未通过或需修订），每个未通过项有处理决定，决策评审已完成。

**明确不做**：V 期间开发 R3 范围；收费或测试定价，也不公开上架；上传用户的正文、URL 或标题。

## R3：精确选区

**进入条件**：阶段 V 结束，无其他门槛。

- [ ] 拖拽实时吸附元素边缘并高亮提示，起止点可吸附元素矩形。
- [ ] 选区确认前八向手柄二次调边；方向键微调 1 像素（`Shift` 每次 10 像素）。
- [ ] 比例锁定：`Shift` 临时锁定，或按预设比例拖拽。
- [ ] 选区确认：拖拽松开后选区保持可调，出现“确认选区 / 取消”；`Enter` 或点击确认后进入原位编辑，`Esc` 取消；单击元素路径不变。

**验收**：吸附、手柄与微调在普通页面和 SPA fixture 可用，与单击元素截图共存不冲突；比例锁定下拖拽始终输出目标比例；拖拽后须确认选区才进入编辑，`Esc` 取消会话。

**明确不做**：真实发布/分享动作、平台 API 与社媒账号授权；美化、品牌水印、尺寸预设与导出格式选择（已移出，D-18）；多选区拼接与整页滚动截图。

## 4. 通用发布门禁

每个版本必须同时满足：

- TypeScript compile 通过；领域逻辑全量单测通过；Extension 关键路径 E2E 通过。
- Markdown ZIP 的内容、frontmatter、来源与图片相对链接检查通过；断网时可独立导出。
- 所有扩展页面的版式检查通过：左导航 + 右内容，没有顶部导航。
- 对外分发的构建可由目标用户自行安装：扩展已通过商店审核（可见性按分发范围选择）。
- 受影响文档和错误恢复路径更新。
