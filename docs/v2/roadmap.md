# 产品路线图

> 层级：vision
> 状态：当前计划；交付状态的唯一入口
> 更新：2026-10-11

本文是阶段顺序、发布范围、交付状态和发布门禁的唯一真源。页面体验见 [扩展](extension.md)，字段见 [条目契约](entry.md) 和 [存储](storage.md)。尚未验证的假设与待确认的路线调整见 [validation.md](validation.md)。代码按本目录的契约实现；与契约不符的代码、消息、设置、测试入口和文案，在实现时一并删除。

## 1. 排期原则

1. 先统一数据模型，再做采集与页面：R1 完成条目与两种页面采集（剪藏、截图），R2 再做应用页、阅读与高亮、属性界面。
2. 每个版本都必须在断网时可降级运行。
3. 没有需要迁移的用户数据，直接实现本目录的契约。导出、测试和文档是功能的一部分，不在版本末尾补做。
4. 不为未进入当前版本的能力提前增加 UI 入口。
5. 交付完成不等于验证完成：用户是否真的使用，由 [validation.md](validation.md) 的阶段 V 回答。

| R2 应用页、阅读与属性 | 所有扩展页面左导航右内容；在资料库读剪藏并高亮；条目属性与属性页；弹窗紧凑壳；截图的下载格式、水印、比例预设与极简美化 | 进行中   | 第 5 节的真机走查项待关闭 |

**状态词**：`未开始` → `进行中` → `范围完成`（清单全部勾选且验收条件满足，尚未经真实用户验证）→ `已验证`（对应假设在 validation.md 中通过）。`未触发` 表示条件性范围的进入条件还没有满足。

## R1：统一条目与页面采集

**产品承诺**：用户可以用剪藏（选区或整块）和截图保存网页内容，两者是同一种条目，带来源与属性；断网也能保存、检索，并把本地内容与已保存图片导出为一份可独立阅读的 ZIP。

- [x] 按 [entry.md](entry.md) 建立条目（含剪藏里的高亮）与属性注册表的类型、运行时校验器与稳定错误码。
- [x] 用一个 IndexedDB 保存条目、图片与属性注册表；截图元数据与原图 `Blob` 同事务保存，删除 `screenshot` 条目时图片同事务删除，删除 `clip` 时高亮一并删除。
- [x] 按 [search.md](search.md) 实现基础搜索、筛选（含属性）与稳定排序，1 万条条目的首屏查询 200ms 内返回。
- [x] 选区菜单两项：剪藏、截图。剪藏一次点击保存，约 3 秒内可撤销，提示里可编辑标题、标签、备注。
- [x] 区块剪藏（[capture.md §6.2](capture.md)）：悬停入口与区块模式；帖子、代码块、表格、图、引用、一节、文章七种区块的识别，首发平台规则是 X 的帖子和 Medium 的文章；Markdown 转换（链接、标题层级、列表、代码块、表格，去掉页面自己的界面）；区块自己的永久链接与页面 meta；整体开关与按网站停用。（真实页面的识别走查按第 5 节真机项进行。）
- [x] 按[截图契约](screenshot.md)完成选区内编辑的边界验收、区域/元素截图的入库，以及复制到剪贴板（PNG，https 页面；`http:` 页面提示下载）。
- [x] 采集时按类型预设附加属性，页面 meta 取得到就写入。
- [x] 提供唯一的“导出内容”命令：每条条目一份带 frontmatter 的 Markdown（剪藏里的高亮写成 `==…==`），加已保存的原图，打成一个 ZIP；大量截图时有配额提示、ZIP 逐 Blob 读取和图片缺失报告。
- [x] 记录 [metrics.md §9](metrics.md) 的事件，只记录事件，不记录正文。（R2 界面对应的 `highlight.created` 与 `entry.property_edited` 随 R2 接线。）
- [x] 仓库里不属于本目录契约的代码、消息、设置、测试入口与文案一并删除（根 `AGENTS.md`）。

**验收**：在普通文章、信息流和 SPA 页面中创建选区剪藏与区块剪藏，页面上不出现任何标记；区域与元素截图都能完成匿名、预览、入库，也能复制到剪贴板；同名属性类型一致；断网后仍能保存、查看和导出，截图的 ZIP 图片链接有效。

## R2：应用页、阅读与属性

**产品承诺**：所有扩展页面都是左导航 + 右内容；用户能在资料库里读剪藏并划出高亮；能在详情里给条目加属性，并在属性页管理它们。

- [x] 一个应用页，左导航 + 右内容：全部、剪藏、高亮、截图、属性、设置；路由与筛选写入 URL。
- [x] 条目详情抽屉与属性面板：添加、编辑、清除属性，值按类型校验。
- [x] 阅读视图与库内高亮：在原文里选中文字创建、改色、写备注、删除；“高亮”视图按剪藏分组；有高亮的剪藏原文只读；渲染不解析原始 HTML，剪藏里的图片只显示占位。
- [x] 属性页：注册表、使用数、类型预设勾选、删除与“删除未使用”。
- [x] 设置页的“截图”部分与它驱动的行为（[screenshot.md §1.3、§4](screenshot.md)）：下载格式（PNG、JPEG、WebP）、文字水印（位置、大小、透明度）、比例预设与选区条上的比例锁定、美化的默认开关与默认样式；复制与下载应用文字水印与美化，入库的图片保持原样。
- [x] 图片水印的输出（[screenshot.md §4.3、§5](screenshot.md)）：设置里的 PNG 与文字一起画在复制与下载的图片上，图片在前、文字在后，随位置、大小与透明度变化；`W` 同时开关；入库的图片不带；图片读不出来时只画文字。
- [ ] 设置页的图片水印预览与重新上传提示（[screenshot.md §4.3、§5](screenshot.md)）：设置页能上传和移除图片，预览还只画文字，读不出来的图片也没有提示。
- [x] 极简美化（[screenshot.md §4.4](screenshot.md)）：工具栏上的美化面板——背景、内边距、圆角、阴影、输出画布比例；即时预览、可复原，不进标注撤销栈；只作用于复制与下载。
- [x] 工具栏弹窗是紧凑左右壳；窄窗口折叠为图标栏；键盘与读屏可用；亮暗外观。
- [x] 首次使用引导卡与各视图的空状态。
- [x] [设计稿](../design/v2/README.md)完成。

**验收**：所有扩展页面都是左导航 + 右内容，没有顶部导航；在资料库里创建的高亮刷新后仍在，导出时写成 `==…==`；属性使用数正确，使用中的属性不可删除；ZIP 的 frontmatter 带着属性；设置页里的截图下载格式、水印、比例预设与美化默认样式保存后，下一次截图立即生效；启用美化后，复制与下载得到带背景与留白的图片，入库的图片保持原样。

## V：内测验证

**产品承诺**：用真实使用回答最危险的假设，再决定后续范围。R1、R2 范围完成后，[用户故事](user-stories.md)里没有任何一条得到真实用户验证；继续增加功能只会扩大未验证的面积。V 不为 R3 及之后的范围开发新能力，准备项只涉及分发、指南和指标可读性。

**进入条件**：R1、R2 范围完成，且第 5 节的未决验收项已补齐。

**准备（P0）**

- [ ] 扩展内测构建（需要商店开发者账号）：用商店的私有可见性发布，仅指定测试者可安装；商店对各种可见性的审核流程相同，需预留审核时间。阶段 V 免费内测，商业化形态留到阶段 V 之后评估。
- [ ] 安装指南与首次使用说明；知情同意说明（只看聚合指标，不收集正文）；商店要求的隐私披露与权限说明（[permissions.md](permissions.md)）。
- [ ] 设置页的本地指标面板覆盖 M-03、M-11、M-19、M-20、M-21、M-22、M-23、M-24（[metrics.md §5、§10](metrics.md)）。
- [ ] 首次使用走查第 1 轮（E-03），按结果修正文案。

**运行（P0）**：自用先行（E-01）、设计伙伴内测（E-02）、每周指标回顾、价值问卷与退出访谈（E-05）。

| 时间         | 事项                                                  |
| ------------ | ----------------------------------------------------- |
| T+0 周       | 自用开始（E-01）；首次使用走查第 1 轮已在准备项中完成 |
| T+2 周       | 设计伙伴开始使用                                      |
| T+3 ~ T+5 周 | 每周 20 分钟回访；每周指标回顾                        |
| T+6 周       | 价值问卷与退出访谈                                    |
| T+7 周       | 决策评审：汇总结论，决定 R3 及后续范围                |

T+0 从准备项全部完成之日起算。参与者、入选条件、数据口径与假设判据见 [validation.md §2、§3](validation.md)。

**退出标准**：A 级假设（H-04、H-16）均有结论（通过、未通过或需修订），每个未通过项有处理决定，决策评审已完成。

**明确不做**：V 期间开发 R3 范围；收费或测试定价，也不公开上架；上传用户的正文、URL 或标题。

## R3：精确选区与可重复的取景框

**进入条件**：阶段 V 结束，无其他门槛。

- [x] 拖拽实时吸附元素边缘并高亮提示，起止点可吸附元素矩形。
- [x] 选区确认前八向手柄二次调边；方向键微调 1 像素（`Shift` 每次 10 像素）。
- [x] 比例锁定：拖拽中按住 `Shift` 临时锁定当前比例（预设比例的锁定在 R2）。
- [x] 选区确认：拖拽松开后选区保持可调，出现“确认选区 / 取消”；`Enter` 或点击确认后进入原位编辑，`Esc` 取消；单击元素路径不变。
- [x] 元素层级：悬停元素时 `↑` 选上一级、`↓` 回到下一级，跳过外框与当前元素完全相同的层级。
- [x] 元素 + 边距：选中元素后在选区条上选边距（0、8、16、24、32 CSS 像素或自定义），取景框 = 元素外框向四周外扩这个边距。
- [x] 沿用上次取景框：同一标签页、同一网页里记住最近一次的取景框（以元素为锚点），下次截图时作为待确认的选区出现；元素找不到时沿用位置与尺寸并提示；取景框比窗口大时提示（[screenshot.md §1.4](screenshot.md)）。

**验收**：吸附、手柄与微调在普通页面和 SPA fixture 可用，与单击元素截图共存不冲突；`Shift` 锁定比例下拖拽始终输出当前比例；拖拽后须确认选区才进入编辑，`Esc` 取消会话。同一个带切换条的夹具页在三种状态下，用“元素 + 24 CSS 像素边距”各截一张：三张图的像素尺寸完全相同，边距环里的像素无差异；中间滚动页面或改变窗口大小后沿用上次取景框，框住的仍是同一块内容。

**明确不做**：真实发布/分享动作、平台 API 与社媒账号授权；多选区拼接与整页滚动截图。

## 4. 通用发布门禁

每个版本必须同时满足：

- TypeScript compile 通过；领域逻辑全量单测通过；Extension 关键路径 E2E 通过。
- Markdown ZIP 的内容、frontmatter、来源与图片相对链接检查通过；断网时可独立导出。
- 所有扩展页面的版式检查通过：左导航 + 右内容，没有顶部导航。
- 对外分发的构建可由目标用户自行安装：扩展已通过商店审核（可见性按分发范围选择）。
- 权限、隐私政策里的权限表和商店的权限说明三者一致；一次完整使用（采集、阅读、导出）期间，扩展自己发出的网络请求只有截图时代取的页面内图片（[permissions.md §1](permissions.md)）。
- 受影响文档和错误恢复路径更新。
