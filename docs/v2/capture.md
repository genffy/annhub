# 采集规则（L1）

> 层级：core
> 更新：2026-10-07

## 1. 职责

采集层把用户的一次“这个值得保留”的指认，转换为语境完整、可追溯、可继续加工的 `FragmentRecord` 草稿。

核心不变量：**没有语境的内容不能直接进入学习核心。**

页面级交互以 [扩展 PRD](extension.md) 为准。

## 2. 保存层级

| 用户意图           | 实体      | 是否加工 |
| ------------------ | --------- | -------- |
| 保留页面位置和备注 | Highlight | 否       |
| 保存一段内容供查阅 | Clip      | 否       |
| 准备理解并应用     | Fragment  | 是       |

采集入口必须让用户理解这三者的差别。自动化不得把 Highlight 或 Clip 静默升级为 Fragment。

## 3. 通用流程

```text
指认内容
  -> 提取 content
  -> 提取 excerpt
  -> 记录来源与标题
  -> 生成定位符
  -> 用户确认或修正
  -> 进入 L2 主动加工
  -> 校验并落库
```

自动能力失败时，优先降级到用户修正，而不是丢弃已输入内容。

## 4. 载体

| 载体     | content            | excerpt            | locator                  |
| -------- | ------------------ | ------------------ | ------------------------ |
| 网页     | 选区文本           | 所在句、段或内容块 | DOM selector + offset    |
| PDF      | 选区文本           | 所在段落或页面摘要 | 页码 + rect              |
| 截图     | 用户写下的关键细节 | 描述 + 页面语境    | 图片 assetId + 相对 rect |
| 视频     | 区间摘要或转写     | 前后关键上下文     | startMs / endMs          |
| 音频     | 区间摘要或转写     | 前后关键上下文     | startMs / endMs          |
| 手工输入 | 用户正文           | 用户补充背景       | none                     |

R1 优先保证网页文本、手工写下的短篇 `inspiration` 和来自网页的截图可靠。手工灵感须写触发背景，使用本地来源与 `none` locator；长篇随笔不属于 AnnHub。截图需要原页面 URL、用户描述、可理解的页面语境与稳定附件 ID；图片在本地资产库中独立保存。区域/元素截取、匿名、裁剪和预览流程以 [screenshot.md](screenshot.md) 为准；其他载体沿用同一契约逐步接入。PDF 载体不在当前路线图中，阶段 V 之后按 [H-15](validation.md) 的结果评估（[D-09](validation.md) 已采纳）。

## 5. 语境提取

`excerpt` 是能让用户重新理解碎片的最小上下文，不等于整个页面正文。

规则：

- 必须包含 `content` 的归一化结果。
- 优先取完整句子或语义段落，避免从固定字符数生硬截断。
- 超长时围绕选区向两侧截断，保证目标内容仍在结果中。
- 自动提取失败时允许手工编辑。
- 不把导航、按钮、页脚、广告和扩展自身 UI 混入上下文。

## 6. 来源与定位

采集层记录：

```text
sourceUrl
sourceHost
sourceTitle
capturedAt
locator
```

信息流页面应尽力解析内容项永久链接，而不是只保存列表页地址。平台规则集中维护，新增站点通过追加规则实现，不散落在业务模块中。

DOM selector 的优先级：稳定测试属性、稳定 ID、过滤后的 class、结构路径。定位失败使用 `{ type: 'none' }`，不阻塞保存。

## 7. 去重

采集时按内容、来源和上下文预检重复：

- 命中后展示已有记录。
- 用户确认后仍可保存。

## 8. 失败处理

| 失败点           | 处理                     |
| ---------------- | ------------------------ |
| 上下文提取失败   | 进入手工编辑             |
| 永久链接解析失败 | 使用当前页面 URL         |
| 定位符生成失败   | 保存 `none`              |
| 附件保存失败     | 保留文本草稿并允许重试   |
| 碎片落库失败     | 保留完整表单，不自动关闭 |

任何自动步骤都不能导致用户已经输入的理解、核验或应用内容丢失。

## 9. 非目标

- 不做无确认的一键批量收藏。
- 不默认保存完整页面正文。
- 不把截图字节直接嵌入 Fragment 消息；图片通过附件 ID 引用独立保存的字节。
- 不让站点适配逻辑散落在各业务模块中。
