# 浏览器扩展 PRD

> 层级：product
> 状态：目标体验真源
> 更新：2026-10-07

本文定义浏览器扩展的产品职责、信息架构、交互流程、状态和验收标准。DOM 与消息实现见根目录 `AGENTS.md`。

## 1. 产品职责

Extension 只负责三件事：

1. 在原始网页中指认内容。
2. 保留来源、语境与定位，保存为统一的条目。
3. 让用户检索、整理属性，并随时导出。

Extension 不提供通用笔记编辑器。

## 2. 信息架构

### 2.1 页面内入口

用户选中文本后显示选区菜单：

| 操作（中文 / English） | 图标          | 结果                           |
| ---------------------- | ------------- | ------------------------------ |
| 剪藏 / Clip            | `bookmark`    | 一次点击保存原文和语境         |
| 高亮 / Highlight       | `highlighter` | 在页面留下视觉标记，可添加备注 |
| 截图 / Screenshot      | `scan`        | 进入区域或元素截图             |

顺序固定为剪藏、高亮、截图。菜单必须使用图标加短文本，不依赖位置测试。

```text
选中文本后，在选区旁出现：
┌────────────────────────────────────────────────────┐
│ [bookmark] 剪藏 | [highlighter] 高亮 | [scan] 截图 │
└────────────────────────────────────────────────────┘
```

悬停或键盘聚焦约 300ms 后，动作旁出现一句后果，让三种保存方式的差别在入口就看得见（[US-CAP-01](user-stories.md)）：

| 动作 | 提示（中文）                    |
| ---- | ------------------------------- |
| 剪藏 | 保存原文和语境，之后查阅        |
| 高亮 | 只在页面留痕，可加备注          |
| 截图 | 框选区域或单击元素 · 保存为图片 |

这组文案是否让用户分清三种保存方式，由 [H-18](validation.md) 的首次使用走查（E-03）验证，未通过时先调整文案。英文界面使用对应的英文译文，语言选择见第 2.7 节。

### 2.2 应用页：左导航 + 右内容

**所有扩展页面都是“左侧导航 + 右侧内容”**：资料库的各个视图、属性页、设置页和工具栏弹窗共用同一套壳，导航在所有页面里位置与顺序一致。不使用顶部导航；窗口变窄时导航折叠为左侧的图标栏，而不是换成顶栏。

```text
┌────────────────────────┬──────────────────────────────────────────────────────────┐
│ AnnHub             [«] │ 全部                   [搜索条目...                    ] │
│                        │ 类型 v  来源 v  标签 v  时间 v  属性 v      共 128 条    │
│ [library]  全部   128  ├──────────────────────────────────────────────────────────┤
│ [bookmark] 剪藏    71  │ [剪藏] Retries can amplify an outage when the            │
│ [highlighter] 高亮 33  │        dependency is already saturated.                  │
│ [scan]     截图    24  │        engineering.example.com · 3 天前  #reliability    │
│                        │ [高亮] 指数退避加抖动，先退避再叠加随机抖动              │
│ ────────────────────── │        sre.example.org · 昨天  #retry                    │
│ [tags]     属性    10  │ [截图] p99 延迟曲线（缩略图）                            │
│ [settings] 设置        │        sre.example.org · 周二                            │
│                        │                                                          │
│ [download] 导出内容    │                                                          │
│ 已用 126 MB            │                                                          │
└────────────────────────┴──────────────────────────────────────────────────────────┘
```

| 导航（中文 / English） | 路由            | 内容                     |
| ---------------------- | --------------- | ------------------------ |
| 全部 / All             | `#/all`         | 三种类型的统一列表       |
| 剪藏 / Clips           | `#/clips`       | 只含剪藏                 |
| 高亮 / Highlights      | `#/highlights`  | 只含高亮，按页面分组     |
| 截图 / Screenshots     | `#/screenshots` | 只含截图，画廊           |
| 属性 / Properties      | `#/properties`  | 属性注册表               |
| 设置 / Settings        | `#/settings`    | 采集偏好、数据、本地指标 |

- 应用页只有一个 HTML，用 hash 路由；浏览器的扩展“选项”入口打开同一页面的 `#/settings`。
- 导航栏底部放“导出内容 / Export content”（唯一的导出命令，[storage.md §6](storage.md)）、存储用量和截图快捷键提示。设置只通过导航进入，不在别处重复。
- 导航可折叠为图标栏，窗口宽度不足时默认折叠；折叠后图标有文字提示，仍可键盘操作。具体宽度与断点见[设计稿](../design/v2/README.md)。
- 内容区随窗口自适应；列表类视图限制最大行宽以保证可读，画廊与属性表占满。
- 当前视图、筛选条件和抽屉里打开的条目都写入 URL hash，刷新后恢复。

### 2.3 视图

- **全部 / 剪藏**：每行显示类型图标、原文摘要、标题、来源主机、相对时间和标签；截图行显示缩略图。顶部有搜索、筛选条和条目总数；类型筛选只在“全部”里出现。搜索与筛选口径见 [search.md](search.md)。
- **高亮**：按来源页面分组，组头是页面标题、主机和条数；行里显示颜色、原文和备注，操作有“回到来源”。
- **截图**：画廊网格，每块是缩略图、标题和来源主机；悬停出现下载与删除。
- 点击一条条目打开右侧的详情抽屉（第 4 节）。
- 不展示“收藏数”之类的成就指标。

### 2.4 属性页

属性注册表的管理界面，借鉴 Obsidian Web Clipper 的属性类型表（[market.md §4.2](market.md)）。

| 列         | 内容                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| 名称与类型 | 类型图标 + 名称；`tags` 置顶并锁定                                       |
| 默认值     | 新条目附加该属性时使用的初值，可空                                       |
| 使用数     | 带有该属性值的条目数                                                     |
| 预设       | 剪藏、高亮、截图三列勾选：采集该类型时自动附加；`title`、`tags` 固定勾选 |
| 操作       | 删除：使用数为 0 且非内置才可用                                          |

- 新建属性：名称 + 类型 + 可选默认值，按 [entry.md §5.3](entry.md) 校验。
- 顶部的“删除未使用”一次清理使用数为 0 的自定义属性，先列出将被删除的名称。
- 使用中的属性不可改类型，也不提供重命名（[entry.md §5.3](entry.md)）。

### 2.5 设置页

只放三类东西：

- **采集**：默认高亮颜色；截图默认是否匿名。
- **数据**：导出内容、存储用量、异常残留资产的报告与清理（[storage.md §7](storage.md)）。
- **本地指标**：阶段 V 期间的聚合数字（[metrics.md §10](metrics.md)），不展示正文。

快捷键只显示当前绑定，并链接到浏览器的快捷键设置页。

### 2.6 工具栏弹窗

点击浏览器工具栏图标打开同一套壳的紧凑版；它也是 `chrome://` 等页面内入口失效时的兜底。

```text
┌────────────────┬────────────────────────────────────────────────────┐
│ [library]      │ 全部 · 最近 5 条                    在资料库中打开 │
│ [bookmark]     ├────────────────────────────────────────────────────┤
│ [highlighter]  │ [剪藏] Retries can amplify an outage...            │
│ [scan]         │ [高亮] 指数退避加抖动，先退避再叠加随机抖动        │
│                │ [截图] p99 延迟曲线                                │
│                │ [剪藏] 幂等键应在请求首次落库时生成                │
│ [settings]     │ [高亮] 重试预算按服务端计更稳妥                    │
├────────────────┴────────────────────────────────────────────────────┤
│ 选中网页文字即可保存 · Cmd+Shift+S 截图                             │
└─────────────────────────────────────────────────────────────────────┘
```

- 左侧图标栏对应全部、剪藏、高亮、截图（带数量角标）和设置；右侧显示当前类型最近 5 条，点击在资料库里打开该条目，“在资料库中打开”进入完整页面。
- 弹窗不提供编辑。

### 2.7 界面语言

界面语言随浏览器界面语言（[D-15](validation.md)）：中文系语言显示中文，其他语言显示英文，没有手动切换。选区菜单、应用页、弹窗、截图工具栏、错误提示和 Markdown ZIP 的章节标题都按这个语言显示；扩展清单里的名称、描述和快捷键说明也有两种语言。保存到条目里的用户内容不翻译。本文的中文文案是界面的中文版本，英文版与它一一对应。

## 3. 三种采集的交互

采集规则见 [capture.md](capture.md)，这里只写用户看得到的部分。

- **剪藏**：点击“剪藏”立即保存，不打开窗口。保存后出现约 3 秒的提示“已剪藏 · 撤销 · 编辑”：撤销删除刚保存的条目；编辑在选区旁打开小气泡，可改标题、标签、备注，“更多属性”在资料库里打开这条条目。保存失败时提示错误与“重试”，选区保持。
- **高亮**：点击“高亮”在页面留下标记并保存，可添加备注、换颜色；回访同一页面时标记恢复；在页面上删除高亮即删除这条条目。连续高亮模式 `Alt+H` / `Cmd+Shift+H` 进入，每次选中创建一条，`Esc` 退出。
- **截图**：`Ctrl+Shift+S` / `Cmd+Shift+S` 或菜单进入；拖拽区域或单击元素，在选区内直接标注、匿名、加马赛克，再确认入库或单独下载；入库后出现在“截图”视图。完整契约见 [截图采集](screenshot.md)。

## 4. 条目详情与属性编辑

点击列表里的条目，在右侧抽屉打开详情；`Esc` 或点击遮罩关闭。窄窗口里抽屉占满内容区。

```text
┌──────────────────────────────────────────────────────────────────────┐
│ [bookmark] 剪藏 · Retries and backpressure         [回到来源] [删除] │
├──────────────────────────────────────────────────────────────────────┤
│ 原文                                                                 │
│ > Retries can amplify an outage when the dependency is               │
│ >   already saturated.                                               │
│ 备注  [对照复盘文档里的流量曲线。                                ]   │
├──────────────────────────────────────────────────────────────────────┤
│ 属性                                                                 │
│ [text]      title        Retries and backpressure                    │
│ [list]      tags         reliability ×   retry ×   +                 │
│ [list]      author       Jane Doe ×   +                              │
│ [calendar]  published    2026-09-12                                  │
│ [text]      project      支付重试                                    │
│ [checkbox]  reviewed     [ ]                                         │
│ [+ 添加属性]                                                         │
│ 只读  source: engineering.example.com/retries · created: 2026-10-07  │
└──────────────────────────────────────────────────────────────────────┘
```

- 标题可直接改。原文、图片按类型显示；`screenshot` 显示可放大的图片和下载。
- **可编辑**：标题、备注、全部属性；`clip` 与 `screenshot` 还可改 `sourceUrl`（会把定位符置为 `none`）；`clip` 的原文与语境可改；`highlight` 的原文与 `sourceUrl` 只读，因为页面标记靠它们恢复。`type` 与 `id` 不可改。
- **添加属性**：输入名称，从注册表补全（候选里显示类型图标）；注册表里没有的名称要先选类型，创建后即进入注册表。保留名被拒绝并说明原因。值编辑器按类型：文本是单行输入，列表是标签输入，数字、日期、日期时间用对应控件，复选框是勾选。清空等于未设置。
- 删除条目前确认；删除 `screenshot` 条目同时删除它的图片。
- 改动在失焦或点击保存时写入；写入失败保留已输入的内容并显示错误与重试。

## 5. 空状态

- **首次使用**：资料库显示引导卡，三句话说明剪藏、高亮、截图各是什么，并给出“打开示例页面”；可关闭。示例页只存在于演示，不混入用户的库。
- **某个视图为空**：显示对应的入口提示，例如“截图”为空时写明 `Cmd+Shift+S`。
- **无搜索结果**：保留当前筛选器，并提供“清除筛选”，不显示导入或营销信息。

激活口径见 [metrics.md §2](metrics.md)，首次理解成本的验证见 [H-18](validation.md)。

## 6. 错误与恢复

- 保存失败（写入或配额）：不显示成功；截图保留预览与全部标注，编辑中的标题、备注和属性保留输入，都可重试；配额不足时提示导出，保存前先做配额校验（[storage.md §3](storage.md)）。
- 页面脚本不可信：选区菜单与截图会话只响应用户本人的输入和扩展自己的触发（[screenshot.md §2](screenshot.md)）。
- 图片缺失：条目仍可阅读，并提示“图片缺失”。
- 导出：生成失败时显示原因和未导出项，不把不完整的 ZIP 标记为成功。

## 7. 快捷键与可访问性

### 7.1 快捷键

| 快捷键                         | 功能                               |
| ------------------------------ | ---------------------------------- |
| `Alt+H` / `Cmd+Shift+H`        | 连续高亮模式                       |
| `Ctrl+Shift+S` / `Cmd+Shift+S` | 截图模式                           |
| `Esc`                          | 关闭菜单、取消截图、关闭抽屉与气泡 |

### 7.2 可访问性

- 选区菜单、截图工具栏和应用页的主流程都能只用键盘完成。
- 壳的导航是导航地标，当前视图用 `aria-current` 标出；折叠为图标栏后仍有可读名称。
- 抽屉打开时焦点进入并被限制在其中，关闭后回到触发位置。
- 颜色不是状态的唯一表达：类型有图标和文字，属性类型有图标和文字。
- 屏幕阅读器能读出条目类型、标题和来源。

## 8. 验收标准

1. 在普通文章、信息流和 SPA 页面均可创建带来源、语境和永久链接的剪藏与高亮；回访页面时高亮恢复。
2. 剪藏一次点击保存，不打开窗口，约 3 秒内可撤销；选区到菜单出现小于 150ms，本地写入的 95 分位小于 300ms。
3. 区域与元素截图都能完成匿名、标注和入库，入库的图片出现在“截图”视图。
4. 三种条目共用同一个属性面板：可添加内置或自定义属性，同名属性类型一致，保留名与超限值被拒绝。
5. 属性页的使用数正确，使用中的属性不可删除，“删除未使用”可用。
6. 资料库可按类型、来源、标签、时间和属性筛选并搜索，条件写入 URL 并在刷新后恢复。
7. 所有扩展页面（应用页各视图、设置、弹窗）都是左导航 + 右内容；窗口变窄时导航折叠为图标栏，不出现顶部导航。
8. 断网时仍能采集、查询、编辑和导出；ZIP 里的 frontmatter 带着属性，Markdown 图片链接均有效。
9. 保存失败不丢失已输入的内容与截图预览。
10. 浏览器界面为英文时，扩展的每个界面都显示英文，不出现中文；为中文时不出现英文的 “Entry”（数据实体名除外）。
11. [examples.md §3](examples.md) 的场景 A 到 C 通过。
