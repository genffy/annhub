Backoff and retry

Retries can amplify an outage when the dependency is already saturated. Instead of retrying immediately, wait base × 2^n and add a random factor between 0 and 1 so that clients do not retry in lockstep.

Exponential backoff

The three-step approach: compute the delay, add jitter, cap the total budget. Retry budgets counted server side are more robust than client-side caps because they see every caller at once.

  • Compute the delay from the attempt number
  • Add uniform jitter
  • Cap the total retry budget

The code

function backoff(attempt: number): number {
  const base = 100 * 2 ** attempt
  return Math.min(base + Math.random() * base, 5000)
}
