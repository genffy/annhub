# 浮层样式与命名空间

> 适用范围：`entrypoints/content/` 的全部浮层样式（`content.css` 与会话注入的样式）；上级约定见 [../AGENTS.md](../AGENTS.md)。

- 浮层样式全部挂在 `[data-ann-ui]`/`.ann-*` 命名空间下，经 manifest 注入（不使用 shadow root），不改宿主页面的 DOM。
- 浮层分两类（visual.md §2）：**深色浮条**不随系统外观，一套深色——选区菜单、剪藏通知（已剪藏/撤销/失败提示）、区块胶囊、键盘模式胶囊，截图的提示条、比例芯片、尺寸标签、编辑工具栏、状态条、成功气泡，批注的工具栏与提示条——用 `content.css` 顶部的 `--annov-pill-*`（定义在浮层根选择器上，不在暗色 media query 里重复）。
- **表单类浮层**亮暗两套、跟随系统——快速编辑气泡、区块“更多”菜单、美化面板、截图的文字输入框与错误卡片——用成对的 `--annov-*`（暗色值与 `styles/tokens.css` 同一套）。
- 新增颜色一律用变量。
- 截图会话里由 `index.ts` 注入的样式同样引用这些变量（带浅色回退值）。
- data-URI 图标读不到变量，深底上颜色一次定好，不做暗色换图分支。
- 能用 `currentColor` 的内联图标走 `icons.ts`。
- 选区蓝 `#4c91ff` 与键盘描边两种外观共用——它们标在页面内容上，不是表面。
