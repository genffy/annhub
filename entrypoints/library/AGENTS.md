# Library 页面约定

> 适用于当前 `entrypoints/library/`（应用页：全部、剪藏、高亮、截图、属性、设置，详情抽屉，阅读视图）和 `entrypoints/popup/`（同一套壳的紧凑版）；不是未来 monorepo 的目标划分。全局规则见根目录 `AGENTS.md`。
> 更新：2026-10-10。

## 职责与入口

- `App.tsx` 是壳：左导航、列表（50 条一页，“显示更多”用 keyset 游标追加；一页在路上时按钮禁用、`loadMore` 也不重入，否则第二次点击带着同一个游标把同一页追加两遍，`e2e/library-browse.spec.ts` 的双击用例守着）、详情抽屉；`route.ts` 是 hash 路由的读写。`reading-view.tsx`、`highlight-surface.tsx`、`markdown-view.tsx` 是阅读与库内高亮；`markdown-view.tsx` 是渲染以及“选区 ↔ 源文本偏移”换算的唯一实现（RK-13），界面与导出不各自换算：渲染的每个 run 带 `data-s`（源偏移；转义序列单独成 run，显示 1 个字符、占 2 个源字符），表格逐单元格渲染，围栏代码块按存下的高亮切开。引文由 `learning-core/markdown.ts` 的 `quoteFromMarkdownRange` 按源偏移拼出可见文字（`quoteForRange` 只是它的薄封装，store 合并重叠高亮时用的是同一个函数），不是源 Markdown 切片；围栏与行内代码的判定也取自那里，渲染器的 `INLINE` 与 `parseBlocks` 不各自再定。`property-panel.tsx`、`properties-view.tsx` 管属性，`settings-view.tsx` 管设置。`property-order.ts` 定属性页的行序（`title`、`tags` 置顶并锁定，其余内置按注册表顺序，自定义按名称）；`utils/entry-icons.tsx` 是所有扩展页面共用的图标与类型标记（`VIEW_ICONS`、`ENTRY_TYPE_ICONS`、`PROPERTY_TYPE_ICONS`、`TypeChip`，样式在 `styles/chips.css`），图标一律来自 lucide，类型在列表、抽屉、筛选和弹窗里都是图标加文字，颜色不单独表意（visual.md §3）。
- 页面不复制领域规则：条目的查询与写入只经 `types/messages.ts` 的消息；查询、校验、归一化在 `learning-core`。页面只在三处直接开同源 IndexedDB，都是读大块字节或要求逐 Blob 处理的地方：截图缩略图读图片 Blob、导出（`onExport` 用 `buildExport` 逐 Blob 构造 ZIP，把 Blob URL 交给 `chrome.downloads`）、设置页清理孤儿资产。
- 视图、筛选、抽屉里打开的条目和阅读视图都写入 URL hash，刷新后恢复（extension.md §2.2）；路由状态只有 URL 一个真源：`route.ts` 的 `readHash` 与 `listHash` 是一对带往返单测的纯函数，列表路由用 `e=<id>` 表示抽屉（`#/entry/<id>` 同样打开抽屉），阅读是 `#/read/<id>`，带 `?h=<高亮 id>` 时打开后滚到那条高亮（高亮视图的每一行都这样链接）。写 URL 只发生在用户操作里（导航链接 push，筛选 `replaceState`），不在 state 变化的 effect 里重写，也不覆盖它不认识的路由。
- 写入纪律：编辑在失焦或确认时提交一次（属性值先改本地草稿，`Enter` 或失焦提交，输入法组合期间不提交；高亮浮层的备注失焦只保存、不关浮层）；失败保留已输入的内容，显示本地化的错误与重试；任何关闭路径（`Esc`、遮罩、返回、导航）先提交未保存的编辑（根 `AGENTS.md` 第 5 条）。任何写入成功后列表、总数、导航计数与候选一起刷新（`reload`）。
- 文案全部走 `utils/ui-text.ts`（中英对应），不在 TSX 里写字面量（`utils/__tests__/ui-literals.test.ts` 用语法树守着：JSX 文字、面向用户的属性、字符串里的汉字）；错误由稳定错误码映射成本地化文案（`failureReason`/`entryErrorText`，配额不足时带“先导出”的说明），不直接展示错误码或后台的英文 message；导出失败的原因按阶段与错误类别选（`export-error.ts`），每条都说明没有生成文件。载入期间列表为空时显示“加载中”，不显示空状态。
- 搜索与筛选条（含总数）只在四个列表视图（全部、剪藏、高亮、截图）出现；属性页和设置页不渲染它，也不跑列表查询（`route.ts` 的 `isListView`）。空状态按筛选是否生效选文案（`hasActiveFilter`，高亮视图的颜色也算）：没有筛选时是该视图自己的入口提示，有筛选时是“没有匹配的结果”加“清除筛选”，筛选保留；不按库里有没有条目判断，否则库里有剪藏、没有截图时，截图视图会谎称“没有匹配”（`e2e/library-browse.spec.ts` 守着）。
- 壳的导航顶部是品牌和折叠按钮（`.nav-fold`，`aria-expanded`）。窗口宽度不超过 720 像素默认折叠，手动折叠记在 `localStorage`（`annhub.navFolded`）——只记折叠，窄窗口里展开只对本次访问有效；折叠由 App 在壳上设 `.is-rail`，图标栏的规则只有一份，不按折叠的原因写两遍。每个视图从页面标题（`h1.page-title`）开始：列表视图里标题与搜索同一行、筛选条在下；属性页与设置页有自己的标题，没有列表控件。类型筛选只属于“全部”（`FilterState.type`，URL 里是 `type=clip|screenshot`，计入 `hasActiveFilter` 与筛选计数），其余视图本身就是一种类型（`e2e/library-queries.spec.ts` 守着）。
- 阅读视图只占内容区（`.reading` 在内容列里铺满），不盖导航：导航里高亮的是打开前的那个列表（`navView`，由 `returnHashRef` 的列表路由推出），点导航离开阅读视图去那个列表。被盖住的列表留在 `.content-stage` 里，保持布局与滚动位置，但设为 `inert`——焦点、指针与读屏都进不去；阅读视图载入后焦点落在它自己的“返回”上。`e2e/library-shell.spec.ts` 守着，含“返回时列表还在原来的位置”。
- 抽屉里 `clip` 的原文与语境就地编辑（失焦或确认时提交一次，被拒绝的编辑保留草稿并可取消，任何关闭路径先写入未提交的编辑）：语境必须包含原文，清空即移除；有高亮时原文只读并写明原因（锁图标加高亮条数），语境照常可改；截图没有原文可改（`e2e/library-drawer-edit.spec.ts`）。
- 渲染不解析原始 HTML；链接只允许 http(s)，新标签页打开并带 `rel="noopener noreferrer"`（capture.md §3.1）。围栏代码块里的高亮同样画出来（`code` 块按存下的范围切开，每段带自己的源偏移），可点、可改色、可删。
- 样式是手写 CSS：`style.css` 开头有自己的重置，设计令牌在 `styles/tokens.css`，没有 Tailwind 也没有它的 preflight。控件不会自己继承字体，重置里要写 `button, input, select, textarea { font-family: inherit }`，否则每个控件都用浏览器自己的字体（量到过 Arial），弹窗的重置同理；`e2e/library-shell.spec.ts` 与 `e2e/popup-entry.spec.ts` 量计算后的字体。新增按钮、输入和链接按钮要自己写外观，否则显示浏览器默认外观（弹窗的 `.link` 就这样漏过）。弹窗是 340×360 的固定壳：左侧图标栏、右侧 `.popup-body`，快捷键提示在 `.popup-body` 里、列表下方，不能做成壳的第三列。筛选条会换行，不能溢出或互相盖住，里面的控件也不能比所在的框更宽，整页不能横向滚动（日期范围曾比自己的框宽出 90 像素）。版式由 `e2e/popup-entry.spec.ts`（弹窗的宽度、暗色对比度）、`e2e/library-browse.spec.ts`（筛选条在 1180、1024、390 像素宽度下）和 `e2e/library-layout.spec.ts`（设置页的行与控件、Markdown 表格、窄窗口图标栏）用 `getBoundingClientRect` 与 `getComputedStyle` 断言守着。
- 设置页自己滚动（`.settings-view` 是滚动容器，导航不跟着走，visual.md §4）。每张卡片是容器（`container-type: inline-size`）：标签与控件的行在卡片窄时改成上下排，按卡片宽度判断，不按视口写断点（视口 721 像素时卡片只有约 420 像素宽）。控件统一高度（`--settings-control-h`），滑块与数值同行不换行，需要换行的组合控件（文件选择加移除按钮）才允许换行。
- 层叠陷阱，都出现过：容器上的通配规则会盖住类名上的外观（`.settings-view button` 曾把高亮色点 `.hl-dot-*` 的背景压成透明，所以用 `:not(.hl-dot)` 排除）；给一类控件设的上限会被同类名的复合控件继承（`.filter` 的 `max-width: 180px` 管下拉框，日期范围也带着这个类，里面的两个输入就顶出了自己的框）；容器里放着用户内容（Markdown）时，容器的元素规则要写成子代选择器（`.drawer-section h3` 连正文里的 `##` 一起压成了 12 像素的灰色小标签，现在是 `.drawer-section > h3`，`e2e/library-layout.spec.ts` 拿阅读视图当参照量抽屉里的标题）；权重相同的规则按源码顺序取胜（窄窗口里计数徽章的填充规则没把 `.nav-item-current .nav-count` 一起列上，当前项的徽章成了强调色字压强调色底）；TSX 里的类名没有规则时页面照样渲染，只是排版散了（`settings-grid` 就这样空了很久）。新增类名时先写规则，再看真实页面。
- 窄窗口图标栏只有 52 像素：品牌用 `assets/icons/logo.svg` 的遮罩（构建时内联进 CSS）代替字样，文字留给读屏；计数徽章与别的项同色。折叠后的新元素要在 `e2e/library-layout.spec.ts` 的“都在图标栏里”断言下过；折叠按钮也在图标栏里（`e2e/library-shell.spec.ts`）。
- 抽屉是模态：遮罩盖住左导航（要导出先关抽屉），焦点进入并被限制在里面，关闭后回到触发行，`Esc` 在输入法组合期间不关。`Esc` 永远先关最里面的一层：高亮工具条，其次浮层（打开时取得焦点，关闭后还给原来的标记），最后才是阅读视图或抽屉。键盘扩展出的选区（`Shift` + 方向键，Chrome 在已有选区之后才允许）与鼠标一样出工具条，`H` 以默认颜色创建。
- 属性面板的每种行（含复选框）都参与 `flush()`：任何关闭路径先提交未提交的草稿；一行没有输入控件时视为“没有待并入的输入”，不能因此让 `flush()` 失败，否则抽屉就关不掉。
- 关闭路径永远不能被“没有可保存的内容”拦住：抽屉的条目还在加载、或已经不存在（URL 里的 `e=` 指向被删的条目）时，`Esc` 与遮罩照样关闭。抽屉的按键处理器只订阅一次，通过 ref 调用最新的“保存并关闭”；用依赖 `entry` 的回调重新订阅，异步渲染提交之后到被动副作用执行之前会有一个空档，这时的 `Esc` 落在上一次渲染的闭包上（`e2e/library-property-regressions.spec.ts` 里用 `MutationObserver` 在提交之后立刻发 `Esc` 守着）。

## 验证

- 渲染与偏移换算等纯函数：`npx vitest run entrypoints/library`。
- 页面行为：先 `rm -rf .output/chrome-mv3 && npm run build`，再跑 `e2e/library-browse.spec.ts`、`e2e/library-drawer-edit.spec.ts`、`e2e/library-export.spec.ts`、`e2e/library-layout.spec.ts`、`e2e/library-property-regressions.spec.ts`、`e2e/library-queries.spec.ts`、`e2e/library-shell.spec.ts`、`e2e/reading-highlight.spec.ts`、`e2e/settings-drafts.spec.ts`、`e2e/popup-entry.spec.ts`。选区一律用真实鼠标和键盘操作（三击、拖选、`dblclick`），不要程序化设置 Range 再派发合成事件；双击一个词时点词自己的中点（用 Range 量），不要点包含它的片段的中点——片段的中点可能落在邻词上。
