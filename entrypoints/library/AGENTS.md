# Library 页面约定

> 适用范围：`entrypoints/library/`（应用页：全部、剪藏、高亮、截图、属性、设置，详情抽屉，阅读视图）和 `entrypoints/popup/`（同一套壳的紧凑版）。全局规则见根目录 [AGENTS.md](../../AGENTS.md)。

## 职责与入口

- `App.tsx` 是壳：左导航、卡片列表、详情抽屉；`route.ts` 是 hash 路由的读写。列表每页 50 条，“显示更多”用 keyset 游标追加：一页在路上时按钮标为 `aria-disabled`、`loadMore` 也不重入，否则第二次点击带着同一个游标把同一页追加两遍；不能换 `disabled`——Chrome 会立刻把焦点从变成 disabled 的按钮上拿走，落到 `body`（测试：`e2e/library-browse.spec.ts` 的双击与键盘用例）。追加之后焦点落在新增的第一张卡片（extension.md §2.3），最后一页让按钮消失时也一样；焦点目标只由 `loadMore` 设，刷新与改筛选不动焦点，等待期间用户把焦点移到别处就不抢回。- `reading-view.tsx`、`highlight-surface.tsx`、`markdown-view.tsx` 是阅读与库内高亮；`markdown-view.tsx` 是渲染以及“选区 ↔ 源文本偏移”换算的唯一实现（RK-13），界面与导出不各自换算：渲染的每个 run 带 `data-s`（源偏移；转义序列单独成 run，显示 1 个字符、占 2 个源字符），表格逐单元格渲染，围栏代码块按存下的高亮切开。引文由 `learning-core/markdown.ts` 的 `quoteFromMarkdownRange` 按源偏移拼出可见文字（`quoteForRange` 只是它的薄封装，store 合并重叠高亮时用的是同一个函数），不是源 Markdown 切片；围栏与行内代码的判定也取自那里，渲染器的 `INLINE` 与 `parseBlocks` 不各自再定。- `property-panel.tsx`、`properties-view.tsx` 管属性，`settings-view.tsx` 管设置（本地指标面板按 [metrics.md §5](../../docs/product/metrics.md) 的近似口径覆盖 M-03、M-11、M-19–M-25 与 M-31（录制使用）：计算在 `learning-core/metrics.ts` 的 `metricSummaries`，经 `GET_METRICS` 一次读回，页面只渲染聚合数字；水印预览复用输出侧的 `paintWatermark`，图片读不出来时只画文字并提示重新上传；「录制」分区显示麦克风授权状态、可就地发起授权请求（extension.md §2.5、annotate.md §2.1），并设置录制时的光标高亮——开关、形状与颜色，annotate.md §3.2）。- `property-order.ts` 定属性页的行序（`title`、`tags` 置顶并锁定，其余内置按注册表顺序，自定义按名称）；`utils/entry-icons.tsx` 是所有扩展页面共用的图标与类型标记（`VIEW_ICONS`、`ENTRY_TYPE_ICONS`、`PROPERTY_TYPE_ICONS`、`TypeChip`，样式在 `styles/chips.css`），图标一律来自 lucide，类型在列表、抽屉、筛选和弹窗里都是图标加文字，颜色不单独表意（visual.md §3）。
- 页面不复制领域规则：条目的查询与写入只经 `types/messages.ts` 的消息；查询、校验、归一化在 `learning-core`。页面只在三处直接开同源 IndexedDB，都是读大块字节或要求逐 Blob 处理的地方：截图卡片读图片 Blob、导出（`export-dialog.tsx` 只做界面与状态，`onExport` 用 `buildExport` 逐 Blob 构造 ZIP，把 Blob URL 交给 `chrome.downloads`，下载时机与文件名不变）、设置页清理孤儿资产。
- 视图、筛选、抽屉里打开的条目和阅读视图都写入 URL hash，刷新后恢复（extension.md §2.2）；路由状态只有 URL 一个真源：`route.ts` 的 `readHash` 与 `listHash` 是一对带往返单测的纯函数，列表路由用 `e=<id>` 表示抽屉（`#/entry/<id>` 同样打开抽屉），阅读是 `#/read/<id>`，带 `?h=<高亮 id>` 时打开后滚到那条高亮（高亮视图的每条高亮都这样链接）。写 URL 只发生在用户操作里（导航链接 push，筛选 `replaceState`），不在 state 变化的 effect 里重写，也不覆盖它不认识的路由。
- 写入纪律：编辑在失焦或确认时提交一次（属性值先改本地草稿，`Enter` 或失焦提交，输入法组合期间不提交；高亮浮层的备注失焦只保存、不关浮层）；失败保留已输入的内容，显示本地化的错误与重试；任何关闭路径（`Esc`、遮罩、返回、导航）先提交未保存的编辑（根 `AGENTS.md` 第 5 条）。任何写入成功后列表、总数、导航计数与候选一起刷新（`reload`）。
- 文案全部走 `utils/ui-text.ts`（中英对应），不在 TSX 里写字面量（测试：`utils/__tests__/ui-literals.test.ts` 用语法树拦：JSX 文字、面向用户的属性、字符串里的汉字，以及模板字符串各段与 `+` 拼接里的全角标点）。拼出来的名称整句放进 `ui-text`，由各语言给出自己的标点（`reading.highlightLabel`：中文“高亮，黄色：原文”，英文“Highlight, Yellow: …”），不在代码里拼“：”；错误由稳定错误码映射成本地化文案（`failureReason`/`entryErrorText`，配额不足时带“先导出”的说明），不直接展示错误码或后台的英文 message；导出失败的原因按阶段与错误类别选（`export-error.ts`），每条都说明没有生成文件。载入期间列表为空时显示“加载中”，不显示空状态。列表与高亮视图的查询随要发出的查询文本重跑（`entryQueryJson`、`highlightQueryJson`），不随注册表重跑：随注册表回复再发同一个查询，第二次往返期间已经显示的空状态会变回“加载中”（测试：`e2e/library-browse.spec.ts`）。URL 带属性条件时，查询等注册表回来再发，不先显示未筛选的列表。
- 搜索与筛选条（含总数）只在四个列表视图（全部、剪藏、高亮、截图）出现；属性页和设置页不渲染它，也不跑列表查询（`route.ts` 的 `isListView`）。筛选条是自绘按钮加弹层（`filter-bar.tsx`，extension.md §2.3/search.md §3）：每个维度一枚触发按钮，弹层是带名称的 `role="dialog"`；来源、标签、属性的弹层带搜索框；属性弹层先选属性、再给该类型的运算符和值。已生效条件显示为高亮芯片：主体重新打开该维度的弹层，× 移除（读屏名称带“移除筛选”）。键盘模型：触发按钮与芯片都在 Tab 顺序里；弹层打开后焦点进入（搜索框优先，否则第一个选项），↑↓ 走选项，Enter/空格选择，Esc 只关弹层并把焦点还给打开它的元素，Tab 离开弹层即关闭，点外面关闭。语义（同维度 OR、跨维度 AND、条件写入 URL）见 [search.md §3](../../docs/product/search.md)；URL 上 `host`/`tag`/`color` 重复出现，条件按 `prop`/`op`/`val`/`val2` 的索引对齐成组（四个参数每个条件都写，缺的留空，往返不串行——旧的单条件 URL 兼容）。空状态按筛选是否生效选文案（`hasActiveFilter`，高亮视图的颜色也算）：没有筛选时是该视图自己的入口提示（图标方块、标题、说明、操作），有筛选时是“没有匹配的结果”加实心的“清除筛选”，筛选保留；不按库里有没有条目判断，否则库里有剪藏、没有截图时，截图视图会谎称“没有匹配”（测试：`e2e/library-browse.spec.ts`）。
- 壳的导航顶部是品牌（带 logo 标记）和折叠按钮（`.nav-fold`，`aria-expanded`），导航项分「资料库」「管理」两组、各带 `.nav-group-title` 小标题（折叠成图标栏时隐藏），当前项是底色加粗加左侧竖条（`::before`）。导航宽 232（图标栏 60），断点 1100 与 720：≥ 1100 展开，720–1099 默认展开、可手动折叠，< 720 默认折叠；任何宽度都不换成顶部导航。导航底部三块（`nav-foot`）：存储用量（全局 `progress`）、“导出内容”描边按钮、快捷键提示（全局 `kbd` 键帽，取浏览器实际绑定）。手动折叠记在 `localStorage`（`annhub.navFolded`）——只记折叠，窄窗口里展开只对本次访问有效；折叠由 App 在壳上设 `.is-rail`，图标栏的规则只有一份，不按折叠的原因写两遍。导航项都在 Tab 顺序里，↑↓ 另外在导航项间移动焦点（App 的 `onNavKeyDown`）；列表视图里 `/` 聚焦搜索框（抽屉或阅读视图开着时不抢）。每个视图从页头（`header.page-head` → `.page-titles`（`h1.page-title` + `p.page-sub` 副标题计数）与 `.page-actions`）开始，内容在 `.page-body` 里——属性页与设置页用同一个页头结构，标题与内容左缘一致。类型筛选只属于“全部”（`FilterState.type`，URL 里是 `type=clip|screenshot`，计入 `hasActiveFilter` 与筛选计数），其余视图本身就是一种类型（测试：`e2e/library-queries.spec.ts`）。
- 全部、剪藏、截图是同一个卡片网格（`EntryCard`，`ul.entry-grid`，extension.md §2.3；卡片最后一行——类型徽标、来源主机（省略）、相对时间，有高亮多一枚“N 高亮”小标签，高宽比 ≥ 2 的截图 `data-tall` 从顶部 `cover` 铺满预览框）：`auto-fill` 的列，卡片不窄于 `--card-min`，左缘与页面标题对齐；同一行等高，最后一行用 `margin-top: auto` 压在卡片底部，整行卡片对齐。标题与标签行里还有自定义属性小标签（`.ppill`，`propertyPills`：按属性页顺序最多两枚、复选框只在为真时出现、列表属性显示第一项）。预览区一律同高：剪藏是正文开头的纯文本，截图是图片。行数截断（`-webkit-line-clamp`）写在预览框里面那层自动高度的元素上：写在固定高度的框本身，省略号之后的行照样画出来，框底露出半行。卡片按钮的名称用 `aria-labelledby` 取标题、标签和元信息，正文开头是 `aria-describedby`：读屏先听到是哪一条，再听内容。卡片的 `overflow: hidden` 会裁掉按钮自己的焦点环，所以环画在卡片上（`:has(> .entry-card-open:focus-visible)`）；抽屉里打开的那张带 `.entry-card-selected`（品牌色描边）。下载与删除只在截图视图出现（悬停或焦点在卡片里时显示），全部视图里的截图卡片没有。高亮视图按条目分组成卡片、多列竖排（`column-width`）：多列写在 `.list` 里面的 `ul.hl-groups` 上，写在固定高度的滚动容器本身会横向溢出。每组卡头是标题（窄卡独占一行）、主机、条数小标签与“回到来源”；每条高亮（`.hl-item`，带自己的颜色条）显示引文、备注行与元信息行（相对时间加所属剪藏的标签与属性小标签）——`.hl-row`/`.hl-quote` 是阅读视图侧栏的样式，别混用。`.list` 是四个列表视图共用的滚动容器，“显示更多”在它外面。`e2e/library-layout.spec.ts` 量列数、卡片等宽等高、预览等高、截断只露整行与读屏名称。
- 阅读视图只占内容区（`.reading` 在内容列里铺满），不盖导航：导航里高亮的是打开前的那个列表（`navView`，由 `returnHashRef` 的列表路由推出），点导航离开阅读视图去那个列表。被盖住的列表留在 `.content-stage` 里，保持布局与滚动位置，但设为 `inert`——焦点、指针与读屏都进不去；阅读视图载入后焦点落在它自己的“返回”上（测试：`e2e/library-shell.spec.ts`，含“返回时列表还在原来的位置”）。
- 抽屉里 `clip` 的原文与语境就地编辑（失焦或确认时提交一次，被拒绝的编辑保留草稿并可取消，任何关闭路径先写入未提交的编辑）：语境必须包含原文，清空即移除；有高亮时原文只读并写明原因（锁图标加高亮条数），语境照常可改；截图没有原文可改（`e2e/library-drawer-edit.spec.ts`）。
- 属性页：注册表是一张加了 `role` 的 grid 表格（`tr` 是 grid，隐式表头关联会丢，角色要写全），页头带副标题计数与“删除未使用（N）”（N 为 0 时禁用），表格上方是三条规则的提示条。`title`、`tags` 置顶并标“固定”，预设两列固定勾选并灰显；删除按钮永远在行里，不可用时灰显且中性着色，下面写明原因——可见处是短词（内置/使用中，`.prop-reason`），整句在 `.sr-only` 里供 `aria-describedby` 朗读，也在按钮 `title` 里，亮暗两套外观下可见文字对比度都不低于 4.5（`e2e/library-properties-page.spec.ts`）。新建表单在表格末尾展开：类型用 `property-type-picker`，名称错误就地显示在输入下方，保存按钮在名称为空或有错时禁用——错误提前用 `learning-core/properties.ts` 的校验函数与已载入的注册表判断，不在界面里复制规则。
- 渲染不解析原始 HTML；链接只允许 http(s)，新标签页打开并带 `rel="noopener noreferrer"`（capture.md §3.1）。围栏代码块里的高亮同样画出来（`code` 块按存下的范围切开，每段带自己的源偏移），可点、可改色、可删。
- 样式是手写 CSS：`style.css` 开头有自己的重置，设计令牌在 `styles/tokens.css`，没有 Tailwind 也没有它的 preflight。控件不会自己继承字体，重置里要写 `button, input, select, textarea { font-family: inherit }`，否则每个控件都用浏览器自己的字体，弹窗的重置同理（测试：`e2e/library-shell.spec.ts` 与 `e2e/popup-entry.spec.ts` 量计算后的字体）。新增按钮、输入和链接按钮要自己写外观，否则显示浏览器默认外观。强调色有两个令牌：`--ann-accent` 是填充（按钮底、描边、焦点环），文字用 `--ann-accent-text`；类型色另有九个令牌 `--ann-type-<type>`、`--ann-type-<type>-soft`、`--ann-type-<type>-text`（图标/描边、标签底色、标签与高亮计数的文字，亮暗成对，取值见 `styles/tokens.css`），类型色只做辅助不单独表意，当前导航项仍整行用强调色；暗色下两者不同，强调色文字压在 `--ann-accent-soft` 上时用错令牌只有 2.58:1（测试：`e2e/library-layout.spec.ts` 与 `e2e/popup-entry.spec.ts` 量类型标签与阅读视图的当前标签）。弹窗是 520 宽的壳：左侧 52 像素图标栏、右侧 `.popup-body`，高度随内容（最小 340，浏览器弹窗上限 600，壳不竖向滚动），快捷键提示在 `.popup-body` 里、列表下方，不能做成壳的第三列。弹窗同时是批注与录制的入口（annotate.md §1.1、§2.1）：当前页可批注时给批注按钮，录制入口带麦克风开关、进行中显示时长，开始失败与下载失败就地说明并可重试或放弃；chrome:// 等内容脚本进不去的页面给原因而不是按钮。筛选条会换行，不能溢出或互相盖住，里面的控件也不能比所在的框更宽，整页不能横向滚动；筛选弹层（`.filter-pop`）是 `position: fixed` 的浮层，避开滚动容器的裁剪，宽度用 `max-width: min(360px, calc(100vw - 16px))` 收在窗口里。版式由 `e2e/popup-entry.spec.ts`（弹窗的宽度、暗色对比度）、`e2e/library-browse.spec.ts`（筛选条在 1180、1024、390 像素宽度下）和 `e2e/library-layout.spec.ts`（列表的卡片网格、设置页的行与控件、Markdown 表格、窄窗口图标栏）用 `getBoundingClientRect` 与 `getComputedStyle` 断言守着。
- 设置页在 `.page-body` 里滚动（导航不跟着走，visual.md §4），内容是两列卡片网格（容器查询：内容宽窄于约 860 变一列）。每张卡片是容器（`container-type: inline-size`）：行在卡片窄于约 420 时改成上下排，按卡片宽度判断，不按视口写断点（视口 721 像素时卡片只有约 420 像素宽）。控件都是原生表单控件加样式，共用件在 `settings-card.tsx`（卡片与行）、`settings-switch.tsx`（`role="switch"`，读屏名称是行的功能名，`aria-labelledby`）、`settings-seg.tsx`（分段单选组）、`settings-slider.tsx`、`settings-posbox.tsx`、`settings-check-chip.tsx`、`settings-swatches.tsx`（色块取 `output.ts` 的 `backgroundCss`，不另抄色值）。滑块拖动中只改本地值，`pointerup` / `keyup` / `blur` 才 `patch`，失败不丢值并提示（测试：`e2e/settings-drafts.spec.ts`）。
- 层叠规则：容器上的通配规则会盖住类名上的外观（如 `.settings-view button` 会压掉 `.hl-dot-*` 的背景）；给一类控件设的上限会被同类名的复合控件继承（`.filter` 的 `max-width` 也套在带着这个类的日期范围上）；容器里放着用户内容（Markdown）时，容器的元素规则要写成子代选择器（`.drawer-section > h3`，不带 `>` 会连正文里的 `##` 标题一起压掉；测试：`e2e/library-layout.spec.ts` 拿阅读视图当参照量抽屉里的标题）；权重相同的规则按源码顺序取胜（窄窗口里计数徽章的填充规则要把 `.nav-item-current .nav-count` 一起列上）；TSX 里的类名没有对应规则时页面照样渲染，只是排版散掉。新增类名时先写规则，再看真实页面。
- 窄窗口图标栏只有 60 像素：品牌用 `assets/icons/logo.svg` 的遮罩（构建时内联进 CSS）代替字样，文字留给读屏；计数徽章与分组小标题收起，图标仍有 `title` 提示。折叠后的新元素要在 `e2e/library-layout.spec.ts` 的“都在图标栏里”断言下过；折叠按钮也在图标栏里（`e2e/library-shell.spec.ts`）。
- 抽屉是模态：透明的点击区域盖住左导航（点抽屉外面关闭，不压暗页面；要导出先关抽屉），焦点进入并被限制在里面，关闭后回到打开它的卡片，`Esc` 在输入法组合期间不关。删除确认是一张卡片叠在抽屉之上：焦点进“取消”，Tab 在两个按钮间循环，`Esc`、取消与点遮罩都只取消确认并把焦点还给“删除”。导出是对话框（`ExportDialog`）：准备 / 进行中 / 完整 / 部分导出各态；进行中不能关闭（导出不可取消，`Esc` 无效），其余状态 `Esc` 与“完成”关闭并把焦点还给导航里的“导出内容”。`Esc` 永远先关最里面的一层：导出对话框与删除确认，其次高亮工具条，再次浮层（打开时取得焦点，关闭后还给原来的标记；点浮层外面也会保存并关掉），最后才是阅读视图或抽屉。键盘扩展出的选区（`Shift` + 方向键，Chrome 在已有选区之后才允许）与鼠标一样出工具条，`H` 以默认颜色创建。
- 属性面板的每种行（含复选框）都参与 `flush()`：任何关闭路径先提交未提交的草稿；一行没有输入控件时视为“没有待并入的输入”，不能因此让 `flush()` 失败，否则抽屉就关不掉。
- 关闭路径永远不能被“没有可保存的内容”拦住：抽屉的条目还在加载、或已经不存在（URL 里的 `e=` 指向被删的条目）时，`Esc` 与遮罩照样关闭。抽屉的按键处理器只订阅一次，通过 ref 调用最新的“保存并关闭”；用依赖 `entry` 的回调重新订阅，异步渲染提交之后到被动副作用执行之前会有一个空档，这时的 `Esc` 落在上一次渲染的闭包上（测试：`e2e/library-property-regressions.spec.ts`，用 `MutationObserver` 在提交之后立刻发 `Esc`）。高亮工具条拦 `Esc` 的捕获监听同理只订阅一次，由渲染时写入的 `toolbarRef` 判断工具条在不在：随工具条订阅、由被动副作用移除的监听，在高亮的回复让工具条离开 DOM 之后还会留一会儿，这时的 `Esc` 什么也没关，也到不了阅读视图。
